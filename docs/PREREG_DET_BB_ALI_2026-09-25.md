## §2. 수리·원천·가드·base 설계

- **(a) 수리 형태 = Sobolev 순 복사 괄호, J_inc = J_cont 직접.** 근거: 생산자(`line_net_rate.c`:296) 가 이미 CMFGEN 비겹침 Sobolev J̄ = β J_cont + (1−β) S_old 를 만들고, 두 준위 대수에서 n_l B_lu J̄ − n_u(A + B_ul J̄) 의 (1−β)S 항은 S 가 **현재** 인구 n 의 것이고 χ_Sob = χ_Einstein 일 때만 (1−β) n_u A 와 상쇄돼 순 율 = β[n_l B_lu J_cont − n_u(A + B_ul J_cont)] 가 된다(MALI 항등식). 생산자는 S_o = η_o/χ_o(직전 커밋 인구 n_o, Sobolev 계수 χ)를 넣으므로 기존 율과 NRB 율의 차이는 D = n_l B_lu − n_u B_ul 로 **F_Λ − F_NRB = D(n)·le_o − (1−β) n_u A = (1−β)A[n_u,o D(n)/D(n_o) − n_u] + O(χ 불일치)**(astra B1) — n = n_o 이고 χ 가 일치할 때만 0 이다. ⟹ **이 개입은 고정 J̄ 행렬의 항등 재작성이 아니라, 선 자기 소스를 새 인구에 암묵적으로 연결하는 반복법 변경**이며, 계약이 말하는 것은 「CMFGEN 비겹침 Sobolev 순율 형태로 바꿨을 때의 응답」이다. 현 코드(Λ-형태)는 그 연결을 반복에 맡긴다 — 2단계가 판독한 Λ-정체(교정 ∝ β). NRB 는 CMFGEN Sobolev 극한의 순율 **형태**(`ZNET` 의 고정 β·고정 J_cont 판)이고 CMFGEN 의 선형화 전체(불투명도·방출 미분, superlevel 인자)와 같지 않다. 행렬은 인구에 선형으로 남는다. ⚠χ 불일치: 생산자 τ 는 `SOBOLEV_COEFF`·f_lu·λ(`lumina.h`:36), 행렬은 Einstein B — 상수 수준 7.25 ppm 불일치 이력(`docs/A210_SOBOLEV_EINSTEIN_IDENTITY_CONTRACT_2026-08-16.md`); β < 10⁻⁵ 선에서는 이 잔차가 β 억제 순율보다 클 수 있다. 상수 몫은 selftest (6) 이 재고, deck 몫(f_lu·λ 직렬화)은 이 계약이 재지 않는다(**한계 기재**). 세부 균형: J_cont = B_ν(T_e) 이면 β 가 상쇄돼 n_u/n_l → 볼츠만(selftest §3).
- **(a′) 적용 대상(astra B1)**: NRB 는 **생산자 상위 인구가 행렬과 같은 NLTE 인구인 선**에만 건다 = `a209_upper_population_for_tau`(:10240–) 의 `use_nlte` 조건 `mapped ∧ !skip_tau ∧ 쌍 소유`(:10147·:10160–10176; 398939 는 element-wide OFF 라 쌍 소유 = `nlte_get_pairs` 6쌍). 행렬 조립은 쌍 단위(:18892–18894 `map ∈ [ion_idx_lo, ion_idx_hi]`)이므로 남는 판정은 **`nlte_skip_z[Z] == 0`**(:10068 정적 마스크, Z = `nlte->nlte_Z[map]`; 398939 `LUMINA_NLTE_SKIP_Z=14` ⟹ **Si II–III 선은 base 형태 유지**, Ca·Fe·S·Co·Ni 선은 NRB).
