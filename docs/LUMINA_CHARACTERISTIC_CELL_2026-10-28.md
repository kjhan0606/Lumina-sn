# 실제 이동 주파수에서 생산 특성선 셀 대조 — 2026-10-28

## 목적과 범위

Si/S 분포와 물리량·스펙트럼의 최종 동질성은 **NOT_MET**다. 이전 대역 대조는
원 격자 이차 적분의 blue 이력 자유도 부족을 확인했고, CONT_FREQ 변경만으로
같은 위치의 큰 흡수 흐름 차이가 해소되지 않음을 보였다. 반경 셀 대조는
같은 생산 Reader 재구성에서 적분이 수렴함을 보였지만 고정-blue 식이었다.

이번에는 실제 이동ν의 fullSR 특성선에서 같은 생산 계수 함수를 고정해,
공용 생산 chain의 끝점 선형 적분과 독립 ODE를 대조한다. 차이가 실제 적분
오차인지, 서로 다른 source/좌표 정의의 차이인지를 구분하는 것이 목적이다.
원 SC 숫자에 맞추는 보정은 하지 않는다. 합성 시험 통과로 최종 목표를 닫지 않는다.

입력은 완료된 legacy 물질70/J71 실행의 실제 C 계수·균일 logν 격자와 source J,
원90점 기하 및 기존 포획의 ray54다. native50→49 외향 셀에서 출구 주파수
611.125064/673.572249/714.952554Å를 고정한다. 구 입력을 쓰는 이유는 실제
생산 Reader를 같은 계수로 조사하기 위해서이며 새 F2의 물질이나 공통 계수
CMFGEN 기준으로 바꿔 부르지 않는다. 모든 입력 해시와 기하 주소를 확인한다.

생산 `lumina_native_linear::Reader`로 진η·ES·J를 반경에서 각각 보간·조립하고
GPU와 같은 순서로 주파수를 선형 보간한다. 원 ν 격자 밖으로 외삽하지 않는다.
광선의 ν(x)=ν_exit D(x)/D_exit와 proper ds=D dz는 실제 속도/반경 함수에서
재평가한다. mesh마다 다른 연속장을 피팅하지 않는다.

독립식은 생산 affine 맵을 쓰지 않는 z좌표 ODE다.

```text
dI/dz = D η − [D χ − 3 d(log D)/dz] I
```

D 미분은 같은 셀의 선형 속도장을 직접 미분한다. 정적 gray 닫힌해와 진공의
I/D³ 불변량으로 부호·단위·프레임을 확인한다. 적응 Radau의 상대 tolerance
1e-8/1e-10 결과 차이와 함수 평가량을 기록한다. 이는 엄밀 전역 오차 상계가 아니다.
공용 CPU chain은 GPU도 사용하는 `cmf_fullsr_linear_map.hpp`를 호출한다.
이 시험만으로 GPU 실제 실행 재현을 주장하지 않는다.

동일 제어 입사 I=1e-8에서 공간1/4/16/64/256의 결과와 독립 ODE 대비 오차를
읽는다. 이동ν의 실제 CMFGEN 입사 스펙트럼을 포획했다고 주장하지 않는다.
미완료·시간초과면 이미 끝난 조건만 보존하고 자동 재시도하지 않는다.

운전자가 구현·직접시험·판독을 담당한다. 부하·프로젝트·공유 입력 접근을
확인한 lageunha에서 CPU1·4GiB·외부180초/내부150초·단회·재시도0으로
새 전용 root에만 수행한다. 새 전대역 수송·BF/SE/RE·물질/observer 실행은0회다.
생산 기본값과 기존 원본은 변경하지 않는다. 실제 불일치를 발견하면 원인과
전역 영향 범위를 구분한 뒤 후속 구현을 결정한다.

## 균일 공간 대조 이후 phase 의미 확인

첫 대조는 `lumina_characteristic_cell_20261028-SngtSy/result`에서
exit0·67.733초에 완료됐다. 독립 ODE 두 허용치의 상대 변화는
611/673/715Å에서8.00e-9/2.24e-9/2.29e-9였다.
공간64→256분할의 독립 참조 대비 상대 오차는 각각
7.2125%→0.36445%,3.1559%→0.22613%,0.45712%→0.062678%였다.
거친 분할에서는 비단조·큰 오차가 나타났다. 그러나 이 숫자를 현재 F2에
직접 적용하면 안 된다.

C 원식 `cmf_nodal_driver_phase_grid`의 n은 `ceil(span*subdivisions)`다.
현재 F2의4는 물리 셀 전체4분할이 아니라 **이동 주파수 한 bin당4분할**이다.
기존 GPU 적응 driver와 resident 경로도 구별한다. 후자는 이 C phase mesh를
사용하며 구간마다 독립 잔차에 따라 mesh를 다시 적응시키는 경로는 아니다.
기록의 숫자4만 보고 전체 셀이4조각이었다고 판단하지 않는다.

이를 직접 확인하기 위해 완료된 독립 ODE 값과 원 해시를 재사용하고,
현재 F2와 같은 `geometry.so`의 C phase 기하로1/2/4/8을 대조한다.
새 ODE 적분은0회이고, 기존 실제 C source와 제어 입사는 유지한다.
이는 완료된 실행의 재시도가 아니라 생산 mesh 정의의 별도 한정 대조다.
lageunha CPU1·4GiB·외부90초/내부75초·단회·재시도0으로 새 root만 쓴다.
현재 F2의 다른 물질/각도 격자 전체에 대한 오차 인증은 여전히 아니다.

선택하지 않은 파장·광선의 문제를 배제하지는 않는다. 반대로 이 세 점의
