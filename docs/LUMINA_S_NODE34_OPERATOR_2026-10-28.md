# 원34점 S 동일 입력 SE 연산자 비교 — 2026-10-28

## 목적과 범위

Si/S 분포의 CMFGEN 불일치 원인을 좁히기 위해 원70의 같은 인구·T/ne·J에서
원34점 S의 C 입력 잔차와 기존 native raw SE를 준위별로 대조한다. 새 온도·
인구 solve, BF/BB 적분, 수송, native 실행, 전역 물리 판정은 하지 않는다.
실제 생산 C roster와 native의 이산 BB roster가 완전히 같다고 가정하지 않는다.

기존 완료 BF90·선율90·원자/물질 snapshot과 원70 native witness를 재사용한다.
운전자가 C 조립기의 기존 행렬에서 초기 인구에 작용한 raw 잔차 및 BF복사,
BF충돌, BB복사, 전체 충돌과 용해 충돌의 유입·유출만 비교 전용 API로
추출한다. 용해는 전체 충돌의 부분집합이다. 기본 생산 API나 물리식을
바꾸지 않고 비교 전용 매크로로만 빌드한다.

원자주소·원70 인구·T/ne·복사장·기존 입력 SHA와 전 경로 완결성, 행별
raw와 과정 흐름의 합, 기존 원34점 C ledger의 최대 정규화 잔차 재현을
확인한다. native와 C가 다른 BB 계약을 사용할 수 있으므로 우선 차이와
과정 범위를 밝히며 차이가 특정 구현의 오류라는 판정은 하지 않는다.
결과에는 정확한 입력·소스·바이너리 신원과 재현 명령을 포함한다.

Lageunha 수동 CPU1·4GiB·외부180초·GPU0·단회·재시도0으로 새 전용 root에만
빌드와 평가를 수행한다. 기존 결과·원본·진행 중인 다른 작업은 보존한다.
미완료면 부분 출력만 보존하고 자동 재시도하지 않는다. 이미 계산된 native
witness는 다시 생성하지 않는다. 최종 Si/S·RE·수송·observer 목표는 NOT_MET다.

## 해석과 다음 확인

이 결과는 원34점에서 차이가 주로 이온 단계 내부의 준위별 균형에 나타남을
보여준다. 다만 서로 다른 BB 선 목록·선 프로파일 계약이 결과에 포함되며,
native의 과정별 고정밀 분해가 아직 없으므로 BB 구현 오류나 특정 충돌
기작을 원인으로 확정할 수 없다. 단계 순유입이 거의 같다는 사실도
정상 이온화 분포가 같다는 증거가 아니다. 다음에는 동일 native BB 계약을
사용해 같은 원34점의 잔차를 비교하고 남는 차이를 과정별로 좁힌다.

재현은 고정 실행 디렉터리의 `source`와 `build/bridge-probe.so`,
`source-sha256.txt` 및 결과 JSON의 입력 SHA를 사용한다. 생성된 결과는
덮어쓰지 않고 새 출력 경로를 지정한다. 위 수치는 진단의 완료이지 CMFGEN
분포나 최종 스펙트럼의 목표 달성이 아니다.

## 후속 동일 선 계약 비교

앞선 실행의 원70 물질, 원34점, BF율, 충돌, 인구 및 원 복사장은 유지하고
native가 저장한 선별 공명구간과 이산 프로파일 질량으로 선율만 계산한다.
같은 C 행렬 조립에서 선율을 교체해 native 행별 잔차와 비교하고, 생산
선율을 쓴 앞선 결과와 과정별 차이를 대조한다. BF 계약은 아직 같다고
가정하지 않으며 정상해·새 수송·공개 물질 갱신은 하지 않는다.
Lageunha에서 CPU1·4GiB·외부180초·GPU0·단회로 새 실행 디렉터리를 사용한다.

결과: `lumina_s_node34_nativebb_20261028-sTfeuk`. S 선 14,426개 중 native
활성 14,412개, 비활성 14개다. native 비활성 선의 세 율은 모두 0으로
처리했다. 기존 생산 선율 / native 이산 선율의 최대 행별 절대 차이는
`1,396,683.466 / 1.44038` cm⁻³ s⁻¹, 최대 총흐름 대비 차이는
`0.125460 / 0.0000277026`이다. BF 복사·BF 충돌·전체 충돌·용해 유입과
유출은 두 실행에서 행별로 정확히 같았다. 따라서 이 입력과 이 점에서
기존의 큰 차이는 선 계약 변경으로 설명되지만, 남은 차이와 다른 점들,
새 복사장에서의 분포는 아직 검증되지 않았다. native 이산 선 적분을
생산 수송의 물리적으로 최선인 규약이라고 자동으로 판정하지 않는다.

후속 단일점 고정 T/ne/J 정상해는 이 선 계약의 S 단계 분포 영향을
수치로 확인한다. 다른 조건은 유지하며 charge/RE 공동수렴·새 수송 및
CMFGEN 전체 모델의 정상해라고 해석하지 않는다. 계산 위치와 자원은
위와 같고 별도 실행 디렉터리를 사용한다.

결과: `lumina_s_node34_nativese_20261028-vy3sr3`. S III 비율은 원70 입력
`0.48199246`, 생산 선율의 고정장 정상 후보 `0.49701189`, native 이산
선율의 고정장 정상 후보 `0.50259937`이다. S IV는 각각 `0.51800334`,
`0.50298343`, `0.49739590`이다. 고정장 정상해의 성분별 잔차는
`9.40e-17`이다. 이 값은 기존 생산 선율과 native 이산 선율의 차이가
이온 분포에도 영향을 미친다는 증거다. 하지만 원70은 원래 정상해가
아니므로 원70과의 차이가 커졌다는 사실만으로 어느 선 처리가 더
정확하다고 판정할 수 없다. 또한 고정 전자밀도와 온도에서 S만 푼
결과이므로 자기일관 모델이나 새 복사장 결과를 대체하지 않는다.

## 남은 행별 차이의 크기 분류

기존 native 선 계약 결과 JSON만 grammar-debug CPU1·4GiB·60초 한도에서
읽었다. 새 율·SE·수송은0회다. 최대 절대차1.44037737은 S III SL3의
행이며, 그 행의 C 유입+유출1.23317248e8로 나누면1.16803e-8이다.
최대 상대차2.77026e-5는 terminal S VI의 아주 작은 행에 있고, 그
인구/전체 S는2.68168e-24, 절대차는3.69058e-25 cm^-3 s^-1이다.
절대 최대 행과 상대 최대 행을 같은 행처럼 해석하지 않는다.

동반한 Si31점 결과의 최대 절대차0.51320827도 Si III SL1의 총흐름으로
나누면5.79836e-10이다. 다만 Si V 바닥 행은 상대차2.76080e-5,
그 행만의 인구/전체 Si가9.13650e-7이다. 따라서 상대 최대가 작은
인구에서 나온다는 이유로 모두 활성 집합에서 버릴 수 없다.
이 분류는 v2의 `max(inflow,outflow,n_i/t_ref)`와 전체 scaled residual
비교가 아니라 기존 보고서의 유입+유출 분모다. 최종 E-동등 판정으로
대체하지 않으며 남은 작은 차이의 기작도 아직 특정하지 않았다.

소비한 S/Si 보고서 SHA256은 각각
`0b090f9d5299dab79c9be0acac2035d74bc4cb5ac689be725a5ef147381aa6f6`,
`17497c2afb1193fc3863548d8db34f164e9860134ff09e7a988442a9f1c718f5`다.
JSON `details`의 `abs(C_raw-native_raw)/gross_C`와
`population/sum(population)`로 위 행을 재현한다. 상수 차이라는 가설만으로
코드나 현재 T/ne 실행의 입력을 수정하지 않았다.
