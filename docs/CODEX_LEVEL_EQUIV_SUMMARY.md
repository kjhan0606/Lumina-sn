## 판정 규칙

- CMFGEN rank: 링크된 `F_OSCDAT` 준위 ID의 `abs(ID)-1`.

  - 절대 기준 `|ΔE| ≤ 1×10⁻⁶ cm⁻¹`.
  - 상대차 `|ΔE| / max(|E_CMFGEN|, 1 cm⁻¹)`.
- `g`: 정수 정확 일치.
- 배치 정규화:
  - `casefold`
  - 공백과 ASCII 영숫자 이외 문자를 제거

  - 표의 배치 불일치는 [manifest](/home/kjhan/BACKUP/Eunha.A1/Claude/Lumina-sn/data/tardis_reference_toy06_19p48d_sivcaiv/coldata_cmfgen_manifest.csv)의 `osc` provenance 라벨을 사용한 보조 대조이다.
  - runtime configuration 동등성은 존재하는 10,986준위 모두 검증 불가/라벨 부재다.
- σ 부착: `has_cmfgen != 0`이고 해당 1,000-bin 행에 실제 양의 유한값이 있어야 함.
  - binary flag/실제 grid 불일치: 0건.
- Υ 부착: 캡처가 읽는 `status==OK` manifest 바이너리와 Fe III 전용 바이너리에서 해당 `level_number`가 적어도 한 전이에 등장해야 함.

선 결합은 처음 `λ+A+f`로 고정했으나 `f_lu`가 A·g·λ에서 재계산된 종속값이어서 동일 선을 반올림 차이로 탈락시켰다. 이를 기록하고 최종적으로 다음 독립 기준을 사용했다.

- `|Δλ| ≤ 5×10⁻⁴ Å`
- `A_ul` 상대차 `≤5×10⁻⁷`, 절대 바닥 `0.5 s⁻¹`
- 끝점 번호는 선 후보 선택에 사용하지 않음
- 다중 후보는 모호로 제외
