## 7. ★함정 목록 — 인수자가 반복하지 말아야 할 것

이 세션 운전석 오류가 **한 계급**이었다: **이름이 시사하는 의미를 재보지 않고 그대로 쓴 것.**

| 믿은 것 | 실제 |
|---|---|
| `.rev1` = 최신 개정 | **보존본**. base `.md` 가 정본 |
| `chmod 444` = 쓰기 차단 | `os.replace()` 는 **디렉토리 엔트리** 교체 — **부모 디렉토리** 권한이 경계 |
| 디렉토리 `mtime` = 생성 | **최종 변경**(생성은 birth) |
| `sacct -j` = 전역 | **클러스터 범위**(`-M syntax` 필요) |
| `/tmp` = 공유 | **노드-로컬**(grammar 에서 안 보임) |
| `… \| tail` 뒤 `$?` | **`tail` 의 rc**(`pipefail` 필요) |
| 마지막 십진 자릿수 변조 | double 에서 **bit-항등**(널 주입) |
| 전역 SUMMARY = 이온별 잣대 | `TARGET_ION` 을 **소비하지 않음** |
| `pgrep -f X` | **자기매칭** + 타 사용자 포함 |

**나머지 함정**:
- nested ssh 는 `$HOME` 에 착지 — `ssh grammar "ssh grammar-debug 'cd <repo> && …'"`.
  `cd` 누락 시 rc=2 file-not-found 가 나고 **게이트 실패로 오독하기 쉽다.**
- `run_in_background` 안에 `&` 를 **중첩하지 마라**(겹치면 죽는다 — 이번엔 살았지만 확인 필요했다).
- **봉인 규율의 구멍**(대장 후보·미수리): 봉인 루트가 `drwxr-x---` 라 **소유자 측
  `os.replace()` 를 막지 못한다.** ⟹ **봉인은 이 벡터에 탐지적이지 예방적이 아니다**
  (검출 = `*.sha`·`sha256sum -c`). 게이트 산출물 9본은
  `/gpfs/kjhan/lumina/zo_artifacts/sealed/`(dir 555 + 원 경로 상대 심링크)로 보호했고,
  판독기의 `REPORT_PATH_SYMLINK`/`UNSAFE_REPORT_PATH` 가드가 **쓰기 전에** 죽는 것을 시연했다.
- **read-only 감리도 저장소에 쓴다**: `python3 -B` 없이 임포트하면 `.pyc` 가 남아 프리플라이트를
