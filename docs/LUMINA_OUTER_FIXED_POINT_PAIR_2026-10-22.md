# 같은 외부대기 연산자의 참조장·J4 잔차 쌍 — 2026-10-22

## 결론의 범위

물질70·CMFGEN J71을 고정하고 J4를 생성한 **바로 그 C 바이너리·준비 계수·광선·경계**에
참조 J와 저장 J4를 각각 한 번 입력했다. 이는 두 번의 실제 전주파수 수송 F이며,
새 자기일관 장이나 SE/RE 계산은 아니다. 참조 J는 원래90점에서 자체89셀 산술 반경
중심과 외부 보조점0·14로 옮긴 뒤, 동일한 전1,115,020ν에 log(ν)-선형 보간했다.
주파수 양 끝점은 일치했고 외삽·바닥값·마스크는 없다. 이 투영은 90점 원장과 같다는
주장이 아니므로 아래에 투영 오차를 별도로 둔다.

셀37의 참조 광자 대역 적분을 분모로 한 잔차는 다음과 같다. 부호 있는 잔차와
절댓값 적분 잔차를 구별한다.

| 파장 | `F(Jref)−Jref` 부호 적분 | `∫|F(Jref)−Jref|` | `∫|F(J4)−J4|` | `∫|F(Jref)−J4|` |
| --- | ---: | ---: | ---: | ---: |
| 100–400Å | −0.352846 | 0.352895 | 3.70e−19 | 5.24e−6 |
| 400–800Å | −0.236797 | 0.240162 | 2.25e−11 | 3.01e−4 |
| 800–1600Å | −0.221760 | 0.223452 | 4.15e−6 | 0.004859 |
| 1600–3000Å | −0.007179 | 0.113751 | 1.33e−4 | 0.005056 |

마지막 대역처럼 부호 적분만 보면 상쇄된다. 별도 `long double` 누적의 명시적
사다리꼴 계산은 셀37·38·88에서 저장 실행 결과를 재현했다. 셀37의 참조→자체→참조
보간 대역 오차는 100–400Å에서 부호 약−1.04e−5/절댓값0.003721,
400–800Å에서 부호1.69e−5/절댓값0.003025다. 전 공간 최대 점값 정규화
재투영 오차0.014314는 별도로 기록한다. 셀37의 참조장 수송 결손0.353은 이
대역 보간 영향보다 훨씬 크다.

J4의 전역 점값 잔차 최대는 참조 최대 J의0.106704(셀8, 약3152Å)다.
따라서 **J4 전체장이 수렴했다는 결론은 금지**한다. 그러나 문제인 셀37 UV에서는
J4가 현행 이산 F의 거의 고정점인 반면 참조 J는 그렇지 않고, F(Jref)도 J4에
가깝다. 이는 **해당 UV 불일치를 같은 P0 연산자의 단순 반복 부족만으로
설명하기 어렵다**는 직접 증거다. F는 외부 총η의 비선형 연장을 포함하므로
선형 수렴식이나 한 번의 잔차를 엄밀한 전방 오차상한으로 바꾸지 않는다.
경계·셀 내부 공간표현·원천함수·주파수/각도 이산화 가운데 어느 항의 기여인지
이 실험만으로 단정하지 않는다.

## 실제 Si/S 생산율 연결

기존 생산 raw PHOT·Milne·준위용해와 같은 실제 C full population을 사용해
전89셀·전1,115,020ν의 광흡수/역재결합률을 읽기 전용으로 계산했다.
기존 CMFGEN 기준 광흡수율은 네 이온·89셀에서 **최대 상대차0으로 재현**했고,
C full population 직접 소비의 절대·상대차도0이었다. 다음은 셀37의
광흡수율/같은 생산식의 CMFGEN J 기준 광흡수율이다.

| 이온 | J4 | `F(Jref)` | `F(J4)` |
| --- | ---: | ---: | ---: |
| Si II | 0.873989 | 0.880263 | 0.875305 |
| Si III | 0.865335 | 0.867614 | 0.865616 |
| S II | 0.710992 | 0.713089 | 0.711541 |
| S III | 0.737935 | 0.738427 | 0.738036 |

네 이온 모두 `F(Jref)`조차 참조 광흡수율에 도달하지 못한다. 특히 S II의
참조/J4/`F(Jref)` 광흡수율은 각각194634.19/138383.32/138791.47cm⁻³s⁻¹이다.
같은 셀 S II의 역재결합률은 각각132765.25/132712.47/132777.25cm⁻³s⁻¹로
훨씬 덜 변한다. 이는 고정 인구에서 광흡수 쪽 불균형을 보여주지만,
준위별 SE 항 전체·전자밀도·온도·이온분포를 새로 풀었다는 뜻은 아니다.
전 셀에서 `F(Jref)`와 J4의 광흡수율 비율 차이 최대는 Si II0.02385(셀9),
Si III0.01557(셀8), S II0.01884(셀9), S III0.00444(셀8)이다.
따라서 두 장이 **모든 위치에서** 같다고 확대하지 않는다.
