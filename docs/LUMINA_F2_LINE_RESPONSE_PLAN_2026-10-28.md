# F2 고정장 선 적분의 이온분포 영향

## 목적과 접근

선 잔차 변화와 이온분포 변화는 같지 않다. F2의 완료 장·수용 물질·최종
전자밀도에서 먼저 저장된 F2 이온분포를 단일 원소·단일점 정상해로 재현한
뒤, 같은 BF·충돌·물질 조건에서 선 적분만 점표본 방식으로 교체해 정상해를
다시 구한다. S 34점과 Si 31점이 대상이다. 이 비교는 새로운 수송이나
전하·온도 재수렴이 아니며 두 선 적분법 중 어느 쪽이 물리적 진실인지
판정하지 않는다. 원 CMFGEN의 별도 정수 선구간을 F2 격자에 이식하지 않는다.

F2의 선택 평가에서는 bound BF만 저장되어 있으므로 재현에 필요한 pseudo
BF 및 미저장 직접 계산 경로를 같은 물질·복사장에서 재생산해야 한다.
전체 90점 재계산 대신 단일점의 율만 구성한다. 원 격자의 BF 결과를 새 장에
섞거나 pseudo를 0으로 가정하지 않는다. 재생산한 기존 선 적분 후보가 저장
F2 후보를 재현하지 못하면 교체 결과를 물리 판정에 사용하지 않는다.
F2 원본과 다른 작업은 보존하며, 서로 다른 점/원소는 각각 별도 실행
디렉터리에서 수행한다. 실행 장소·자원·시간은 실제 단일점 비용을 먼저
확인하여 정하고, 성급한 짧은 제한으로 동일 계산을 반복하지 않는다.

## 실행과 결과

F2 최종 평가에는 준위 인구·occupation·FL/SL 분율은 있으나 재인수 후의
전체 BF total 배열은 저장되지 않았다. 단일점에서 같은 캐시 재인수와
pseudo 재적분을 수행해 bound 24,426개 경로를 재사용하고 241개를 직접
계산했다. 예비 재구성은 약 37초였으며 각 단일점은 Lageunha CPU1·4GiB·
180초 상한으로 실행했다. 재구성 BF는 각 결과 디렉터리에 보존했다.

첫 S 시도 `lumina_f2_s34_line_response_20261028-rBVBhJ`는 후보 출력의
메모리 배치 오류로 정상해 전에 실패했다. 배열 배치를 수정한 후 새
디렉터리 `lumina_f2_s34_line_response_fix_20261028-dFknmW`에서 재실행했다.
Si는 `lumina_f2_si31_line_response_20261028-GxzxTo`에서 실행했다. 각 점의
기존 F2 선율 정상해는 저장 F2 인구를 모든 비교 성분에서 정확히 재현했다.

| 위치·이온 | F2 선형 선율 | 같은 F2 점표본 선율 | 차이 |
|---|---:|---:|---:|
| 34점 S III | 0.5138678264 | 0.5143624065 | +0.0004945801 |
| 31점 Si III | 0.1882244440 | 0.1881037494 | -0.0001206946 |

초준위 최대 상대 변화는 각각 약 2.12%, 0.334%였다. 두 선율 정상해의
성분별 잔차는 모두 1e-16 이하이며, 이는 해당 고정 T/ne/J 선형계에 대한
수치 결과다. 이온화 분포에서 선 적분법의 차이는 기존 CMFGEN70 대비 F2
최대 차이 S III 약 0.0319, Si III 약 0.0188보다 작지만, 두 비교는
원70 미수렴 참조와 F2 자체장이라는 서로 다른 조건을 포함하므로 원인의
크기를 엄밀히 분해하는 것은 아니다. 선형 보간과 점표본은 같은 nodal J에
의존하므로 선 내부 실제 복사장의 해상 여부도 판정하지 못한다. 전하·RE·
자체장·스펙트럼 공동 목표는 미달성이다.
