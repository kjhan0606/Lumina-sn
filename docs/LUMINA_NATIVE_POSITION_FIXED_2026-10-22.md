# 동일 native 반경의 Lumina–CMFGEN 고정장 비교 — 2026-10-22

## 목적과 판정 경계

기존 `F/Jref`는 Lumina 셀중심 F와 CMFGEN native 끝점 J의 평균을
비교했다. 이번 진단은 물질70·CMFGEN J71, 원 전체 주파수
`1,115,020`점, 원자/물질·외부대기·내부 경계·고정 J를 유지하면서
Lumina F의 **출력 관측점 두 개만** CMFGEN native 반경에 놓는다.
셸39의 native49/50을 먼저 대조한다. 두 코드의 각도·주파수
연산자까지 동일하다는 보증은 아니며, SE/RE·새 이온화 분포·스펙트럼
계산이 아니다. 전체 최종 목표는 계속 `active/NOT_MET`다.

기존 `NativeSpatialGeometry`의 마지막 두 출력 표본은 외부 참조
반경이었다. 이번 선택적 경로는 이 **출력 위치**를 대상 native 두
반경으로 바꾼다. 고정 `own_j`의 마지막 두 **입력 행**은 원래
`reference_indices`로 보존되어 외부 산란 source가 바뀌지 않는다.
원래 ray impact 집합도 유지하고 대상 두 impact만 추가한다. 따라서
나머지 셀중심 F가 미세하게 바뀔 수 있으며 이전 `native-4` F와
셀37/39 대역값을 직접 비교해 관측 격자 섭동을 함께 기록한다.

## 직접시험과 실행

`tests/test_lumina_outer_native_spatial.py`의 Lageunha CPU2 직접시험
**5통과/11.36초**. 기본 reference 두 관측점 선택 시 기존 계획과
출력이 완전히 같고, 다른 native 반경을 선택해도 C 고정장 호출이
유한·비음수 결과를 반환함을 확인했다. 실제 원자료의 일치를 뜻하지
않는다.

셸39 새 root는
`/gpfs/kjhan/cmfgen_runs/lumina_native_position39_20261022-Snv5iR`.
Lageunha 수동 CPU16/GPU0·메모리 계획64GiB·벽 최대3600초·고정장
F 단회·자동재시도0으로 시작했다. 기존 `native-4` 수송과 같은
봉인 C 라이브러리를 재사용하며, 원 Jref·계수·CMFGEN formal의
해시를 실행 전에 확인한다. 완료되면 root의 `execution.json`에
실제 F 호출수·시간·RSS·원소스/입력 해시, native 위치의 CMFGEN
J 대비 F, 셀중심 섭동을 기록한다. 기존 원본과 이전 출력은
수정하거나 중복 계산하지 않는다.

재현 실행 형식은 원 프로젝트에서 Lageunha CPU16 환경의
`PYTHONPATH=scripts python3 -B scripts/diagnose_lumina_native_position.py
--out-root <새 빈 root> --shell 39`이다. 이 명령은 **새 F 한 회**를
수행하므로 종료 결과의 단순 검증 명령으로 자동 실행하지 않는다.

## 셀39 실제 결과와 미결 원인

F는 **1/1 완료**, 벽`1262.10`초, 최대RSS`23043456KiB`, 실제16스레드였다.
완료 기록 `execution.json` SHA256
`84f279b15f5970d6d27945fb530e18173fec1857f536fda62750d5ec1df51dec`.
결과 파일 `F-native-positions.npy` SHA256
`57be9661cc05fa3d08a3b2f58f520b5845c272a0cd458ea3f66991995ba79ec4`,
동일 위치 CMFGEN J 투영 `CMFGEN-native-J.npy` SHA256
`1c98e5e86d1bf9e66b68d9f2a5abded70f67a60a6c2458147ffd6c9d8a078437`를
독립 `sha256sum`으로 확인했다. 새 관측 ray 구간은`94664`, 기존
`native-4`의`92984`보다1.81% 많다.

기존 셀37 중심 F의 위 네 대역 새/기존 비는 모두 표시 정밀도에서1이다.
세분 재적분의 1400–1500Å는 바깥/안쪽`1.08695/0.94175`다.
따라서 얇은 Si 대역의 중간 source 대비 약50% F 비를 실제 CMFGEN J
대비 약50% 부족으로 옮겨 적을 수 없다. 반면 같은 위치라고 해서
전 대역 일치도 아니다. 원 기준의 전역 p95·광흡수율/개체수/스펙트럼
수용은 미판정이다.

100–400Å 바깥 노드의 큰`1.817`은 물리 오차로 즉시 판정하지 않는다.
여기의 한 셀 radial 광학깊이 중앙값은 약`9327`, 400–800Å도 약`91.5`다.
이 C native-spatial 경로는 각 소구간 **중앙**에서 선형 native χ/η를
고정해 formal 적분한 뒤 구간 **끝**에서 강도를 관측한다. 두꺼운
구간에서 끝 강도는 정확한 끝점 source보다 마지막 소구간의 계수
표본 위치에 민감하다. 셀중심 F 섭동은 작아 추가 impact ray만으로
바깥 노드`1.817`을 설명하기 어렵다.

같은 formal 원계수의 총방출률 `η_true+χ_es J_source`와 χ에서,
node 자신의 source 및 인접 셀 쪽 **node에7/8·이웃에1/8**을 준
계수비 source를 독립 CPU1 판독했다. 이는 중앙 광선의 마지막
1/8 radial 구간의 중앙 계수 대리값이며 전체 ray J가 아니다.
모두 해당 native node의 실제 CMFGEN J 광자 적분으로 정규화했다.

네 관측 F/J는 각각 두 이웃 소구간 source/J 사이에 있다.
이 값만으로 정확한 angular 기여율이나 구현 오류 비중을 증명하지
않지만, **두꺼운 node 표본의 큰 잔차를 물리 방정식 차이로 곧바로
해석할 수 없다는 직접 근거**다. 이 때문에 셀37의 동일 표본
재실행은 보류한다. 다음에는 실제 CMFGEN 셀중심 J 또는 동일
formal 연산자의 중심 ray 평가가 필요하다.
