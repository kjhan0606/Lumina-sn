# 단 사전등록 — TOOL-BYTEPAR: 진짜 byte 비교기 (2026-08-18)

계약 1개: **두 런 산출물의 byte-parity 를, 필터·정렬·다중집합 비교로는 만족시킬 수 없는
강도로 판정하는 비교기를 만든다.** 물리 변조 0. 이것은 물리 단이 아니라 **잣대 단**이다.

## 왜 — 08-08 의 두 실패가 이 도구의 부재에서 나왔다

| 요구 | 그때 답한 것 | 결과 |
|---|---|---|
| DET-R6 **R6-4** "MC 팔 바이트-parity" | **필터된 로그 줄** 비교 | 감사가 강등 |
| SH-GAMMA **Γ2-b** "byte-동일" | **순서·위치를 버린 다중집합** 비교 | 감사가 강등 |

두 경우 모두 "차이 없음" 이 나왔으나, 그 비교는 **값이 바뀌어도 통과할 수 있는 비교**였다.
⟹ 도구가 없으면 사람은 통과하는 비교를 고른다. 도구를 먼저 만든다.

소비자: **R6-4 · E4**(직접), **ME2**(스펙트럼 대조), 이후 모든 회귀 단.

## 실측 — 비교 대상의 지형 (2026-08-18 확인)

값 산출물은 **순수 수치 CSV** 이고 타임스탬프·경로·PID·호스트명이 **없다**:

```
lumina_spectrum.csv        wavelength_angstrom,flux
lumina_ion_pops.csv        shell_id,Z,stage,n_ion
lumina_plasma_state.csv    shell_id,W,T_rad
nlte_levels_iter000.csv    Z,ion,shell,level_idx,global_idx,E_eV,g,n_pop
```
⟹ **값 파일은 정규화 없이 원시 byte 비교가 가능하다.** 로그(`stdout/stderr`)만 휘발 필드를
가지므로, 두 계층을 **구조적으로 분리**한다 — 이것이 08-08 실패의 근본 처방이다.

## 설계 — 2계층

### Tier 1 · VALUE (이것이 게이트다)

- 선언된 값 파일 목록을 **파싱 없이 byte 대 byte** 비교
- 정규화 **0**. 예외 없음
- 산출: 파일별 `sha256`(양쪽) · 크기(양쪽) · 동일/상이
- 상이 시 **최초 차이 offset** + 그 지점 hexdump ±32B + (텍스트면) 줄·열 번호 + 양쪽 원문
- **fail-closed**: 한쪽에만 있는 파일 = FAIL(건너뛰기 금지) · 크기 불일치 = FAIL ·
  읽기 실패 = FAIL · **비교한 파일이 0개면 FAIL**(공허한 PASS 금지)

### Tier 2 · LOG (보조, 감사되는 정규화)

- 정규화 규칙은 **이름을 가지고 선언**되며, 각 규칙은 정규식 + **선언된 적용 범위**를 갖는다
- **정규화 census 의무**: 규칙별로 양쪽에서 몇 줄·몇 바이트를 건드렸는지 보고서에 싣는다
- 정규화 후 비교는 **순서 보존 줄 단위**. **정렬·다중집합·집합 비교 금지**
- 최초 상이 줄 번호 + 양쪽 원문(정규화 전·후 모두)
- ★**은폐 방지 가드**: 어떤 규칙이 치환한 영역 안에 **물리 수치로 파싱되는 토큰**이
  그 규칙의 whitelist 밖에 있으면 **FAIL CLOSED**. 정규화가 값 변화를 삼키는 것을 막는다

## 음성 대조 (내장 selftest — 이 도구의 자격 조건)

게이트는 주입 결함으로 FAIL 을 시연해야 PASS 자격이 있다. 아래 **8종 전부** 필수.

| # | 주입 | 기대 |
|---|---|---|
| **P** | 동일한 두 파일 | PASS |
| **B1** | 값 파일의 **1 바이트** 반전 | FAIL + **정확한 offset** 보고 |
| **B2** | CSV 수치의 **마지막 자리 1 ulp** 변경 | FAIL |
| **B3** | ★**같은 줄 다중집합, 순서만 뒤바꿈** | **FAIL** ← Γ2-b 실패 모드 |
| **B4** | 한 줄을 **삭제**(필터된 비교면 통과할 형태) | **FAIL** ← R6-4 실패 모드 |
| **B5** | 정규화 규칙이 **물리 수치를 삼키도록** 범위를 넓힘 | **FAIL CLOSED**(은폐 방지 가드) |
| **B6** | 비교 파일 목록이 **빈 목록** | **FAIL**(공허한 PASS 금지) |
| **B7** | 한쪽에만 파일 존재 | FAIL |

★B3·B4 가 이 도구의 존재 이유다. 이 둘을 통과시키는 비교기는 08-08 을 반복한다.
