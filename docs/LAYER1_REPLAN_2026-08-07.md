## 0. 왜 목록을 새로 쓰는가

구 1층 목록은 **독립도**(위상정렬)로 정렬돼 있었다 — 판정의 *신뢰도*를 위한 순서다.
그러나 1층 착수 즉시 막혔고, 원인은 판정 신뢰도가 아니라 **물리가 서 있지 않다**는 것이었다.

실측(Codex A): 반복 0 에서 **`ABSENT` 7건 · 끊긴 간선 6건.**
판정(Fable): 실행 불능의 근원은 설계 공백이 아니라 **절단**이다 —
주석이 선언한 LTE-Saha 부트스트랩(`lumina_plasma.c:2347`)을
`(void)phi_neb` + `POP_BF_STALE`(2646-2650)이 잘랐다.
그 사망 지점(`lumina_main.c:263-265`)은 pure-CMFGEN 분기(:346)보다 **앞**이므로
**결정론 팔도 같은 자리에서 함께 죽는다** — 즉 CPU 전 구성이 첫 수송에 도달하지 못한다.

⟹ 순서를 **물리 의존 사슬**로 바꾼다. 각 단이 끝나면 **실행 가능한 물리가 한 조각 늘어난다.**

## 0.1 이월 자산 (0층 = 확보된 것. 폐기 대상 아님)

계약 10건(C2-EXEC · H-TRANSFORM · GEN-GUARD · K-SHAPE · **K-FRESH** · Z-INERT ·
D-BUILD · TE-DEAD · A2-00 · CONFIG-PREC)은 음성대조로 FAIL 을 시연한 뒤 얻은 자산이다.
Fable 이 추가로 이월 판정한 것:

| 이월 | 근거 |
|---|---|
| canonical radiation-field owner (세대·provenance·validity·q-set hash) | 2-arm 합류의 기반 |
| population transaction 원자성 (begin/commit/rollback) | 부분 발행 차단 |
| A2-08/09 signed publication + **A2-10 동세대 계약의 내용** | 계약은 옳고 **위상만 틀렸다** |
| 결정론 팔 전체 (assemble→ALI→commit) + 해석적 극한 자가검사 | 완결 구현 |
| rate-SE 폐합 기계 (canonical view Γ 직적분, Seaton+3-body) | A-2 캠페인 산물 |
| log-sum-exp 이온 사다리 · K-FRESH 개념 · seed-T_e 1회 발행 계약 | 캡으로 "수리"하지 않고 정확해로 푼 사례 |

**계약을 깎지 않는다.** 틀린 것은 계약이 아니라 **위상(순서)과 절단**이다.

## 1. 1층 단계 (이 순서로 한다)

### L1-1. 반복 0 물질 공급자 복원 — *물질 상태가 선다*

절단(`lumina_plasma.c:2643-2650`)을 폐합한다. seed-T_e LTE Saha 를
**provenance 스탬프를 단 선언적 반복 0 공급자**로 세운다.
루프 중 fail-closed 계약은 **그대로 둔다** — 부트스트랩 1 회로 범위를 못박는다
(반복 ≥1 에서 장이 깨졌을 때 LTE 로 조용히 미끄러지면 결함 은폐다).

- 얻는 것: `ABSENT` 7건 중 **4건 연쇄 해소**(Z · n_e/ion · LTE levels · tau),
  K-FRESH 가 살아나고 **두 팔 모두** 처음으로 첫 수송에 도달.
- 함께 폐기: `(void)phi_neb` 뒤의 사문 사슬(zeta 보간 · ML 보정 · twocomp lock ·
  `OUTER_ION_BOOST`) — 생산 경로에서 결과 무영향인 shadow 다.
- 함께 폐기: 주석 화석 `2347` "LTE-Saha pin fallback" (코드와 반대를 선언해
  판독자를 두 번 속였다).
- 게이트: 주입 결함으로 FAIL 시연 후 PASS. 반복 0 공급자가 **1 회만** 발화하는지.

### L1-2. 세대 장부의 위상 정합 — *반복이 돈다*

A2-10 동세대 계약(`11987-11992`)은 **옳은 물리**인데 루프 발행 순서
(commit→T_e→발행)가 원리적으로 충족 불능이다. 발행(a208/a209)을
**field commit 직후 · T_e 호출 전**으로 옮긴다. 비적격 시 `T_e_generation = 0` 화
(`lumina_main.c:645-649`, 바로 위 주석 "Preserve the committed material temperature" 와 모순)
를 없애고 커밋된 세대를 보존한다.

- 얻는 것: **iter ≥ 1 이 전 구성에서 죽던 두 번째 사망 지점 해소** — 열 물리가 처음 완주.
- 함께 폐기: 주석 화석 `main.c:646` "Preserve".
- ⚠ **계약을 깎아 통과시키지 않는다.** 위상을 맞춘다.

### L1-3. 결정론 부트스트랩 + 두 팔 합류 — *잡음 없는 장 위에서 돈다*

★운전석 가설은 **전제가 기각**됐다: "LTE start 가 필요한 것은 MC 전용이라서" 는 틀렸다.
어떤 수송이든(MC든 formal 이든) 입력으로 opacity/source 를 요구하고 그것은 population 을
요구한다 — 인과 순서의 문제이지 잡음의 문제가 아니다.
**결론은 고리를 하나 늘리면 성립**한다:

```
seed T_e → LTE(Saha) 물질 상태 → solver-owned tau/χ → 결정론 formal solve
        → 무잡음 J_nu (generation 1) → rate-SE/NLTE 통계평형 → (MC 팔 합류)
```

즉 결정론 팔이 대체하는 것은 **LTE start 가 아니라 ARTIS 의 "LTE 시대"**
(`num_lte_timesteps` 동안의 잡음 낀 초기 MC 수송)다. LTE 는 *기간*에서 *순간*(상태-0 한 번)이 된다.
**이것은 ARTIS 모사가 아니라 CMFGEN 자신의 구조다.**

최소 조건(방향): ① 세대 단일 장부 — 루프 인덱스(`iter+1` 하드코딩) 대신 owner 의 computed+1
② pure lane 에 a209 emissivity 발행 신설 ③ 동일 q-set hash·profile identity 의 **결정론 line-J̄**
(없으면 SE 가 `POP_BB_STALE`).

- 얻는 것: 두 팔이 **한 런에서 동시에** 돌고, 논문 Fig.1 의 "두 장의 일치 = 진단" 이
  처음으로 **계측 가능**해진다.
- 현 상태 실측: 2-arm 은 **미구현(스위치 구조)** — 두 팔 다 완결이고 같은 canonical 계약에
  발행하지만(`MC_PATH_LENGTH` vs `CMFGEN_REPLAY`) env 로 **상호배타** 실행이며,
  한 런에서 두 장을 비교하는 진단은 **0건**. 비교 인터페이스는 이미 있어 합류 비용은 낮다.

### L1-4. 계측 배선도 재작성 — *잣대가 선다*

현 계측은 전부 **단일팔** 신선도·세대 게이트다. L1-3 이 서면 계측의 정점이
"게이트 나열"에서 **동세대 J^MC vs J^det 어긋남 지도**(양 × 위치 × 크기; 셸 × 대역)로 바뀐다.
이것이 보고 규약(CMFGEN 어긋남 지도)과 같은 형식이다.

- 함께 처분: 단일팔 게이트 중 두 팔 진단으로 대체되는 것을 정리(삭제가 아니라 **재배치**).

### L1-5. 물질 입력의 물리화 — *시작 상태가 물리가 된다*

L1-1~3 은 사슬을 세운다. 이 단은 **사슬에 들어가는 값**을 물리로 만든다.

| 항목 | 현 판정 | 할 일 |
|---|---|---|
| 초기 `T_e` = `T_inner` 전 셸 복제 (`lumina_atomic.c:1058-1061`) | **NON-PHYSICAL**(프로파일로서) | 균질 팽창 외피에서 외곽이 내부 경계온도와 같을 수 없다. 덱 `plasma_state.csv` witness 와의 관계를 일관되게 |
| top-ion `Z=1` 임시 대입 (`population_contract.c:105`) | **NON-PHYSICAL**(격리된 부채) | 최상단 15 이온의 바닥 g 를 외부 앵커로 도입 — ARTIS 는 준위 1개(U=g₀)를 준다 |
| 덱 `transition_probabilities.npy` 상시 기본 | **NON-PHYSICAL**(기본값으로서) | K-FRESH 인식론(덱은 seed 일 뿐)과 모순 — solver 소유로 |
| n_e 5% 문턱 (`2793-2800`) | 감쇠는 PHYSICAL / **5% 선언은 NON-PHYSICAL** | 전하보존 잔차를 장부화하기 전까지 신뢰 불가 |
| `solve_radiation_field`·`coupled_*` 무연산 스텁 | **NON-PHYSICAL**(화석) | 호출부와 함께 폐기 |

### L1-6. 입력축 감사 재개 — *이제 판정이 가능하다*

구 목록의 입력축 항목(R-4 22 이온 소스 앵커링 · R-6 `r≥1` 76 lines · I2c Co IV A_ul ·
I3 잔여 이온 값 대조 · 공유맹점 외부 앵커)은 **작동하는 런 위에서만** 판정할 수 있다.
따라서 여기로 내린다 — 폐기가 아니라 **순서 이동**이다.

## 2. 상위층 재작성

구 상위층 항목은 **지금의(틀린) 배선을 전제로** 쓰여 있으므로 그대로 두지 않는다.

### 2층(사실만) — 재작성

구 2층은 "돌지 않는 코드"에서 뽑은 사실이다. 상당수가 무효다.
L1-2 완료 후 **런이 실제로 낸 값**으로 다시 채운다.
⚠ 특히 회귀 대장 `gate_set`(111 항목)은 **죽은 노브 1,384건**과 겹치므로
"그 A/B 당시에도 죽어 있었는가"를 git 고고학으로 가르기 전에는 재해석하지 않는다.

### 3층(고리 얽힘) — ★전제가 바뀐다

캠페인의 원 논거는 *"닫힌 고리에서 역추적은 원리적으로 순환하므로,
고리가 소비하되 생산하지 않는 것을 감사한다"* 였다.

그런데 **두 팔의 일치는 고리 안에서 얻어지는 독립 잣대**다 —
MC 와 결정론이 **같은 물리를 다른 방법으로** 풀기 때문이다.
L1-3 이 서면 3층의 성격이 바뀐다: 고리 얽힘 항목 중 상당수가
"어긋남 지도" 로 **직접 판정 가능**해진다.

⟹ 3층은 L1-3 완료 후에 재작성한다. 지금 쓰면 없는 잣대를 전제로 쓰게 된다.

## 4. 규율 (이 재작성에도 그대로)

- 단 하나 = 물리 계약 하나. 게이트 PASS 시점 = 커밋 시점.
- 음성 대조 의무: 주입 결함으로 FAIL 을 시연해야 PASS 자격.
- 클램프·floor 금지. 계약을 깎아 통과시키지 않는다 — **위상을 맞춘다**.
- offline-first: 기전 오프라인 특정 → 수리안 오프라인 검증 → 기대치 사전등록 → 판정런 1회.
- 노브를 늘리지 않는다. 부트스트랩은 **선언적 1회 공급자**이지 스위치가 아니다.
