# 새 복사장 물질응답에 기존 T/ne 보정 연결

## 목표·범위

Astra 자문에 따라 국소 진단을 늘리기보다 기존 전원소 열·전하/SE 블록을
새 자체장 소비 경로에 연결한다. 최종 목표는 같은 물질·장 상태의 공동
수렴과 CMFGEN 물리량·스펙트럼 비교다. 이번 구현의 산출물은 그 중 고정
새 장에서 전90점 T/ne를 갱신할 수 있는 실제 callback 연결이며, 수송을
자동 실행하거나 국소 온도 기울기를 전역 보정값으로 대입하지 않는다.

## 기존 입력과 구현

기존 F2·원자자료·이전 실행 결과는 변경하지 않는다. 기본 고정온도 경로를
유지하고 명시적인 `--temperature-evaluations 5..12`를 선택한 경우만 기존
`lumina_coupled_material.solve_coupled`를 재사용한다. 실제 평가 callback은
기존 `ModelResponse.evaluate(T, ne)`와 `ResponseBalance.evaluate`를 함께
소비한다. 바뀐 온도에서는 기존 생산자가 전 BF를 다시 적분하고, 깊이
단열항도 같은 전체 프로필에서 다시 계산한다. 새 수식·열원·물리적 바닥값을
도입하지 않는다. 감쇠·보폭·후보 수용은 기존 해법이 소유한다.

모든 후보의 물질·열장부는 기존 실행 디렉터리 규칙으로 보존하고, 실제
수용된 후보의 인구/T/ne와 기록을 출력한다. 거부 또는 평가 한도 소진은
기존 수용 상태를 유지한다. 내부 고정장 수치 수렴과 전하 잔차를 보고하되,
열평형·수송/산란·최종 공동수렴 또는 CMFGEN 일치로 승격하지 않는다.

## 확인·자원·보존

운전자가 구현과 직접시험을 담당한다. 합성 callback으로 실제 기존 감쇠
해법의 root 도달, 요청 T/ne 소비, 후보 거부 시 원 payload 보존, 평가 한도와
고정장/공동수렴 구분을 확인한다. 기존 새 장·coupled·전하 투영·율 회귀도
함께 실행한다. Lageunha CPU1·4GiB·외부150초, GPU0·새 물리 수송0이다.
전역 T/ne 생산 실행은 기존 단회 예산을 자동 재사용하지 않는다. 새 온도의
여러 BF 전적분 비용을 반영한 별도 실행 범위·시간·횟수가 필요하다.

재현 명령은 `python -m pytest -q tests/test_lumina_fixed_field_thermal.py
tests/test_lumina_new_field_response.py tests/test_lumina_coupled_material.py
tests/test_lumina_charge_projection.py tests/test_model_material_rates.py`다.
기존 실행 원본과 기본 경로는 보존하며 선택 기능의 소스만 되돌릴 수 있다.

## 구현·직접시험 결과

Lageunha의 실제 소형 시험은 **53 passed / 6.23초**였다. CLI import와
새 선택 인수의 노출을 확인했다. 바뀐 T의 전체 BF 재적분 횟수는 완료
평가마다 더하고, 새 온도 후보와 기존 수송 모멘트의 물질 상태가 다름을
출력에 명시한다. 후보 거부 시 초기 결과의 정확한 객체를 유지하는 시험과
잘못된 callback T/ne 및 예산의 사전 거부 시험도 통과했다.

실제 F2의 전90점 released-T 계산, 새 산란 수송, 최종 스펙트럼은
실행하지 않았다. 합성 root 통과를 물리 root 증거로 사용하지 않는다.
다음 실제 실행을 준비할 때에는 이미 완료한 F2의 기준 BF/BB/FF·열장부를
검증해 재사용할 수 있는지 먼저 확인하고, 여러 온도 전적분 비용을 포함한
시간·평가 횟수·실행 위치를 정한다. 이 연결 코드만으로 기존 단회 실행
권한을 다시 소비하거나 새 F3 수송을 시작하지 않는다.
