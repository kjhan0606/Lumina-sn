# F6 — rung 1의 ε와 production의 ε가 서로 다른 양이다

발견: 2026-08-03, 운전석 감사(v2 패치 정독 중). 상태: **사실 확정 / 처분 미결**.
이것은 F5(누적에서 ε 누락)와 **별개의, 더 상위** 문제다. F5는 구현 결함이고
이것은 **정의 결함 가능성**이다.

## 사실

production이 조립에 쓰는 ε (`src/lumina_plasma.c:8471-8472`):

```c
double C_ul  = n_e * rl->coeff / ((double)rl->g_up * sqrt(T_e));
double denom = C_ul + rl->A_ul * radeq_beta_esc(tau);
return (denom > 0.0) ? C_ul / denom : 1.0;
```

즉 **ε′ = C/(C + A·β)**. `radeq_beta_esc(tau) = (1−e^{−τ})/τ`는 Sobolev 탈출확률이다
(`src/lumina_plasma.c` 동 함수).

v2 패치가 rung 1 행에 기록하는 ε (`radeq_line_local_response`, patch v2 :104-135):

```c
/* eps0 = C/(C+A) */
```

즉 **ε₀ = C/(C + A)**. manifest도 `"eps_l_definition": "C_ul/(C_ul+A_ul) raw"`로
그렇게 선언한다(patch v2 :378).

그리고 같은 행이 `λ* = 1 − β`, `ρ_local = (1 − ε₀)·λ*`를 기록한다(patch v2 :247-248).

**β가 ε′ 안에도 있고 λ* 안에도 있다.** 두 정의는 정확히 β만큼 다르다.

## 크기 — 하필 사전등록 대역에서 최대

사전등록 판독은 `tau >= 100` 에너지의 90% 이상과 가중 중앙값 `rho_local ∈ [0.99, 1.0)`다.
τ = 100이면 β = 0.01이므로 두 정의의 차이가 최대로 벌어진다. A/C = 100인 선을 예로 들면

| 정의 | ε | ρ = (1−ε)(1−β) |
|---|---|---|
| ε₀ = C/(C+A) (패치) | 0.0099 | **0.980** |
| ε′ = C/(C+Aβ) (production) | 0.5 | **0.495** |

τ가 클수록 β→0이라 ε′→1, ρ′→0이고 ε₀는 τ와 무관하다. 즉 **사전등록 구간
[0.99, 1.0)은 ε₀ 정의에서만 도달 가능하고 ε′ 정의에서는 구조적으로 도달 불가**다.
정의 선택이 rung의 판정을 사실상 결정한다.

## 두 가지 독법 — 아직 판정하지 않는다

**독법 A (패치가 옳다).** 2-준위 ALI의 `S = (1−ε)J̄ + εB`에서 ε는 산란 1회당
소멸확률이어야 하고, 탈출·트래핑은 Λ(즉 λ* = 1−β)가 담당한다. ε′를 쓰면 β를
두 번 세는 셈이다. 이 독법이 맞으면 **production의 방출률 분해가 β를 이중계상**하고
있고, 그것은 UV 문제에 직결된다 — ε_eff가 곧 재순환 이득 1/ε의 분모이기 때문이다.

**독법 B (production이 옳다).** production의 χ_line은 팽창 불투명도
`w = (1−e^{−τ})·ν/(c·t·Δν)`를 통해 이미 τβ를 품고 있고, 수송은 Sobolev β가 아니라
완전 formal solution을 푼다. 이 경우 ε′는 이중계상이 아니라 다른 분해에 맞는 짝이며,
그렇다면 **λ* = 1−β를 그 위에 얹은 rung 1의 ρ 정의가 틀린 짝**이다.

어느 쪽인지는 손으로 판단할 문제가 아니라 유도로 결정할 문제다. 지금 확정된 것은
**두 양이 다르다는 사실과 그 차이가 판정 대역에서 최대라는 것**뿐이다.

## 처분 요구

1. **rung 1 실행 전에 판정해야 한다.** 정의를 정하지 않고 재면 나온 수치가 무엇의
   spectral radius인지 말할 수 없다. 사전등록 구간은 정의에 종속이므로 지금 상태로는
   "사전등록 통과"가 의미를 갖지 못한다.
2. 어느 쪽으로 결정하든 **행이 두 ε를 모두 실어야 한다** — 원시 ε₀, production이
   실제 적용한 값(`eps_floor`/`eps_cap` 적용 후), 그리고 β. 그래야 사후에 두 독법을
   같은 payload에서 비교할 수 있다. 현재 행 스키마에는 ε₀뿐이다.
3. 부수 발견: production은 `eps_floor=1e-5`, `eps_cap=1.0`으로 ε를 자르는데
   (`src/lumina_cmfgen.c:795-797`) rung 1 행은 자르기 전 값이다. 몇 행이 floor에
   걸리는지 payload로 알 수 없다. 클램프 대장에 추가 대상.
4. 독법 A가 맞을 경우 **production 쪽 수리**가 되고, 이는 읽기 전용 1단의 범위를
   넘는다. 별도 단으로 분리해야 한다.

## 유도 판정 (2026-08-03, 운전석) — 독법 B. 그리고 λ*도 틀린 짝이다.

### ε′는 Sobolev 사다리를 합산한 **순** 열화확률이다

선 l에서 광자가 흡수되면 상준위가 여기된다. 탈여기 1회당

- 충돌 소멸 확률 `p_d = C/(C+A)`
- 복사 재방출 확률 `p_e = A/(C+A)`, 그중 β만 공명영역을 탈출하고 (1−β)는 **같은 셀
  같은 선에서 재흡수**되어 사다리를 한 칸 더 올라간다

국소 사다리를 합산하면

```
P_esc = Σ_{n≥0} [p_e(1−β)]^n · p_e β
      = p_e β / (1 − p_e(1−β))
      = [Aβ/(C+A)] / [1 − A(1−β)/(C+A)]
      = Aβ / (C + Aβ)

P_dest = 1 − P_esc = C / (C + Aβ) = ε′
```

즉 **ε′ = C/(C+Aβ)는 정확히 "선 흡수 1회당 순 열화확률"**이다. production이 임의로
β를 끼워넣은 게 아니라 사다리 합산의 닫힌 형태다.

### 그 ε′와 짝이 맞는 것은 팽창 불투명도다

코드의 선 불투명도는 `w = (1−e^{−τ})·ν/(c·t·Δν) = τβ·ν/(c t Δν)`로 **β를 이미 품고
있다**. 따라서 수송에서 일어나는 bin 수준 상호작용은 **이미 사다리를 마친 사건**이다.
거기에 붙일 소멸확률은 순 값 ε′여야 하고, ε₀ = C/(C+A)를 붙이면 bin 상호작용마다
사다리를 새로 시작하는 것으로 취급해 **열화를 과소계상**한다.

⟹ **독법 B가 맞다. production의 ε′는 옳고, 패치의 ε₀가 이 연산자에 대해 틀린 ε다.**
독법 A가 걱정한 "β 이중계상"은 일어나지 않는다 — β가 χ에 들어간 것과 ε′에 들어간 것은
서로 다른 역할(전자는 bin 유효 불투명도, 후자는 사다리 합산 결과)이다.

### 그런데 λ* = 1−β도 틀린 짝이다 — 더 큰 문제

패치가 반복하는 연산자로 가정한 것은 Sobolev 2-준위 `S=(1−ε)J̄+εB`, `Λ*=1−β`다.
그러나 코드가 실제로 반복하는 것은 그게 아니다(`src/lumina_cmfgen.c:1641`):

```c
cs->chi_es[idx] = chi_e + (chi_ln - chi_ln_th);
```

이고 수송은 `S = S_fixed + (χ_es/χ_tot)·Λ_formal[S]`를 푼다. 반복의 국소
spectral radius는 따라서

```
rho_local = (chi_es/chi_tot) · lambda_star[idx]
```

이고, **두 배열 다 production이 이미 계산해 들고 있다** — `cs->chi_es`(:1641)와
`cs->lambda_star`(:2147, :2179, 실제 formal 연산자의 대각). 여기서 `λ*`는 Sobolev 선
탈출확률이 아니라 **셀·bin 수준 formal 연산자의 대각**이다. 둘은 다른 양이다.

⟹ v2/v3의 `rho = (1−ε₀)(1−β_Sobolev)`는 **코드가 실제로 수행하는 반복의 spectral
radius가 아니다.** ε를 ε′로 바꾸는 것만으로는 고쳐지지 않는다.

### 처분

1. **rung 1의 핵심 측정을 `(chi_es/chi_tot)·lambda_star`로 바꿔야 한다.** production
   배열만으로 계산되므로 `radeq_line_local_response`·log-domain logistic·line2k
   테이블·ε 정의 논쟁이 **전부 불필요해진다**. v3 복잡도의 상당 부분이 사라진다.
2. **사전등록은 폐기하고 다시 써야 한다.** 현 문안은 선별 Sobolev 양에 대한 것이라
   반복의 spectral radius를 재지 않는다. 단, 이것은 결과를 본 뒤 골대를 옮기는 것이
   아니라 **production 측정 이전에 잣대가 다른 연산자를 잰다는 것이 드러나서** 바꾸는
   것이다. 그 구분을 원장에 명시할 것.
3. 선별 view(어느 선이 지배하는가)는 여전히 쓸모 있으니 **보조 산출물로 유지**하되,
   사전등록 예측은 bin 수준 ρ에 걸어라.
4. ε₀/ε′/β를 행에 모두 싣자는 앞의 요구는 유지한다 — 두 독법의 사후 비교와 클램프
   대장(`eps_floor` 적중 수) 때문에 여전히 필요하다.
