# fullSR SC·주파수 sweep — 자체 전주파수장 회복

## 목표와 범위

원 물질70·native90·1115020주파수·107광선·16172물리구간을 유지하여
완전한 자체 J1을 만들고, 다음 자체 산란 응답과 동일 물질의 CMFGEN 대조로
진행한다. 최종 Si II/III·S 분포와 스펙트럼 동질성 목표는 미달이다.
제조 문제의 통과나 전주파수 수송 완결을 물리 동질성으로 대체하지 않는다.

계획 근거는 인수인계서의 Astra
`01a17351-ea0b-7d33-bd32-84c99a64247a` 검토다. 기존 연속 특성선
적분기는 독립 참조용으로 보존한다. 새 경로는 명시적 선택이며 기존 CUDA
수송 수식·적분기·기본 동작을 수정하지 않는다. 운전자가 구현·직접시험·실행을
담당하고, 같은 계획에 대한 별도 정례 감사를 추가하지 않는다.

## 구현과 물리적 한계

기존 `D=gamma(1-beta*mu_lab)`, `dl=D dz`와 원래 광선·관측 사건을
재사용한다. `U=I_nu/nu^3`의 청색 상풍식을 같은 주파수 I 단위로 풀며
청색 상태는 직전 주파수의 **자체 전공간 해**다. 동결 산란 J와 혼동하지
않고 주파수 타일·호출 경계에도 유지한다. 최고주파수는 기존 상수 스펙트럼
연장에 대응하는 일반식으로 풀어 외부의 양의 미소 원천도 보존한다.

공간 조각에서는 평균 유효 opacity와 양 끝점 선형 원천의 양의 SC 가중치를
사용한다. 원 계수의 공간 변화를 무시한 정확해라는 뜻이 아니다. 공간 세분과
주파수 세분을 실제 J·율로 대조해야 한다. signed chi·gain과 chi_eff=0을
허용하며 source/chi 나눗셈·새 floor·clamp를 넣지 않는다. 중간 극소/극대
강도는 기존 scaled Positive로 보존한다. 기존 외부 원천 처방은 바꾸지 않았다.

OpenMP는 서로 독립인 광선만 병렬화한다. 광선별 타일을 고정 순서로 합쳐
스레드 수에 따른 합산 순서 변화를 피한다. 완료된 타일만 모멘트·청색 상태에
반영하며, 실패한 타일의 출력은 발행하지 않는다. 부분 모멘트와 완료 청색
상태를 체크포인트로 남겨 승인된 재개 때 완성 주파수를 다시 계산하지 않는다.
참조 J의 source 주입은 거부하며 J2 입력은 같은 물질의 완성 자체장 계보를
확인한다. 부분장은 완성 J 파일로 발행하지 않는다.

## 직접시험

grammar-debug의 CPU2 이하·외부180초 한도에서 수행했다. 새 시험25개는
모두 통과했다. 독립 Decimal 적분의 signed tau 0/양/음/±1000, 유효
opacity0, 진공의 일정 U, 흡수1200 뒤 gain1200 복원, 미소 원천과 gain,
실패 시 출력 보존, 타일 폭·1/2스레드 동일성, 부분 실패 후 재개, 시간 제한,
core 경계의 독립 상태, 최고주파수 미소 원천, 기존 실제 기하 연결·관측 사건과
새 산란 source 소비를 포함한다. 제조 문제에서 공간 세분 오차의 약1/4 감소와
주파수 세분 오차의 약1/2 감소도 확인했다. 이는 실제 모델의 오차 상계가 아니다.

회귀 명령:

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=2 timeout 180s python3 -m pytest -q \
  tests/test_lumina_fullsr_sc.py tests/test_lumina_linear_native.py \
  tests/test_lumina_compiled_input.py
```

최초 합침 결과는81통과·1skip·1실패/7.26초다. 실패한 기존
`test_compiled_provider_same_material_saved_j_return`은
`LUMINA_COMPILED_SAVED_J` 환경변수 누락으로 시작 전에 종료됐다.
이를 새 수송기의 수치 불일치나 해당 저장장 검증 성공으로 기록하지 않는다.

후속으로 기존 native90 율 어댑터와 새 SC 완료장 연결을 함께 시험해
80개가6.23초에 통과했다. 별도 저장장 시험을 통과한 것으로 바꾸지 않는다.
`compare_lumina_fullsr_sc.py`는 실제 수송 방법과 완성 자체장 계보를 남기고
기존 `lumina_native90_rates.py`의 같은90점 PHOT/Milne 소비자를 호출한다.
원래 있던 해당 율 모듈은 내용 변경 없이 저장소에 보존한다.

## 실행과 보존

GPU는 syntax 클러스터 Slurm, CPU가 많은 계산은 grammar Slurm을 쓴다.
새 계산은 CPU16·32GiB·부모45분·내부2500초·GPU0·자동 재시도0이며
불량 노드 grammar072/078/080을 제외한다. 초기 공간4세분·주파수1세분으로
전격자를 계산하며, 이 결과만으로 수렴 판정을 하지 않는다. 기존 최대3회
CPU 실행 범위 안에서 결과를 보고 후속 계산을 선택한다.

원 봉인 계획 SHA256은
`f3b01d29c798e910fe42427283f1a9697189da45926d0bc4b77961e991909bab`다.
같은 원 계수 제공자 바이너리·geometry·Planck·gradient 신원을 확인한다.
대형 계수 본문은 원 봉인을 계승하고 반복 전체 재해시하지 않는다.
실행기와 로컬 import/include 폐쇄만 새 root에 복사하고 각 파일을 해시한다.
기존 계산 root와 실패 증거는 변경하지 않는다.

재현은 새 root를 대상으로 `stage_lumina_fullsr_sc.py <project> <새-root>`,
grammar의 `run_lumina_fullsr_sc.sh <같은-root>`다. 결과 정본은
`sc-result.json`, 부분 모멘트는 `moments.partial.npy`, 완료 청색 상태는
`blue-<next_frequency>.npy`다. 전격자 검증이 끝난 경우에만 `moments.npy`와
`J.npy`를 내고 각각 SHA256을 기록한다. 다음 자체장·수치 세분 대조·물질
응답·최종 물질의 관측자 스펙트럼은 아직 미완이다.
