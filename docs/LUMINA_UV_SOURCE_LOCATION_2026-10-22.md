# UV 셀 source와 CMFGEN native J의 위치 차이 — 2026-10-22

## 직접 관찰

같은 물질70·CMFGEN J71·전1,115,020ν의 고정 수송에서 셀37의
100–400Å `F/Jref≈0.63`과 셀39의 `≈1.48`을 물리 수송 오류라고
바로 해석했던 비교에는 **서로 다른 반경 표본**이 섞여 있었다.
`Jref`는 CMFGEN의 native 양 끝점 J를 셀 하나에 대응시킨 평균이고,
Lumina 출력은 해당 셀의 중심 물질·광선 표본이다. 셀 내부 χ와 총η가
강하게 변하면 `평균(η/χ)`와 `평균(η)/평균(χ)`는 달라진다.

CMFGEN 실제 formal `χ,η_true,χ_es,J_source,J`를 native 양 끝점에서
읽고, `η_total=η_true+χ_es J_source`로 source를 구성했다. 반경 중간
계수 source는 `(η_total,out+η_total,in)/(χout+χin)`이고, 이를 같은
주파수·광자 가중치로 적분했다. 아래 값은 모두 그 셀의 **native 두 끝점
J 평균 대역 적분**을1로 정규화한 것이다.

| 셀, 100–400Å | 양 끝 source 평균 | 계수 중간 source | Lumina 셀 source | P0-4 F | native-4 F |
| --- | ---: | ---: | ---: | ---: | ---: |
| 37 | 0.999907 | 0.630760 | 0.647029 | 0.647171 | 0.630514 |
| 39 | 0.997927 | 1.476510 | 1.434976 | 1.438210 | 1.479678 |

셀37 native51/52 각각의 실제 CMFGEN `J/source` 대역비는
`1.000036/1.000650`, 셀39 native49/50은 `1.005484/1.001381`이다.
294.017Å에서 같은 물질70의 radial 광학깊이는 셀37 약`21131`,
셀39 약`9496.6`이다. 원 formal `χ`와 `10^10 cm` 단위 반경차를
별도 CPU1 판독으로 직접 재계산한 값은`21130.990018/9496.594045`였다.
따라서 이 매우 두꺼운 UV 조건에서 두 끝점 J는
국소 source를 따른다는 해석이 **두 셀의 실제 자료로** 지지된다.
셀37의 `native-4 F`와 계수 중간 source 차이는 참조 정규화로
`−0.000246`, 셀39는`+0.003168`이다. 큰35–48% 외관 잔차와는
규모가 다르다.

400–800Å 셀37의 중간 source/끝점 J는`0.725579`, native-4 F는
`0.763825`이고, 800–1600Å는`0.760090/0.824468`이다. 이 대역은
같은 국소 source만으로 전체 수송장을 대체할 수 없으므로 UV 한 대역의
정렬을 전주파수 동질성으로 확대하지 않는다. 기존 CMFGEN J의 4점 PCHIP
셀중심 보간은 셀37 EUV에서 끝점 평균의 약`0.81`이었다. 이는 **직접
formal 중심 J가 아니라 보간 대리값**이며, 실제 χ·η의 급변을 반영한
중간 source`0.63`과 다르다. 어느 대리값도 중심 J의 권위 참조가 아니다.

## 동일 생산 PHOT/Milne 광흡수율 — S는 위치 효과가 지배, Si39는 대리 기준 잔여

원 C 전체 인구 `2,184,238`값과 동일 raw PHOT route·Milne·물질70의
네 이온 생산 소비자를 그대로 사용했다. CMFGEN native 계수의 두 끝점에서
`η_true+χ_es J_source`를 구성하고 원 Lumina ν로 보간한 뒤, 100–3000Å
구간에서만 중간계수 source 대리장을 만들었다. 그 밖의 주파수는 원
`Jref`를 유지한다. 이는 **실제 CMFGEN 중심 J가 아니며** 어떤 물리장
채택/SE 해 갱신도 아니다. 기존 Jref/P0/native-4 광흡수율은 이전
생산 결과와 상대`1e-9` 이내로 직접 재현했다.

| 이온 | 셀37 native-4/중심 source 대리율 | 셀39 native-4/중심 source 대리율 |
| --- | ---: | ---: |
| Si II | 0.96898 | 0.80719 |
| Si III | 0.95149 | 0.79871 |
| S II | 0.99416 | 0.99884 |
| S III | 1.04174 | 1.05191 |

S II/III의 기존 셀37 약26–28% 부족과 셀39 S III 약38% 초과는
같은 위치를 대리하는 source 기준에서는 대략0–5% 범위로 줄었다.
이는 두 셀의 *광흡수율 진단*에 한정된다. Si II/III는 특히 셀39에서
약20% 부족이 남아, 위치 효과만으로 네 이온의 모든 차이를 설명할 수
없다.

단, **그 약20%는 원 CMFGEN J에 대한 차이가 아니다.** 같은 생산
적분에서 셀39 `native-4/Jref`는 Si II`0.95717`, Si III`1.00092`,
S II`1.05871`, S III`1.38494`다. 얇은 Si 생산 대역에서 중간 source가
실제 J보다 훨씬 크므로, source 대리 기준으로 바꿀 때 Si의 겉보기
부족이 새로 생긴다. 원 끝점 기준의 Si 셀39은 오히려 근접하지만,
끝점 평균 J도 실제 **셀중심** J가 아니어서 통과 판정은 유보한다.

같은 PHOT 소비자를 네 대역과 나머지로 재적분했으며, 각 대역의 합은
전율과 상대`1e-8` 안에서 일치한다. 셀39의 Si II/III는 CMFGEN `Jref`
광흡수율의`70.39%/74.38%`가 800–1600Å에서 나오고, 바로 그 대역의
`native-4/중간 source 대리율`이`0.7356/0.7322`다. 이 대역 하나가
전체 대리율 잔차에 각각`−0.1997/−0.2095`를 기여한다. 다른 대역의
양의 기여가 일부 상쇄해 전율 잔차는`−0.1928/−0.2013`이다. 반면
셀39 S II의 400–800Å와 800–1600Å 잔차는 각각`+0.0259/−0.0261`로
거의 상쇄되므로 전율 일치만으로 대역별 물리 동질성을 주장할 수 없다.
Si의 **중간 source 대리 기준 잔여**는 100–400Å의 광학적으로 두꺼운
source 위치 효과와 다른 주파수 대역에 있다. 이 잔여가 실제 CMFGEN
중심 J에 대한 오류인지는 아직 확인해야 한다.

## 별도 UV 실제 ray 연산자 확인

보존된 CMFGEN 물질60/index23732 포획은294.017Å의 원 광선과 직전
주파수 blue가 byte 동일하다. 두 셀에 해당하는 native 깊이50→51,
52→53을 양방향 전 angular ray에서, 같은 끝점 χ/η/b/blue·입사 강도로
양의 Bézier SC와 독립 양의 선형물질 formal 적분을 대조했다. 한 셀
교체의 가중 차이 절댓값 합/원 J는 최대`3.045e-5`였다. 중앙ray는 별도
SciPy formal 적분과도 대조했다. 중앙ray의 셀당 이동은 주파수 약41칸이나
물리 광학깊이는 약9천–2만이라, 이 한 위치에서는 주파수 이동량만으로
큰 광자장 차이를 설명하기 어렵다. **포획은 수리 전 물질60/원 legacy
SC이며, 양의 Bézier 값은 같은 입력의 재계산**이다. 현재 물질70의
전체 F 또는 실제 v11 중심 J와 동일하다고 표시하지 않는다.
