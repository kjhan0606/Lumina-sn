같은 보존 출력의 `LINEHEAT`/`NETRATE`를 한 번 순차 대조해 789,775개 선쌍의

`ZNET = 1 + (c^2/(2 h nu^3)) * (1 - n_lower/(g_ratio*n_upper)) * Jbar`이며
`g_ratio=g_lower/g_upper`다. 동일 전이의 `LINEHEAT`, 재구성 population, oscillator
strength/A, `SCL_LN`으로 예측한 ZNET은 14개 모두 출력 정밀도 내에서 저장 `NETRATE`와
일치(최대 상대차 `<4e-5`)했다. 다만 이 초기 역산은 line profile quadrature의 합이 1이라고
가정했으므로 native `Jbar` 자체를 직접 분리한 값은 아니다.

`e4d5ec0d…8f49c4f7`다. 주파수별 `q_i=LINE_PROF_SIM(i)*Δν_i`에 대해 native는
`ZNET=Σ q_i*(1-RJ_i*CHIL_MAT/ETAL_MAT)`, `JBAR_SIM=Σq_i*RJ_i`,
`LINE_QW_SUM=Σq_i`를 따로 누적한다. `set_line_opac.f`의 `Δν_i`는 native 격자
사다리꼴 가중치다. `FIX_DOP` profile은 `TDOP=2 K`, Doppler 원자질량4, 난류속도

### 동일-state BB 순율 블록 대조

`summarize_cmfgen_ir_grid_impact.py`의 선택적 NETRATE 대조를 이용해 Si II/III·S II/III
12,415개 전이를 `(Z,stage,lower_full,upper_full)`로 모두 짝지었다. 공통 A와 동일한 native
`NATIVE_FULL_POP.bin` 인구를 양쪽에 사용했다. native 쪽은 출력된 `ZNET`에서
`F_native=n_upper*A*ZNET`을 만들고, fine 쪽은 보존 Jbar와 질량 Q로
`F_fine=n_upper*(A*Q+B_ul*Jbar)−n_lower*B_lu*Jbar`를 계산했다. 둘 다 양수=하향 순율이다.
각 선의 순율을 아래 SL에 더하고 위 SL에서 빼 준위별 BB 유입−유출 벡터 D를 구성했다.
동일 SL 내부6개 전이는 풀 변수에 기여하지 않으므로 양쪽에서 상쇄했다. 열 전용 `SCL_LN`
재척도를 입자율에 곱하지 않는다.

native full/index는 기존 same-state 비교의 hash(`112471f1…acfdfb`, `71bf6dc8…af56d6`)와
각각 일치하고 선택 Lumina 응답 hash도 연결했다. 처음 Lumina 인구로 평가한 뒤 native
이진 인구를 양쪽에 똑같이 적용해 반복해도 아래 결과는 유지됐다. 이로써 약1e-8 규모의

대표 앵커도 앞선 재구성과 맞는다: Si IV 255874 `1.0195215`(앞선 중심 반올림 범위
`1.01907–1.01998` 안), Si IV 257462 `0.99999206`, S III 313702 `0.99981420`,
315920 `0.99970541`이다.

이 전 선 분포는 **인쇄된 격자에서 재구성한 Q**이지 native 내부 `LINE_QW_SUM`의
직접 포획이 아니다. `CONT_FREQ`와 중심 주파수의 출력 정밀도, 원래 native 정수 구간
(`TRANS_INFO`/`fort.77`) 부재가 남고, 표에는 A·개체수·Jbar·열 기여 가중이 없다.
따라서 이는 `1 Doppler-width` 격자의 수치 적분 오차가 일부 Si/S 전이의 BB율에
들어갈 수 있음을 뒷받침하지만, 이온화 분포나 39/90 열 부호 불일치의 원인·크기를
확정하지 않는다. Lumina의 `Q≈1`을 native의 거친 격자 오차에 맞춰 바꾸지 않는다.

### 고정상태 profile-mass-only 반사실

같은 포획의 `NETRATE`/`LINEHEAT` 789,775개 쌍을 line ID와 전이 라벨로 대조하고,
기존 native signed `LINEHEAT`를 그대로 사용해 `H_Q=1≈H_native/Q`를 계산했다. 이는
재구성한 Q만 1로 바꾸고 normalized profile `Jbar`, T/ne, 인구, 나머지 연산자를 고정한
반사실이다. Q는 `Σq/(√πσ)`로 정규화하고 저장된 line ledger 값을 그대로 합산했다.
새 solver·수송·물질응답은 없다. 깊이36 S III Q-only 합은 기존 분석값을 재현한다.

새 native 실행·완전한 물리 보정·공동수렴 증거는 아니다.

### 고정상태 Q=1 + fine-grid J 주요 이온 전 선 반사실

같은 789,775개 전이 쌍을 재사용해 주요 이온의 모든 해당 선에 대해 Q와 profile-weighted
Jbar를 함께 바꿨다. 출력식 `ZNET=Q(1−αJbar)`에서 `α`를 native 재구성값으로 역산하고,
`LINEHEAT/ZNET`을 고정한 채 `Q=1`과 EDDFACTOR fine-grid J의 profile 평균을 대입했다.
따라서 이 결과는 native 산출값 자체가 아니라 인쇄 `CONT_FREQ`/선 중심으로 재구성한
고정 T/ne·인구·원 J의 line-operator counterfactual이다. 새 수송·SE·물질응답은 없다.
재현기는 [reconstruct_cmfgen_lineheat_fine_j.py](../scripts/reconstruct_cmfgen_lineheat_fine_j.py)이며,
수식 단위시험 6개를 통과했다. 기존 포획에서 깊이36·85를 재실행해 앞서 기록한 이온별
Q-only 및 Q+fine-J 값과 반올림 범위 내에서 재현했다. 이 확인 출력은 파일로 저장하지
않았으며, 원 입력 신원과 해시는 이 문서 상단에 기록한 포획 manifest를 따른다.

아래 값은 `erg cm^-3 s^-1`, 양수=냉각으로 통일했다. Lumina 목표는 앞 표의 BB 열을
부호 반전해 비교했다.

깊이36 S III 3,678개 전이 전체의 Q=1+fine-J 값은 Lumina와 `3.75e-8`(3.1%) 차이다.
깊이85 Co IV/Fe IV/Co V/Ni IV 합은 native `+9.04811e-3`에서 `+3.59881e-3`으로

이는 동일한 native source 식에서 coarse profile quadrature를 Q=1·fine-J 적분으로
바꾸면 관측된 주 이온별 열 차이가 대부분 사라진다는 강한 고정상태 증거다. 따라서
현재 가장 지지되는 원인은 물질/J의 총 배열 배선 누락이 아니라 선 profile의 주파수
적분 해상도 차이다. 다만 F10.6 중심과 출력 NCF의 유한 정밀도, 포획본의 exact native
interval-map 부재가 있고, `ZNET`/`LINEHEAT` 출력 정밀도로 계산한 counterfactual이므로
100% 일치나 exact native qsum을 뜻하지 않는다. 무엇보다 T/ne/인구를 갱신하지 않았으므로
Si/S 이온화 분포, 에너지-전하 공동수렴 또는 최종 스펙트럼의 해결 판정이 아니다.

그러므로 profile-area 차이가 실제 물질응답 계약에 들어간다는 점은 확인됐지만, 전 선의
exact native `Q`와 profile-weighted `Jbar`를 같은 원자모형 전이로 짝지은 비교는 아직 없다.
현재 보존 포획에는 `TRANS_INFO`와 `fort.77`이 없어 exact native interval mapping을
복원할 수 없고, `CONT_FREQ` 재적분은 native 격자를 근사하는 별도 진단일 뿐 exact
`LINE_QW_SUM` 대체가 아니다. 이번 이온별 합은 SE 영향이나 39/90 열 부호 불일치,
이온분율 공동수렴을 증명하지 않는다.

### S III 정규화 Jbar 차이의 격자 분해 (read-only, 2026-11-04)

같은 고정 상태 깊이36에서 대표 S III 두 선의 차이를 세 항으로 나눴다. `J_NCF`는
인쇄된 `CONT_FREQ`에 EDDFACTOR의 fine-grid J를 선형 보간한 뒤 native `TRAPUNEQ`
가중으로 직접 합산한 값이다. `J_PL-HO`는 같은 NCF 노드의 J를 구간별 선형으로 두고
Gaussian 선 profile을 12점 Gauss 적분한 값이며, `J_fine`은 원 EDDFACTOR fine-grid J를
같은 profile로 직접 사다리꼴 적분한 값이다. Gaussian 폭은 고정 `4.506845517e-5`다.

| 전이 ID | `Q_NCF` | `J_NCF/J_fine−1` | `J_PL-HO/J_fine−1` | `J_NCF/J_PL-HO−1` |
|---:|---:|---:|---:|---:|
| S III 313702 | `0.9998142` | `−0.4250%` | `−1.9715%` | `+1.5777%` |
| S III 315920 | `0.9997054` | `+0.06514%` | `−0.4658%` | `+0.5334%` |

따라서 겉으로 관측된 native/fine `Jbar` 차이가 작은 것은 native NCF의 직접 합산 오차와
NCF 사이 J 변화를 선형 보간으로 대표할 때의 차이가 반대 부호로 상당 부분 상쇄되기
때문이다. 이 두 선에서는 profile 면적 `Q`가 거의1이어도 J 적분은 격자 해상도에
민감하다. NETRATE 선 중심 출력의 반올림 한계 `±5e8 Hz`를 이동시켜도 각각
`J_NCF/J_PL-HO−1 = 1.566–1.589%`, `0.531–0.536%`이고 최종 native/fine 차이는
`−0.431–−0.419%`, `+0.0627–+0.0676%`로 유지된다. 중심 반올림만으로 생긴 결과는 아니다.
각 선의 `±3σ` 안 fine grid에는 24점이 있지만 NCF에는 6점뿐이며, 중앙 NCF 간격은
`1.000σ`다. 같은 구간에서 fine J와 NCF 선형보간 J의 profile-weighted RMS 잔차를
국소 profile 평균 J로 나누면 313702는 `4.123%`(최대 절대 잔차 `7.616%`), 315920은
`0.8140%`(`1.457%`)다. 따라서 두 선 모두 native NCF가 line-profile 내부 J 구조를
충분히 직접 표본화하지 못한다. 이 잔차는 fine grid 대비 보간 재구성 진단이며, native
내부 J의 독립 정답이나 물리 오차 상한은 아니다.

이는 근사 격자 진단이지 CMFGEN 내부 `LINE_QW_SUM`의 정확 재현은 아니다. 출력 주파수
정밀도와 exact native interval map 부재가 남고, 고차 적분은 NCF 노드 사이를 선형으로
연결한다. 특히 `J_PL-HO`와 fine-grid 값 차이는 실제 고주파 구조를 포함한 원 J를
선형 보간이 복원하지 못하는 정도까지 포함한다. 그러므로 두 오차를 물리적으로 완전히
독립인 항으로 단정하지 않으며, 이 결과만으로 어떤 격자를 수정하거나 이온화 분포를
수용하지 않는다. 다만 작은 native/fine 잔차가 정확도 증거가 아니며 profile quadrature와
J 해상도 모두를 살펴야 한다는 점은 강하게 지지한다.

이번 분해는 동일-state 고정-J에서 특정 열 전이의 원인을 강하게 좁힌 것이지, 이온화율이나
열/복사장 공동수렴을 증명하지 않는다. 상위 14개 roster, 저장 열합, 일반 `SCL_LN` 연결은
주원인으로 지지되지 않는다. 과거 `CONT_FREQ` 단순 Gaussian 재적분은 native qsum과 고유
격자 보간을 분리하지 못했으므로 원인 판정으로 채택하지 않는다. S III 정규화 `Jbar`의
격자 민감도와 깊이85 주요 Co/Fe/Ni line-operator 차이는 위 고정상태 반사실로 좁혔다.
다음 read-only 단계는 동일 식을 90점 열잔차에 확장해 전체 shell에서 profile 보정이
어느 범위까지 작동하는지 확인하는 것이다. 이는 line heat 비교이지 full `STEQ_T`, 이온율,
자기일관 수렴 판정이 아니다. 새 CMFGEN 실행·수송·물질응답은 기존 승인 범위에 포함되지
않으므로, 이를 요구하는 단계에서는 별도 권한을 받는다.

판정: 입력 T/ne/인구와 총 J 배열 전달은 맞지만 line operator 경로의 열항은 맞지 않는다.
깊이36 Si IV 255874의 직접 열차는 native line-profile 면적 과적분이 거의 설명하며,
고정상태 Q=1 반사실도 이를 재현한다. Si III/S III 열차와 깊이85 전체 차이는 이 보정만으로
닫히지 않는다. 하지만 Q=1과 fine-J를 함께 적용한 고정상태 반사실은 S III 및 깊이85 주요
이온 line heat를 Lumina에 근접시켰다. 따라서 현재 가장 강한 원인 후보는 상태 배선이나
저장 합산 산술보다 native line-profile 주파수 quadrature 해상도 차이다. 나머지 전이와
90점 전체 열수지 기여는 아직 전부 분해되지 않았다. `SCL_LN`
보정 일반 누락 가설은 생산 코드/CMFGEN 제어 재대조에서 지지되지 않았고, 원자모형의
독립 물리 오류나 새 회귀로 확대 해석하지 않는다. 공동수렴·Si/S 이온화 동질성·최종
스펙트럼은 계속 `NOT_MET`이다.

실행기 표식 오류 수정과 관련 시험 4개 통과는 commit `0cf2b529`에 이미 푸시됐다. 이후

정규화 Jbar 오차를 분리했다. 이번 기록에는 해당 결과와 반올림 한계를 반영하며, 새
