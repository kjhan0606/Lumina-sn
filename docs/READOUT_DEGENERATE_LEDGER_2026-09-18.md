## 1. 질문
DET-LTEUNMAP-EPS 이후 중간 셸(9–24)은 **LTE(T_e)** 에 정착했다(S II .02–.10 대 CMFGEN .71–.85). 원인은 bin 조립기의 연속체 소스 `S_fixed = (χ_abs·B(T_e) + η_line)/χ_tot` — 연속체 방출을 Kirchhoff-LTE 로 두어 bf-불투명 빈의 J 를 B(T_e) 로 고정하는 채움 ①(판독 A). 이것을 실제 인구의 Milne 방출 `η_bf`(`bf_get_eta`, `LUMINA_CMF_BF_MILNE=2` 로 이미 빌드되나 **미소비**)로 바꾸면 J → S_bf = B·(r/Φ) 가 되어 광이온화-RR 이 항등 상쇄되고(퇴화), **남는 채널**이 r 을 정한다. 그 채널이 무엇이고 어디에 착지하는가.

## 3. 읽기

1. **S II→III(문턱 531 Å, 깊은 EUV)**: 퇴화 극한이 CMFGEN 과 **같은 자릿수** — r_deg(1.0) 0.34–1.7 대 r_C 0.18–0.72(비 1.9–2.3×), r_deg(0.05) 는 10× 아래. ⟹ CMFGEN 의 중간 셸 황 이온화는 「갇힌 EUV 연속체 + 비열적 이온화 ↔ RR+DR」 로 설명되며, Lumina 가 더하는 것은 J=B(T_e) 의 가짜 광이온화(r 을 100–300× 올림)다. 비열적 강도(pref)가 감도 최대 노브: CMFGEN 값은 pref 0.05 와 1.0 **사이**(≈0.5)에 놓인다 — 코드 주석의 x_e 의존 η_ion(Xu & McCray) 논의와 정합.
2. **Si II→III(758 Å, FUV)**: 퇴화 극한은 CMFGEN 보다 10–500× **과재결합** — CMFGEN 의 Si 는 FUV 광이온화가 정한다(함의 J 장부: J_req/B ~ 10⁻³, 희석 광구장). 즉 758 Å 빈은 CMFGEN 에서 갇혀 있지 않다. Lumina 에서 그 빈은 현재 J=B 로 **과잉** 이온화. 채움 ① 을 걷으면 Si 는 J(758 Å) 가 실제 수송값으로 가느냐에 달린다 — mapped 선 S=B 열적 선숲이 FUV 를 여전히 열화시키면 과재결합으로 튈 수 있다(다음 rung 의 위험).
3. **Ca II→III(1045 Å)**: 같은 논리로 FUV 광이온화 지배(CMFGEN r 10⁵); 퇴화 극한은 무관.

## 4. 수리안의 구조적 한계 — 반복수

DET 레인은 외부반복 **2회 고정**(동결 러너 `STRICT_TWO_ITERATION_CONTRACT`, `LUMINA_PURE_CMFGEN_ITER=2`). 소스만 η_bf 로 바꾸면 LTE 시드에서 J(iter0)=S_bf(LTE)=B ⟹ r(iter1) = Φ·α_RR/(α_RR+α_DR)/n_e (+ 작은 NT) = **0.40×(S)·0.27×(Si) 만 이동**, 반복마다 같은 비 ⟹ 2회 런의 S f_II 는 .017 → ≈.04–.10 에 그친다. 고정점(r_deg)에 닿으려면 ~10 회 이상 필요(기하 수렴, 비 0.3–0.4). ⟹ **2회 런은 구성상 미결**이다. 파티션 시간 상한은 무제한이므로 ITER≈8–10(≈20–25 h/런) 은 가능하나 러너의 2회 계약을 바꿔야 한다(스테이징 복사본 편집 + STAGE_IDENTITY, G-ID 에 ITER 키·러너 해시 기재).
