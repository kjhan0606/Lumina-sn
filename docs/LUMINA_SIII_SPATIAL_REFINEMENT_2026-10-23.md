# S III 바깥 native 점의 공간 소구간 민감도 — 2026-10-23

## 목표와 경계

고정 물질70/J71에서 같은 native49/50 반경의 S III 광흡수율은
C F/CMFGEN J가 각각 바깥`1.5615`, 안쪽`0.9405`다.
715Å 단일점은 바깥 약`2.12`다. 기존 C formal은 각 원물질 셀을
4개 소구간으로 나누고 native χ/η를 각 소구간 중점에 고정해
끝점 강도를 표본화한다. 이번에는 **공간 세분 수만 4→8**로
바꾸어 그 차이의 세분 의존성을 본다. 이 계산만으로 CMFGEN과
수치 연산자 동등성, Si/S 이온분포나 스펙트럼 수용을 판정하지 않는다.

## 봉인 입력과 변경

- 같은 물질70/J71, 전`1,115,020` C 주파수, 원 CMFGEN native
  χ/η/산란 source 및 동일 고정 J, 외부대기와 내부 확산 경계를 사용한다.
  출력 위치는 0-based native`[49,50]`, 셀39다.
- 기존4분할 결과 root
  `/gpfs/kjhan/cmfgen_runs/lumina_native_position39_20261022-Snv5iR`의
  `F-native-positions.npy` SHA256
  `57be9661cc05fa3d08a3b2f58f520b5845c272a0cd458ea3f66991995ba79ec4`,
  CMFGEN J SHA256
  `1c98e5e86d1bf9e66b68d9f2a5abded70f67a60a6c2458147ffd6c9d8a078437`.
- 4→8분할 사전 기하는 같은110 ray·관측 반경이고 내부 반구간만
  `94,664→184,048`로 증가한다. 공통 생산 기하의4분할 상한은
  유지하고 고정 J·두 native 관측점의 격리 경로에만8을 허용한다.
  직접시험 `tests/test_lumina_outer_native_spatial.py`는
  Lageunha CPU2에서 **6통과/15.51초**. 같은 상수 물질 소형
  문제에서 세분별 출력 최대 상대차는 시험 실패 시 약`6.9e-7`였고,
  이를 정상 세분 의존성으로 분류해 시험은 유한·양수 및 `1e-5`
  일치만 요구한다. 이는 실제 CMFGEN 동질성 기준을 약화한 것이 아니다.

## 실행·판독 계획

Lageunha 수동 CPU16/GPU0, 메모리 계획64GiB, 벽 상한3600초,
전주파수 F 한 회·자동재시도0. 기존4분할은 `1262.10초`,
RSS`23043456KiB`였고8분할은 소구간 약2배이므로 비용이 증가한다.
새 빈 root만 사용하고 원 입력·기존 결과는 덮어쓰지 않는다.
실패 또는 시간 초과 시 기록을 보존하고, 단순히 성공으로 바꾸거나
자동 재실행하지 않는다.

완료되면 (1) 새 전주파수 F와 참조 J의 파일 신원을 확인하고,
(2) 같은 native 위치의 715Å 점값 F/J 및 S III
400–800/600–750Å와 기존 **10Å×15구간**, 전대역 고정인구 PHOT/Milne 광흡수율을
기존4분할과 비교한다. 세분이 바깥 차이를 크게 줄이면
**공간 이산화 민감도**는 지지되지만 CMFGEN operator 전체
동등성은 아니다. 차이가 거의 없으면 이 4→8 변화로
바깥 잔차가 해소되지 않는다고만 판정한다. 어느 쪽도 최종
자기일관 목표를 대신하지 않는다. 동일 원속도장·주파수 이동 규칙·
각도 가중치·관측 반경·F/J 추출 정의도 결과에서 확인한다.

Astra는 전달 수치 기반의 **조건부 계획 자문**에서 이 단회가
비용 대비 의미 있다고 보았다. 다만 판별 대상은 넓은 공간
수렴성이 아니라 **현재 C 소구간 4→8의 유한 길이 민감도**뿐이며,
두 해상도만으로 수렴 차수나 연속극한을 주장하면 안 된다고
명시했다. 안쪽 node가 악화하거나 715Å 점값과 적분율이
서로 다르게 움직이는 경우도 함께 보고한다. Astra는 원자료를
직접 읽지 못했고 실행·코드 변경은 하지 않았다. 운전자는 원 코드·
입력·기하와 실행 결과를 직접 재현·판정한다. 최종 목표는
`active/NOT_MET`.
