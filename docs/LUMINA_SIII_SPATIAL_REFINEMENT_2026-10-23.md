# S III 바깥 native 점의 공간 소구간 민감도 — 2026-10-23

## 목표와 경계

고정 물질70/J71에서 같은 native49/50 반경의 S III 광흡수율은
C F/CMFGEN J가 각각 바깥`1.5615`, 안쪽`0.9405`다.
715Å 단일점은 바깥 약`2.12`다. 기존 C formal은 각 원물질 셀을
4개 소구간으로 나누고 native χ/η를 각 소구간 중점에 고정해
끝점 강도를 표본화한다. 이번에는 **공간 세분 수만 4→8**로
바꾸어 그 차이의 세분 의존성을 본다. 이 계산만으로 CMFGEN과
수치 연산자 동등성, Si/S 이온분포나 스펙트럼 수용을 판정하지 않는다.

입력·기하와 실행 결과를 직접 재현·판정한다. 최종 목표는

운전자 자체 판정은 **4→8 유한 길이 민감도 확인, 그러나 S III
바깥 불일치 해소 실패(REWORK)**다. 이 한 변경만으로 큰 잔차가
제거되지 않았으므로 단순 소구간 수 부족을 유일 원인으로 보는
설명은 지지되지 않는다. 두 해상도만으로 공간 수렴 차수·연속극한,
native 공간보간 자체·CMFGEN 주파수 upwind와 C 연속 특성선의
차이·각도 구적 중 어느 것의 원인 비중도 확정할 수 없다.
다음 확인은 추가 전주파수 실행보다 **같은 원 광선·계수·경계에서
두 주파수 연산자를 직접 대응**하는 것이다. 최종 Si/S 자기일관
분포와 스펙트럼/물리량 동질성은 여전히 `active/NOT_MET`다.
