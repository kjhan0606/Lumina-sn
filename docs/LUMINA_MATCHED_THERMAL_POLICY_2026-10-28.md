# 최종 CMFGEN 비교의 열방정식과 현재 재현 분기의 구분

## 확인한 문제

운전자가 새 자체장 온도 보정을 연결한531e0e7f는 `physical_stored`를
명시했다. 그러나 기존 `PLAN_CMFGEN_FULL_MATERIAL_RESPONSE_2026-10-27.md`의
고정장 물질 보정 계약은 `native_instantaneous_scenario`였고,
`PLAN_NATIVE_INSTANTANEOUS_REFERENCE_2026-10-27.md`도 같은 순간 침적열과
native 열근사·단열을 기준으로 한다. 이 연결에서 최종 비교의 열정책이
이어지지 않은 점은 운전자가 바로잡아야 할 문제다.

기존 문서도 저장0가열의 released-T 해만으로 최종 물리 앵커를 만들 수
없다고 명시한다. 현재0열 분기의 물질응답·내부 잔차 감소가 유효하더라도
그것을 준비된 순간열 CMFGEN과 같은 방정식의 해라고 부르지 않는다.
원70은 어느 쪽에서도 수렴한 released-T 앵커가 아니다.

## 같은 상태에서 실제로 다른 식

원 MODEL SHA256은
`e8ec1835355869c3b8fbaf761fc8b6eeb516b527aa660aea768b8cbc19e2f6c9`다.
읽기 전용 확인에서 DO_DDT=F, INS_DEP=T, COH_ES=T, INC_AD=T,
SCL_LN=T/SCL_LN_FAC=0.5, FIX_T=T, T_MIN=0.5를 확인했다.
INS_DEP=T라는 입력과 원 RVTJ의 실제 저장 붕괴열0은 구분한다.
이미 확인한0시간 decay 분기의 결함 때문에 입력 플래그만으로 실제
순간 침적열이 적용됐다고 판단할 수 없다.

## 중요한 물리 판단의 Astra 자문과 운전자 결정

Astra `gpt-6-astra`, 세션 `01a181b1-109e-7ff2-9ddd-ea7cd048ebf7`에
이 열방정식 계약 충돌만 읽기 전용 자문했다. 비용·시간·운영 횟수
자문은 아니며 추가 계산·파일 변경도 하지 않았다. 주요 의견은 다음과 같다.

- 두 정책의 root 비교는 근사/열원 민감도 비교일 수는 있지만 같은 모델의
  E-동등 증거가 아니다. 상태 허용폭에 들어도 잔차/Jv 동등성은 별도다.
- 기존 합의를 유지하는 기본 비교는 양쪽에 같은 순간열·native SCL/FF·
  native 내부에너지/AD를 적용한 모델이다. physical 광자 장부는 별도 보존한다.
- physical photon 모델 자체를 최종 권위로 선택한다면 순간열을 포함한
  별도 명시 계약과 같은 잔차를 푸는 대응 기준해가 필요하다. SCL만 끄거나
  온도를 맞춰 이 변경을 숨기지 않는다.
- 같은 J·기준 물질의 네 섭동은 모든 정책의 장부가 저장돼 있으므로
  조건부 재사용 가능하다. 기존 방향·수용 판정은 정책 변경 후 승계하지 않는다.

운전자는 이 판단에 동의한다. 새 최종 기준을 임의로 바꾸지 않고 기존
native 순간열 계약을 비교의 기본으로 유지한다. 현재 실행은 원래
physical_stored 분기로 보존하며 소급해 native 해로 재명명하지 않는다.
최종 물리량·스펙트럼·보존 기준은 축소하지 않는다.

## 구현과 섭동 재사용 범위

후속 CLI는 온도 보정 시 `--thermal-policy`를 반드시 명시하게 했다.
이 정책을 잔차·Jacobian·수용·방향 기록·물질 내보내기에 일관되게 전달한다.
아무 정책이나 사후에 골라 더 작은 장부로 합격시키지 않는다.

같은 정책의 재개는 요청 T/ne를 정확히 재생한다. 정책을 바꿀 때에는
`--thermal-replay-prefix 1..4`로 초기 미분 자료만 명시적으로 읽는다.
각 깊이의 원소/핵종 총수와 원 입력·epoch·장·물리 구현이 같아야 하고,
저장/순간 침적열 프로필도 섭동 사이에서 불변임을 확인한다. 전역 총수만
같고 깊이별 핵종 밀도가 달라지는 경우는 같은 물리 재사용이 아니다.

새 정책의 기준 잔차와 행 척도로 Jacobian을 다시 조립하고, 선택한
내부에너지로 전체 깊이의 각 AD 미분을 다시 계산한다. 외부 고정열만
바뀌어도 행 척도가 달라질 수 있으므로 예전 scaled 행렬·방향을 그대로
쓰지 않는다. native의 정적 SL 에너지도 인구가 변하면 내부에너지가 변한다.
다섯 번째 이전 후보는 새 방향 후보로 재생하지 않는다.

## 아직 남은 연결과 실제 실행 범위

열정책을 명시하는 것만으로 전체 M/E/S-동등이 된 것은 아니다. 특히
`cmfgen_model_sources.py`의 현재 전주파수 계수는 FF를 ALL_POSITIVE_IONS로
게시한다. native 열행의 FF 선택과 동일한 수송 모델을 만들려면 후속 계수
생산에도 native FF 선택을 연결해야 한다. 이 선택, 수렴한 released-T
기준해, 같은 물질/장의 전역 잔차와 observer 비교가 여전히 남는다.

새 열정책으로 실제 후보를 계산하거나 native/수송을 추가 실행하지 않았다.
현재 CPU16·32GiB·최대12시간·5평가 단회의 source snapshot과 입력은 그대로다.
재사용 코드가 준비됐다는 사실은 다음 다른 정책 실행의 자동 승인이 아니다.
이 문서와 직접시험의 판정도 최종 목표 달성이 아니며 **NOT_MET**다.
