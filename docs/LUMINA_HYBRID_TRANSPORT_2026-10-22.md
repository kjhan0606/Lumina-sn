# 자체 복사장·생산 Si/S율을 위한 수송 완결 묶음 — 혼합 실행 준비

상태: **계획 선택, 미구현·미제출·미판정**. 구현·직접시험·실행은 운전자 Codex가 담당한다.

## 목표와 현재 장애

원 native90 자체 J1/J2와 갱신 잔차, 실제 Si/S 생산율을 산출하고 CMFGEN 이온분포/스펙트럼/물리량과 대조할 수 있어야 한다. 커널 시험이나 원13003 단일구간 성공만으로 이 묶음을 완료하지 않는다. 먼저 그 경로를 막는 전주파수 공간 적응을 원 정확도로 완결해야 한다.

434043은 3249GPU초 후 내부 시간 한도로 종료했다. 전주파수 초기 coarse/두half와 candidate replay 이후 공간 적응7206회까지 진행했으나 마지막 후보의 출력별 최대 추정오차비221.834866>1로 미달했다. 이는 전체 자기일관 수렴오차나 물리구간 진행률이 아니다. 저장된 완성NPY/독립3열 판정은 없다. 종료 시 선택slab2302의 정확한leaf경계는 저장되지 않았으므로 같은mesh의실패재현이라고 표현할 수 없다.

## Astra의 묶음 선택과 적용상 정정

Astra `01a161e4-570d-77c0-8f33-a29ed21acf73`는 동일 native 계산의 단순 시간 연장보다 **warp source-measure 기본 + 명시적 수치/작업 한도에 한정한 native 적분 대체**를 선택했다. 자문은 완료·닫았으며 소스 구현·새 실행·정확도 통과를 대신하지 않는다. 다른 모델이나 반복 감사는 추가하지 않는다.

자문에 포함된 두 범위는 실제 증거에 맞게 한정한다.

- 434043의 미완slab에서 precision/work-limit가 관측된 것은 아니다. 관측된 것은 시간 초과다. 후보 비교에는 보존된 실제 입력과 알려진569899를 쓰되, 거기에서 warp의 수치 실패가 재현될 것이라고 가정하지 않는다. 전환 분기 자체의 직접시험과 실제 물리입력 결과를 구분한다.
- 자문의 “기존 준비4651초 유지”와 “추가1GPUh”는 동시에 만족할 수 없다. 이미4341초를 소비했으므로 남은310초로3600초를 제출하지 않는다. 사용자 시간확대·추가진행 사전승인 범위에서, 새 구현의 조건부 단회 한도를 **추가3600초·누적최대7941초**로 명시한다. 기존사용은 삭제/초기화하지 않으며 실제 제출 직전에 원장에 예약한다. 현재 예약/새GPU실행은0이다.

## 구현 범위와 보존할 수치계약

새 선택은 현재 `CMF_GPU_WARP_MEASURE`와 `CMF_GPU_NATIVE_BIN_STREAM`의 무조건 동시선택이 아니다. 두 적분기의 역할과 바이너리/driver 정체성을 구분한 명시적 혼합 dispatch로 구현한다. 기존기본/scalar/native/warp 선택은 그대로 유지한다.

동일출력의 warp 적분이 성공하면 그 결과를 사용한다. BAD_INPUT/NUMERIC_RANGE 등의 부적합입력을 대체 적분으로 숨기지 않는다. work/precision 한도인 경우만 같은 χ/η·반경·ES×J·fullSR·signedχ·동일원천1e-8을 사용한 native 적분으로 처음부터 계산한다. 실패한 부분값과 성공값을 혼합하거나 오차를 낮추지 않는다. 두 시도의 패널예산 합은 원호출의 maxpanels를 넘지 않아야 하며, 두 번째도 실패하면 미완으로 반환한다.

가능하면 빠른 warp kernel과 드문 scalar 대체 kernel을 분리해 native의 큰 thread-local 상태를 모든 warp lane에 부과하지 않는다. 미완중간값을 replay/관측에 전달하지 않고 원출력열/원오류를 유지한다. 추가 상태·공유 상태·실제 stack 예약을 원1GiB 활성공간과 host/device16GiB에 포함한다. 새 경로의 메모리/수치계약을 충족할 수 없으면 구현을 수정하며 제한을 조용히 확대하지 않는다.

원천1e-8·공간1e-5·완성출력별추정오차비<=1·독립미세3열각1e-4를 보존한다. 10초 성능목표는 보고하되 국소정확도를 차단하지 않는다. CPU 연속재구성후보는 생산미채택 상태를 유지하며 이번 I0=0 수송에 끼워 넣지 않는다. 실제 native90 입력/원 독립참조/과거 실패는 변경하지 않는다.

## 하나의 실행 흐름과 판정

구현과 CPU 직접시험을 같은 목적 안에서 묶는다. 전환 분류·패널 합·실패 미발행과 원 입력의 T/S/반환오차를 확인하고 strict CUDA 컴파일 및 제한 장치 대조를 거쳐, 조건이 충족된 새 바이너리만 원13003 전주파수 단회에 사용한다. 작은 시험마다 별도 단계 종료감사나 모델 호출을 만들지 않는다. 종전 warp의512열0.361초를 전체장 ETA나 수치한도 해결의 증거로 쓰지 않는다.

최소 증거는 봉인 소스/바이너리/입력 신원, 원CPU 대조, 대체호출 수와 미해결 수, 적분 실행비용, 완성NPY/해시, 원독립3열과 최종출력별추정오차, 전체작업/메모리/본할당시간이다. 대체kernel의 clock tick이나 중첩실행시간은 실측 wall time 또는 GPU 비용과 혼동하지 않는다. 시간 한도라면 그 사실과 마지막완료상태를 남기고 자동 재시작하지 않는다.

국소 완결 뒤 같은물리장·공간/주파수 오차의 광선간 전달과 관측/PHOT 축약을 실제 J1/J2·생산율에 연결한다. 경로오차 carry가 없는 상태에서 국소 통과를 최종J/PHOT1e-4 보증으로 표시하지 않는다. 원온도/물질복원·CMFGEN 비교 기준을 완화하지 않으며 남은 실제장/생산율/스펙트럼이 없으면 묶음도 미완이다.

## 자원·입력·롤백·재현

준비 CPU는 lageunha에서 부하 확인 후1코어·작은직접시험180초 이내, strict 컴파일은GPU없이 별도 명시시간을 사용한다. 조건부 단회GPU는 노드미고정A1001/CPU1/host-device16GiB/활성1GiB/512NF·최대3600초·no-requeue·자동재시도0이다. 내부구간/전체/외부정리 시간은3600초 안에 중첩해 배치하고 종전3240초를 무심코 상속하지 않는다. 장치 직접시험과 수송은 이3600초에 함께 포함한다.

현재 정산 기준 사용71.7176111111/144GPUh·잔여72.2823888889GPUh·예약0을 계승한다. 실제 제출 시 최대1GPUh만 예약하고 종료 시 본할당 ElapsedRaw만 한 번 차감한다. 같은할당의 중첩Python/step/시험시간을 중복 차감하지 않는다. 별도 전체장 실행을 이 국소단회로 꾸미지 않는다.

원 입력config `/gpfs/kjhan/cmfgen_runs/lumina_field0_checkpoint_20261020-EoA5Bi/input/config.json`의 SHA256은 `5fe599e35c767659ac40fd80052250e6950615679eee8bd14cc6b2aef3997a82`다. 원 실패434043 root와 f6696f6e…/warp7674c464… 바이너리·CPU 원참조를 보존한다. 새소스/실행은 별도격리root에 봉인하고 채택 전 기존선택을 바꾸지 않는다. 구현 완료 전 재현명령을 완성된 것처럼 만들지 않으며 이후 이 문서에 정확한 compile/시험/단회제출/출력대조 명령과SHA를 추가한다.
