## 구현 범위와 보존할 수치계약

새 선택은 현재 `CMF_GPU_WARP_MEASURE`와 `CMF_GPU_NATIVE_BIN_STREAM`의 무조건 동시선택이 아니다. 두 적분기의 역할과 바이너리/driver 정체성을 구분한 명시적 혼합 dispatch로 구현한다. 기존기본/scalar/native/warp 선택은 그대로 유지한다.

동일출력의 warp 적분이 성공하면 그 결과를 사용한다. BAD_INPUT/NUMERIC_RANGE 등의 부적합입력을 대체 적분으로 숨기지 않는다. work/precision 한도인 경우만 같은 χ/η·반경·ES×J·fullSR·signedχ·동일원천1e-8을 사용한 native 적분으로 처음부터 계산한다. 실패한 부분값과 성공값을 혼합하거나 오차를 낮추지 않는다. 두 시도의 패널예산 합은 원호출의 maxpanels를 넘지 않아야 하며, 두 번째도 실패하면 미완으로 반환한다.

가능하면 빠른 warp kernel과 드문 scalar 대체 kernel을 분리해 native의 큰 thread-local 상태를 모든 warp lane에 부과하지 않는다. 미완중간값을 replay/관측에 전달하지 않고 원출력열/원오류를 유지한다. 추가 상태·공유 상태·실제 stack 예약을 원1GiB 활성공간과 host/device16GiB에 포함한다. 새 경로의 메모리/수치계약을 충족할 수 없으면 구현을 수정하며 제한을 조용히 확대하지 않는다.

원천1e-8·공간1e-5·완성출력별추정오차비<=1·독립미세3열각1e-4를 보존한다. 10초 성능목표는 보고하되 국소정확도를 차단하지 않는다. CPU 연속재구성후보는 생산미채택 상태를 유지하며 이번 I0=0 수송에 끼워 넣지 않는다. 실제 native90 입력/원 독립참조/과거 실패는 변경하지 않는다.

## 하나의 실행 흐름과 판정

구현과 CPU 직접시험을 같은 목적 안에서 묶는다. 전환 분류·패널 합·실패 미발행과 원 입력의 T/S/반환오차를 확인하고 strict CUDA 컴파일 및 제한 장치 대조를 거쳐, 조건이 충족된 새 바이너리만 원13003 전주파수 단회에 사용한다. 작은 시험마다 별도 단계 종료감사나 모델 호출을 만들지 않는다. 종전 warp의512열0.361초를 전체장 ETA나 수치한도 해결의 증거로 쓰지 않는다.

최소 증거는 봉인 소스/바이너리/입력 신원, 원CPU 대조, 대체호출 수와 미해결 수, 적분 실행비용, 완성NPY/해시, 원독립3열과 최종출력별추정오차, 전체작업/메모리/본할당시간이다. 대체kernel의 clock tick이나 중첩실행시간은 실측 wall time 또는 GPU 비용과 혼동하지 않는다. 시간 한도라면 그 사실과 마지막완료상태를 남기고 자동 재시작하지 않는다.

국소 완결 뒤 같은물리장·공간/주파수 오차의 광선간 전달과 관측/PHOT 축약을 실제 J1/J2·생산율에 연결한다. 경로오차 carry가 없는 상태에서 국소 통과를 최종J/PHOT1e-4 보증으로 표시하지 않는다. 원온도/물질복원·CMFGEN 비교 기준을 완화하지 않으며 남은 실제장/생산율/스펙트럼이 없으면 묶음도 미완이다.
