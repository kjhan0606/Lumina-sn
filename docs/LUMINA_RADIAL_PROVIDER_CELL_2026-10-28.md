# 생산 provider와 같은 반경 재구성의 국소 선택 — 2026-10-28

## 목적·사전 범위

원 SC 숫자에 맞추려고 생산 보간을 바꾸지 않는다. 실제 같은 셀에서 연속장의
정의 차이와 그 연속장에 대한 적분 오차를 분리해 다음 수리 대상을 결정한다.
최종 Si II/III·S 이온분포/물리량/observer 동질성은 계속 **NOT_MET**다.

새 근거를 묶은 Astra 방향 자문은 생산 provider와 같은 연속 재구성을 먼저
정하고, 그 위에서 적분·격자수렴을 확인하라고 권고했다. 6.9% 조건부 잔차를
허용 오차로 선언하거나 새 GPU/전모형 물질 계산을 서두르지 않는다. 자문은
실행 자원 승인이나 새 필수 감사가 아니다. 이미 완료된 과거 자문 세션은
동시 열린 세션 한도 때문에 닫았으며 과거 답변·판정은 보존했다.

입력은 기존714.9525535Å·native49–50(0기준) 외향 ray54의 같은 실제 포획,
앞선 `pair-history`의 봉인 입력 해시, 원70/J71 전체 저장장이다. 원 저장장의
χ·진η·ES·source J와 포획 총η의 분해를 먼저 실제로 확인했다. 기본 진단인
s-선형 총η와 생산의 `진η(r)+ES(r)*J(r)`를 같은 함수라고 취급하지 않는다.

`cmfgen_radial_packet_cell.cpp`는 생산 `cmf_linear_provider.hpp`의 Reader를
직접 호출한다. χ·진η·ES·source J는 물리 반경에서 각각 선형이며 ES×J는
그 뒤 조립한다. 원 SC 제어점 계산은 기존 식을 그대로 공용 함수로 꺼냈다.
생산 기본 수송/계수 생산자/원자율은 바꾸지 않는다.

같은 고정 blue·B의 r-선형 함수와 생산의 proper-length 좌표를 모든 세분 mesh가
재평가한다. mesh마다 새로운 blue 보간장을 만들지 않는다. 다음을 함께 판독한다.

- 원 SC가 정의하는 source/τ Bézier의 독립 formal 적분과 저장 SC의 일치.
- 기존 s-선형 총η 참조와 r-선형 총η 대조, 생산 Reader의 분리 ES×J 참조.
- 같은 생산 Reader callback의1/2/4/8/16/32/64/128/256분할 적분과 독립 참조.
- 원 포획 길이와 생산 proper-length 길이 차이. 서로 다르면 숨기거나 맞춤
  scale을 곱하지 않으며 전체 차이를 source 보간만의 탓으로 하지 않는다.

이것은 고정-blue 국소식으로 생산 계수 재구성을 조사하는 것이지, 생산 전주파수
fullSR 연산자나 새 산란/물질해의 검증이 아니다. 양의 유효 소멸계수 범위만
지원하며 gain을 clip하거나 다른 해법으로 조용히 대체하지 않는다.

소형 gray 닫힌식·ES×J 비선형 조립·같은 연속장 재표본·원 SC 얇음/두꺼움과
기존 SC 시험12개가 lageunha에서 통과했다. 실제 포획 비교는 새 전용 root에서
lageunha 수동 CPU1·4GiB·외부180초·단회·재시도0으로만 수행한다. 원자료와
기존 결과는 보존한다. 새 전주파수 수송·물질·observer 계산은0회다.

## 실제 결과와 결정

실행 root `lumina_radial_provider_cell_20261028-3BF5Gg`의 수동 실행은
exit0·13.754초였다. `runner/`에 생산자·의존 모듈·C++/헤더 사본을 고정했고
`result/radial-cell.json`에 정확한 입력·코드·바이너리 해시가 있다.

원 전체 저장장의 R/V/σ/ES는 같은 포획과 일치했고, χ 최대 상대차는
`2.1455e-16`, `진η+ES×sourceJ`로 복원한 총η의 최대 상대차는 `4.1572e-16`이다.
따라서 이번715Å 포획에는 실제 source 분해를 연결할 수 있다. 이를 다른 주파수의
MOM 실패 snapshot이나 과거 미포획 source-J의 복원 성공으로 확대하지 않는다.

| 고정된 연속장 정의 | 같은 실제 입사에서 downstream I |
|---|---:|
| 저장 원 SC | 1.1577657579474474e-8 |
| 원 SC source/τ Bézier의 독립 적분 | 1.1577657579474484e-8 |
| 기존 s-선형 χ/총η/B/blue의 독립 적분 | 1.2461829555039095e-8 |
| r-선형 총η 대조·proper 좌표 | 1.2588074429238228e-8 |
| 생산 Reader의 r-선형 진η/ES/J 조립·proper 좌표 | 1.2588045042658261e-8 |

SC 연속 source 참조는 저장 SC를 상대 `8.57e-16`로 재현했다. 같은 SC 정의의
구현 오류를 발견한 것이 아니다. 생산 Reader 정의의 참조는 원 SC보다
**8.72705%**, 기존 s-선형 참조보다 **1.01282%** 크다. 진η·ES·J를 분리 조립한
것과 총η를 r에서 바로 선형 보간한 것의 차이는 이 셀에서는 상대 `−2.3345e-6`으로
작았다. ES×J 조립 누락이 이 셀의 큰 차이를 만든다는 설명은 지지되지 않는다.

native 저장 경로 길이는 `2.581420660472013e14 cm`, 생산 proper-length 함수는
`2.5813879132735956e14 cm`로 상대 `−1.26857e-5`다. 원/생산 물리 좌표 정의를
같다고 강제하지 않았다. 전체 차이를 길이 한 항의 탓으로도 해석하지 않는다.
반경 선형 가중치가 실제 `cmf_nodal_input_prepare()`의
`(r-r_inner)/(r_outer-r_inner)`와 같음을 소스에서 확인했고, 계수 조립은 같은
`lumina_native_linear::Reader`를 실제 컴파일해 사용했다.

동일한 생산 Reader·r-선형 B/blue callback을 재표본한 세분 결과는 다음과 같다.
각 mesh는 다른 연속장을 새로 피팅하지 않는다.

| 공간 분할 | 동일 독립 참조 대비 상대 적분 오차 |
|---:|---:|
| 1 | 1.00258e-2 |
| 16 | 4.53129e-4 |
| 64 | 4.63716e-5 |
| 128 | 1.20869e-5 |
| 256 | 3.05479e-6 |

64/128/256의 관측 차수는1.9244였고, 그 세 점의 Richardson 외삽과 독립 참조의
상대차는 `1.76e-7`이었다. 국소 수치 관측이며 전역 오류 보증이나 최종3단 격자
수용을 대신하지 않는다. 같은 연속장에서의 남은 수치 오차와 서로 다른 연속장
사이의8.7% 차이를 구분할 수 있었다. 이 차이를 없애려고 생산 source를 거친
원 SC 숫자에 맞추는 보정은 채택하지 않는다.

**다음 수리의 기준:** 계수·좌표·blue를 서로 다른 함수로 복원한 대조는 생산
오류의 증거로 쓰지 않는다. 생산 Reader 재구성을 유지하는 비교 경로가 갖춰졌고,
그 안의 국소 적분은 수렴한다. 이후에는 그 공통 정의에서 공간·주파수 해상도와
산란/물질 결합을 다뤄야 한다. 이번 국소식은 주파수 차분의 blue와 B를 명시적으로
고정했으므로 생산 전주파수 fullSR 연산자의 정확성/수렴을 아직 증명하지 않았다.
새 F2 물질응답·수렴 released-T 앵커·observer 계산도 수행하지 않았다.

`127aa4b15aea2237395764362c0d0e81a900f3f12bb1712e388960cc07653bc1`.
실행 바이너리 SHA256:
`28fa0acfd066f76eabd43cff1d954ca5fa4417209374045b9f08f332f9a8f5f0`.
최종 관련 회귀는 lageunha CPU1 스레드 환경·4GiB·150초 상한에서
**112 passed/11.09초**였다. 원 SC 제어점 공용화가 원 국소식과 기존 시험을
유지함도 함께 확인했다. 새 자료를 물리 동질성 PASS로 표시하지 않는다.

재현은 같은 봉인 입력·새 출력 경로에서만 수행한다.

```bash
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 \
  python3 scripts/compare_cmfgen_radial_packet_cell.py \
  --run "$PACKET_FIELD" --formal-build "$FORMAL_V2" --prior "$PAIR_HISTORY" \
  --reference "$ORIGINAL_FIELD" --out NEW
```

이번 묶음은 공통 계수/좌표 함수의 실제 연결과 국소 재구성 선택 근거를 남겼다.
원자모델·전원소 SE/전하/RE·수송 공동수렴과 Si/S·스펙트럼의 최종 목표는
여전히 미달이며 **NOT_MET**를 유지한다.
