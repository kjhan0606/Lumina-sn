# 같은 F2 물질·주파수 격자에서 복사장 영향 — 2026-10-28

Si III 31점과 S III 34점에서 F2의 온도·전자밀도·인구·원자율 계약과
1115020점 격자를 고정하고 원 CMFGEN70 장과 F2 장의 광이온화·재결합
흐름을 비교한다. 원장은 log 주파수에서 보간하고 격자 밖 외삽은 금지한다.
같은 F2 단면·용해 평가로 해당 이온의 모든 BF 경로를 적분하며, 저장 F2
흐름을 독립 재현한다. 별도 정상해·수송·RE·스펙트럼은 계산하지 않는다.
원70은 비수렴 기준이므로 이것은 같은 물질의 장 차이이지 실제 CMFGEN
평형과의 차이를 모두 분해하거나 분포 목표 달성을 판정하는 시험이 아니다.

계산은 원소·점별 단회로 분리하며 기존 원본을 보존한다. F2 단일점 BF
재구성의 실측 약 37초와 전체 BF 적분 이력을 고려해 작업이 허용 시간 내
완료 가능한지 검토한다. 무작정 짧게 돌려 반복하지 않는다.

## 결과

`lumina_f2_si31_field_effect_20261028-jMFGT6`은 48.5초에 완료됐다.
각각 CPU1·4GiB·180초 상한이다. 원장과 F2 격자의 최솟값·최댓값은

각 이온에서 재현한 뒤 원장만 교체했다.

고정된 F2 인구에서 BF 순흐름(광이온화−자발−유도 재결합)은 Si III에서
원장 약 `−5.485`, F2 장 약 `0.000005` cm⁻³ s⁻¹이고, S III에서 원장
약 `+36.746`, F2 장 약 `0.000004` cm⁻³ s⁻¹이다. 자발 재결합은 같은
물질·온도에서 유지되고 유도 재결합은 장 교체에 따라 변했다. 이 BF 순흐름은
해당 이온 경계의 한 과정에 한정되며 충돌 및 다른 이온 경계의 기여를
대신하지 않는다.

원장 J를 새 격자로 보간했으므로 이것은 원 CMFGEN 이산 선·연속항 계산을
재실행한 결과가 아니다. 또한 F2 인구를 고정한 작용 비교라 장 교체 뒤의
자기일관 이온분포 변화량이 아니다. 다만 물질·격자·단면을 맞춘 조건에서도
복사장 차이가 Si와 S의 광이온화에 서로 다른 방향으로 영향을 준다는 점은
확인했다. 공동수렴과 최종 물리량·스펙트럼 목표는 미달성이다.
