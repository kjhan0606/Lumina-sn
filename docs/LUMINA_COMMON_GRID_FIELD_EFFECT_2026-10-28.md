# 같은 F2 물질·주파수 격자에서 복사장 영향 — 2026-10-28

Si III 31점과 S III 34점에서 F2의 온도·전자밀도·인구·원자율 계약과
1115020점 격자를 고정하고 원 CMFGEN70 장과 F2 장의 광이온화·재결합
흐름을 비교한다. 원장은 log 주파수에서 보간하고 격자 밖 외삽은 금지한다.
같은 F2 단면·용해 평가로 해당 이온의 모든 BF 경로를 적분하며, 저장 F2
흐름을 독립 재현한다. 별도 정상해·수송·RE·스펙트럼은 계산하지 않는다.
원70은 비수렴 기준이므로 이것은 같은 물질의 장 차이이지 실제 CMFGEN
평형과의 차이를 모두 분해하거나 분포 목표 달성을 판정하는 시험이 아니다.

계산은 원소·점별 단회로 분리하며 기존 원본을 보존한다. F2 단일점 BF
재구성의 실측 약 37초와 전체 BF 적분 이력을 고려해 작업이 허용 시간 내
완료 가능한지 검토한다. 무작정 짧게 돌려 반복하지 않는다.

## 결과

S 실행 `lumina_f2_s34_field_effect_20261028-5bRm0R`은 57.6초, Si 실행
`lumina_f2_si31_field_effect_20261028-jMFGT6`은 48.5초에 완료됐다.
각각 CPU1·4GiB·180초 상한이다. 원장과 F2 격자의 최솟값·최댓값은
일치하고 외삽은 없었다. F2 저장 광이온화·자발·유도 재결합 흐름을
각 이온에서 재현한 뒤 원장만 교체했다.

| 위치·이온 | 원장 이온당 광이온화율 s⁻¹ | F2 장 이온당 광이온화율 s⁻¹ | F2/원장 − 1 |
|---|---:|---:|---:|
| 31점 Si III | 4.87468033e-4 | 4.98812322e-4 | +2.33% |
| 34점 S III | 2.99444306e-4 | 2.72376490e-4 | −9.04% |

고정된 F2 인구에서 BF 순흐름(광이온화−자발−유도 재결합)은 Si III에서
원장 약 `−5.485`, F2 장 약 `0.000005` cm⁻³ s⁻¹이고, S III에서 원장
약 `+36.746`, F2 장 약 `0.000004` cm⁻³ s⁻¹이다. 자발 재결합은 같은
물질·온도에서 유지되고 유도 재결합은 장 교체에 따라 변했다. 이 BF 순흐름은
해당 이온 경계의 한 과정에 한정되며 충돌 및 다른 이온 경계의 기여를
대신하지 않는다.

원장 J를 새 격자로 보간했으므로 이것은 원 CMFGEN 이산 선·연속항 계산을
재실행한 결과가 아니다. 또한 F2 인구를 고정한 작용 비교라 장 교체 뒤의
자기일관 이온분포 변화량이 아니다. 다만 물질·격자·단면을 맞춘 조건에서도
복사장 차이가 Si와 S의 광이온화에 서로 다른 방향으로 영향을 준다는 점은
확인했다. 공동수렴과 최종 물리량·스펙트럼 목표는 미달성이다.

## 파장대별 기여 추적

같은 F2 물질과 격자에서 광이온화 흐름을 파장 구간으로 직접 적분해
원장과 F2 장의 차이를 어디에서 만드는지 확인한다. 문턱 한 점의 J를
전체 경로 기여로 대체하지 않으며, 구간별 합은 앞서 확인한 전체 흐름을
재현해야 한다. 별도 수송·정상해 없이 원소·점별 CPU1·4GiB·180초 상한의
새 실행을 사용한다. 직전 동일 경로 적분은 약 49~58초였다.

결과 디렉터리는 S `lumina_f2_s34_bf_bands_20261028-Y6MOSE`, Si
`lumina_f2_si31_bf_bands_20261028-AuPLRW`다. 각각 96.4초와 73.5초에
완료됐고 모든 구간의 합은 이전 전체 광이온화 흐름을 재현했다. 다음은
F2−원장의 광이온화 흐름 차이이며 단위는 cm⁻³ s⁻¹이다.

| 파장 | 31점 Si III | 34점 S III |
|---|---:|---:|
| 350–450 Å | −1.219 | −0.010 |
| 450–550 Å | −1.358 | −0.090 |
| 550–650 Å | −0.077 | −35.628 |
| 650–750 Å | +0.033 | −1.292 |
| 1000–1500 Å | −3.875 | −0.032 |
| 1500–2500 Å | +12.039 | +0.291 |
| 전체 파장 | +5.474 | −36.753 |

S III의 전체 감소 중 약 97%에 해당하는 `−35.628`이 550–650 Å에서
나왔다. Si III는 1500–2500 Å의 증가가 다른 대역의 감소를 상쇄하고도
남는다. 이는 여러 하위 준위와 경로의 실제 단면·인구를 포함한 흐름이며,
바닥준위 문턱 부근의 J 하나로 대표하지 않는다. 따라서 다음 수송 원인
조사는 S의 550–650 Å와 Si의 1500–2500 Å를 우선하되, 두 지점의 차이를
단일 공통 원인으로 단정하지 않는다. 장은 원장 log 주파수 보간이며
온도·ne·F2 인구 고정 결과라는 앞선 해석 한계는 그대로다.

## 원장 교체 후 단일 원소 정상분포

파장대별 BF 흐름만으로 정상분포를 예측할 수 없으므로, 같은 F2 물질·온도·
전자밀도·격자에서 원소 전체의 BF와 BB에 원장 또는 F2 장을 적용하여
S 34점과 Si 31점의 고정장 정상해를 비교한다. 충돌과 모든 이온 단계는
유지한다. 저장된 F2 단일점 BF를 SHA·장·물질·준위 분율로 확인해 재사용하고,
원장 BF는 해당 원소의 모든 경로를 재계산한다. 먼저 저장 F2 정상해를
재현해야 원장 결과를 해석한다. 단일 원소·고정 ne의 조건부 결과이며
공통 전하, RE, 새 수송, 원 CMFGEN의 수렴해가 아니다.
각 점은 Lageunha CPU1·4GiB·180초 상한, 별도 디렉터리에서 실행한다.

완료 결과는 S `lumina_f2_s34_twofield_se_20261028-cnY7E4`(98.3초),
Si `lumina_f2_si31_twofield_se_20261028-G7erxa`(71.9초)다. 기존 F2
선율과 BF의 단일 원소 정상해는 저장된 F2의 해당 인구를 정확히 재현했다.
기존 F2 BF 캐시는 각 결과와 배열 SHA 및 최종 trial의 Saha·FL/SL 분율·
occupation을 확인해 재사용했으며, 원장 BF 배열은 별도로 보존했다.

| 위치·이온 | 원70 입력 분율 | F2 물질+원장 정상해 | F2 물질+F2 장 정상해 | F2 장−원장 |
|---|---:|---:|---:|---:|
| 34점 S III | 0.48199246 | 0.49267184 | 0.51386783 | +0.02119599 |
| 31점 Si III | 0.20705331 | 0.19417438 | 0.18822444 | −0.00594994 |

동일 F2 T/ne·격자에서 원장과 F2 장의 교체는 S III를 약 +2.12%p,
Si III를 약 −0.595%p 움직였다. 이는 해당 단일점·단일 원소 정상해에서
복사장 차이가 분포에 미치는 조건부 기여를 직접 보여준다. 원70은 다른
T/ne의 미수렴 입력이므로 나머지 원70 차이를 곧바로 수치 오류나 특정
물리 기작에 배정할 수 없다. 원장을 새 격자로 보간한 비교이며 원
CMFGEN 이산 연산자를 재실행하지 않았다. 전하·RE·장 갱신 및 전90점
공동수렴과 최종 스펙트럼 목표는 여전히 미달성이다.
