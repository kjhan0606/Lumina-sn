## 수치 방법

각 공간 조각에서 r 중점의 chi_nu/eta_nu와 b=delta/dl을 동결한다.
eta는 기존 제공자의 true_eta+chi_es*동결 자체 J다. 원래 D와 dl에서 얻은
delta를 사용하고 특성선의 log(nu) 이동을 직접 따른다. 각 native bin을
청색→적색의 양의 affine(T,S) 맵으로 만들고 부분 bin·최고nu 밖 상수
연장을 포함한다. 맵의3delta는 I 표현에서 한 번만 반영한다.

고정 조각의 이동폭은 출력 nu와 무관하므로 순서 있는 두-stack 이동창으로
범위를 합성한다. NF에 선형인 맵 수이며 source/T를 역산하거나 서로 빼서
작은 양의 원천을 잃지 않는다. signed chi·gain과 중간 underflow는 기존
scaled Positive로 보존한다. native bin 안의 평균 chi/선형 eta SC 근사는
별도의 bin 세분1–16으로 검증한다.

입사장은 U=I_nu/nu^3를 선형 또는 양의 단조 harmonic cubic으로 보간한다.
cubic은 양의 Bernstein 제어점을 쓰고 실제 J/I 값을 clipping하지 않는다.
U 일정인 진공해를 보존하며, 평탄한 I의 유한 격자 오차는 별도 보간 오차다.
매 공간 조각의 보간 확산은 남을 수 있어 이 방법을 정확한 연속 수송이라고
주장하지 않는다. 제한된 red 출력에서도 cubic 이웃값을 잃지 않도록 공간
조각 수에 대응하는 red halo를 유지한다.

Astra의 이전 읽기 전용 평가01a17395-7043-7232-872c-871a9175c191은
이 후보의 강직성 회피·O(NF) 가능성을 지지했지만 공간 동결, 반복 보간,
부분 bin/경계·gain 보존을 미검증으로 남겼다. 운전자가 직접 구현·시험하며
새 정례 감사나 모델 의뢰를 추가하지 않는다.

## 다음 소형 대조의 확정 설계 — 구간 출구 프레임 고정

Astra의 평가와 운전자 유도를 합쳐 다음처럼 진행한다. 구현·직접시험은
운전자가 맡으며, 새 대형 실행/물질 피드백/생산 채택은 아직 하지 않는다.

한 원래 물리구간의 출구 Doppler를 D_exit라 하고
`d(s)=log(D(s)/D_exit)`, `Q_j(s)=exp(-3d(s))*I(s,nu_j*exp(d(s)))`를
운반한다. 입구에서 원 native I를 한 번 재구성해
`Q_entry=I_entry(nu_j*exp(d_entry))*exp(-3d_entry)`로 바꾼다.
공간 cell의 기존 comoving 맵T,S에는 이미3delta가 들어 있으므로
`T_fixed=T*exp(3*(da-db))`, `S_fixed=S*exp(-3db)`로 변환한다.
이를 같은 j의 Q에 적용하고 cell 사이에는 주파수 보간을 하지 않는다.
출구 db=0에서만 native I로 돌아온다. Q를 최종 observer I라고 부르지 않는다.

source의 native 인덱스 범위는 `[j+db/h,j+da/h]`다. 공통 정수부/소수부를
분리해 양끝 부분 bin과 그 사이 whole-bin 이동창을 순서대로 합성한다.
두 끝이 같은 bin에 있을 때는 하나의 부분 bin으로 계산한다. da>=db>=0이므로
source의 낮은 주파수 계수 연장은 필요 없다. 이 조건을 비단조 D에 확대하지
않는다. 공간 cell의 zero drift도 해당 공통 주파수 offset에서 처리해야 한다.

최고nu 밖은 현재와 같은 constant I/chi/eta다. 최고 bin을 포함한 상방 전체의
입사와 계수가 주파수 독립이면 모든 상방 I는 같은 scalar 식을 풀어,
매 cell 갱신 후 constant 연장과 입구의 한 번 연장이 대수적으로 같다.
Astra도 추가 확인에서 이 조건부 논증에 동의했고, 주의점을 최고 bin 바로
아래의 재구성 오차로 좁혔다. 비영 source·cell별 다른 물질/b의 최고 bin
대조로 구현을 확인한다. 실제 세 열은 최대625223+1414<1115020이므로
상방 경계를 만나지 않는다.

실제 대조는 다음 세 설정만 한 묶음으로 CPU1·8GiB·외부180초 안에서 한다.

1. fixed-frame uniform4 — 보존된 구간별 재투영 space4와 비교.
2. fixed-frame uniform16 — 같은 방식의 space16 및 uniform4와 비교.
3. fixed-frame endpoint16 — uniform16과 같은 cell 수로 끝점 집중 효과 확인.

endpoint16의 분할점은 사전에 `i/8 (i=0..8)`과
`2^-k,1-2^-k (k=4,8,16,24)`의 정렬된 합집합으로 고정한다(총16cell).
기준·원 자료·LINEAR_CHI·cubic U·초기J/I=0·독립세열은 동일하다.
비영 입구/진공과 최고nu source 경계는 기존 제조 사례를 재사용한다.
같은 mesh의 기존↔fixed 차이를 반복 재투영 효과로, fixed 내부의 mesh 차이를
공간 동결/기하 평가로 구분한다. 영입사만으로 입구 재구성이 검증됐다고
표시하지 않는다. 기준 미달이면 그대로 기록하고 무조건 uniform 확대하지 않는다.

이 의뢰는 종료·닫았다. 최종 우선순위는 수송 이산화 판별, 선택한 수송의
자체 J 폐합, 전원소 SE/RE·Si/S 분포, 최종 동일물질 observer 순서다.
이 문단은 아직 fixed-frame 구현/실제 대조 성공을 뜻하지 않는다.

## S II 용해식 조사 중 확인한 CONT_FREQ 규약 — 수치 대조 준비

native `GENOPAETA_V10`의 용해 분율 식과 B의 식은 소스상 같은 형태다.
반면 `COMP_OPAC`은 실제 FL이 아닌 별도 CONT_FREQ에서 연속항을 계산하고,
eta에 `(FL/CONT_FREQ)^3 exp[-h(FL-CONT_FREQ)/(kT)]`를 적용하며 chi의 유도
항을 이에 맞춰 보정한다. line 항은 실제 FL에서 더한다. 따라서 같은 FL의
저장 chi/eta를 비교해도 BF 평가 주파수가 같다는 보장은 없었다.

실제 참조 `CONT_FREQ`를 원 binary 주파수와 연결했다.611.0975/611.1251 Å의
연속항 평가 파장은611.345454 Å(각−121.58/−108.08km/s)다.673.5722,
714.9848,721.9815 Å의 평가 파장은 각각673.602608,715.081459,721.721251 Å다.
ASCII 출력의 반올림값을 그대로 입력하지 않고 대응하는 binary 원ν를 복원했다.
이 사실만으로15배 차이의 정량 원인을 확정하지 않는다.

다음 CPU 대조는 동일 계수 생산기를 이4개 CONT_FREQ에서 평가하고, native
연속항 보정식과 이전 직접 점의 실제 FL line 항을 합쳐 참조와 비교한다.
`cache-A.py`/`job-cache-A.slurm`, 격리 출력 `cache-A`, grammar CPU1·4GiB·
300초(내부270초)·GPU0·단회/no-requeue다. 정규화 상수를 맞추거나 용해항을
끄지 않는다. 새 수송/물질/observer 갱신은 없으며 아직 수치 대조 전이다.
