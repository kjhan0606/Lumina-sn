# 수송 정확도 대비 비용 개선 — 중점 동결 특성선 이동창

## 목적과 범위

전격자 자체 J1은 완성됐지만 공간4 SC의 원13003 오차가 약9%여서
정확도 합격이 아니다. 공간256·주파수4에서도 세 열은 각각
+0.1376%,+0.1390%,-0.3196% 차이다. 전체 균일 세분을 확대하지 않고
같은 fullSR 물리식으로 이 오차를 저렴하게 줄일 수 있는지 판별한다.
이 결과는 최종 Si/S 분포·SE/RE·스펙트럼 동질성을 대신하지 않는다.

현재1217831의 입력·코드·시간·J2 계산은 변경하지 않는다. 원 물질70·native90·
원 계수/기하·경계·원격자 주소를 재사용하며, 새 후보는 명시적 소형 경로다.
다른 물리 근사나 CMFGEN J 주입·opacity/강도 floor를 추가하지 않는다.

## 수치 방법

각 공간 조각에서 r 중점의 chi_nu/eta_nu와 b=delta/dl을 동결한다.
eta는 기존 제공자의 true_eta+chi_es*동결 자체 J다. 원래 D와 dl에서 얻은
delta를 사용하고 특성선의 log(nu) 이동을 직접 따른다. 각 native bin을
청색→적색의 양의 affine(T,S) 맵으로 만들고 부분 bin·최고nu 밖 상수
연장을 포함한다. 맵의3delta는 I 표현에서 한 번만 반영한다.

고정 조각의 이동폭은 출력 nu와 무관하므로 순서 있는 두-stack 이동창으로
범위를 합성한다. NF에 선형인 맵 수이며 source/T를 역산하거나 서로 빼서
작은 양의 원천을 잃지 않는다. signed chi·gain과 중간 underflow는 기존
scaled Positive로 보존한다. native bin 안의 평균 chi/선형 eta SC 근사는
별도의 bin 세분1–16으로 검증한다.

입사장은 U=I_nu/nu^3를 선형 또는 양의 단조 harmonic cubic으로 보간한다.
cubic은 양의 Bernstein 제어점을 쓰고 실제 J/I 값을 clipping하지 않는다.
U 일정인 진공해를 보존하며, 평탄한 I의 유한 격자 오차는 별도 보간 오차다.
매 공간 조각의 보간 확산은 남을 수 있어 이 방법을 정확한 연속 수송이라고
주장하지 않는다. 제한된 red 출력에서도 cubic 이웃값을 잃지 않도록 공간
조각 수에 대응하는 red halo를 유지한다.

Astra의 이전 읽기 전용 평가01a17395-7043-7232-872c-871a9175c191은
이 후보의 강직성 회피·O(NF) 가능성을 지지했지만 공간 동결, 반복 보간,
부분 bin/경계·gain 보존을 미검증으로 남겼다. 운전자가 직접 구현·시험하며
새 정례 감사나 모델 의뢰를 추가하지 않는다.

## 확인할 산출물과 자원

CPU1·8GiB 이내·소형 시험/실제 구간 외부180초·GPU0을 사용한다.
새 root에서 같은 원13003·J0=I0=0·보존된 독립 미세3열을 대조한다.
각 출력 상대차1e-4 기준은 유지하며, 실패하면 실패한 값과 비용을 남긴다.
공간4/16/64와 native bin1/4 세분을 먼저 비교한다. bin 세분은 ray 주파수
격자 세분과 다르므로 기존 SC의 주파수4와 같은 설정이라고 부르지 않는다.
새 전체장이나 자동 재시도는 이 소형 검토로 실행하지 않는다.

기존 SC·J1/J2와 실패 증거는 보존한다. 후보가 기준을 만족하더라도 전체장
정확도·산란 폐합·생산 Si/S율·SE/RE·observer는 따로 실제 증거가 필요하다.
재현은 `tests/test_lumina_fullsr_frozen.py`와 기존 원13003 비교기의
`--engine FROZEN_MIDPOINT` 명시 선택이다. 실제 실행 root/해시는 후속 기록한다.

## 선형 chi 모멘트 재사용 — 개선됐지만 아직 미달

별도 `LINEAR_CHI` 선택은 기존 `cmf_positive_moments.h`를 재사용한다.
native bin 안의 선형 chi·eta를 기존 양의 모멘트로 적분하며, 순 gain은
반사와 scaled T로, 내부 gain 봉우리는 effective chi=0 분할로 처리한다.
평균 chi 선택의 기존 ABI·증거는 유지한다. source가 실제로0인 경우에만
그 적분을 생략하며, 양의 source를 임계값으로 없애지 않는다.

독립 Gauss 적분과 signed chi/내부 gain·큰 gain, bin1/4 분할 불변성의
직접시험을 추가했다. 이 모멘트 코어는 선형-opacity 문제의 검증 자료이며
공간 동결이나 반복 주파수 보간까지 인증하지 않는다.
