### 3.1 원자료 행 직접 선택

셸 `s`에 대해 다음 집합을 만든다.

```text
A_s = {j : v_inner[s] ≤ CMFGEN.vel_mid[j] < v_outer[s]}
j_s = A_s에서 vel_mid가 가장 작은 원자료 행
```

### 3.2 T 입력의 의미

각 셸의 입력 T는 **선정된 원자료 행의 T를 그대로 복사**한다.

이는 CMFGEN T 곡선을 보간하거나 셸 평균 T를 추정하는 절차가 아니다. 선정점에서 비교할 새 이산 고정-T 입력을 정의한다. Lumina 셸 값을 그 셸 내부 표본점에서 평가한다는 이산화 규약도 함께 기록한다.

다음은 금지한다.

- 다른 CMFGEN 속도점으로 결과를 확장하기
- 미선정 행에 같은 T가 맞는다고 주장하기
- 셸 평균·연속 프로파일의 일치를 주장하기
- 빈 셸을 최근접값·평균·외삽으로 채우기
- 지도 그림에서 평활화로 미측정 칸을 채우기

따라서 산출 명칭은 **“셸별 원자료 표본점 지도”**이며 전 속도 연속지도가 아니다.

## 4. 측정량과 출력 계약

### 4.1 단계 분율

Saha 권위:

\[
f^{S}_{Zq,s}=\frac{n^{S}_{Zq,s}}{N_{Z,s}}.
\]

NLTE 권위:

\[
f^{N}_{Zq,s}=\frac{\sum_{\ell\in(Z,q)}n_{\ell,s}}{N_{Z,s}}.
\]

`N_Z`는 해당 실행의 원소 총수밀도다. 모델의 밀도·조성·원자질량 규약에서 독립 산출하고 생산 단계 총량과 대조한다. 원자질량을 임의의 정수 질량수로 대신하지 않는다.

단계 번호 `q`는 전하수이며 `0=I`, `1=II`다. `active_ions.csv`의 분광 단계 열과 혼동하지 않는다. 다음 집합을 구별한다.

- `P^S_Z`: 봉인 덱을 대응 소스가 읽어 생성하는 Saha 권위 생산 단계 집합. 관측 덤프나 참조 열에서 역으로 추정하지 않는다.
- `P^N_Z`: 실효 레인에서 실제 계산 대상이 되는 NLTE 단계 집합. 해당 단계의 개별 준위 집합은 소스의 projection과 기록자 순회에서 정한다.
- `C_Z`: 선정 시각의 공개 ionfrac 헤더가 제공하는 단계 집합. 헤더 라벨·NSTAGES·행 열수의 대응을 읽는다.
- 수치 비교 대상은 권위별 `P^a_Z ∩ C_Z`다. 지도 좌표는 `C_Z`를 유지하고, 생산 집합에 없는 참조 단계도 상태로 남긴다.

[저자 실행: 봉인 덱·대응 저장소 소스·기존 로그 판독] 현재 실물에서 읽은 집합은 다음과 같다.

| 원소 | `P^S_Z` | `C_Z` | Saha 수치 비교 단계 | `P^N_Z ∩ C_Z` |
|---|---|---|---|---|
| Ca | 1–5 | 0–4 | 1–4 | 1, 2 |
| Si | 1–5 | 0–4 | 1–4 | 1, 2 |
| S | 1–5 | 0–4 | 1–4 | 1, 2 |
| Fe | 1–6 | 0–5 | 1–5 | 1, 2 |
| Co | 1–6 | 0–5 | 1–5 | 1, 2 |
| Ni | 1–6 | 0–5 | 1–5 | 1, 2 |

근거 경로에서 `SRC=/gpfs/kjhan/lumina/dproxy_audits/worktree_364ee72_dualauth`다.

- `BASE/input/model/ionization_energies.csv`와 `SRC/src/lumina_atomic.c:2061–2102`: 원소별 ionization 행 수가 `k`, 최소 단계가 `b`이면 `b,…,b+k`를 생성한다. 현재 여섯 원소는 모두 `b=1`이다.
- `SRC/src/lumina_cuda.cu:11299–11310`: 모든 셸과 `atom_data.n_ion_pops` 전체를 순회하여 생산 단계 밀도를 출력한다.
- 공개 파일별 `#NSTAGES`·`#vel_mid` 헤더: Ca·Si·S는 5단계, Fe·Co·Ni는 6단계다. O-0의 일괄 단계 수 표기는 이 원소별 정의의 대용이 아니다. O-0 원문은 보존한다.
- `SRC/src/lumina_plasma.c:10057–10064,16796–16844`와 `BASE/stdout.log:207–219`: 현 레인의 여섯 원소 NLTE 대상은 각각 II·III이며 개별 준위 수는 Si 125·147, Ca 62·232, Fe 2599·1500, S 322·256, Co 2558·3214, Ni 1000·1000이다.
- `SRC/src/lumina_plasma.c:20926–20948`: 기록자는 superlevel 수가 아니라 projection의 개별 준위를 출력한다.

따라서 Ca·Si·S의 생산 단계 5와 Fe·Co·Ni의 생산 단계 6은 참조 비교 행을 만들지 않지만, 값이 0이든 양수든 생산 피복과 `Σ_(q∈P^S_Z) n^S_Zq`의 원소 총량 대조에 포함한다. 이 행을 덤프에서 제거하거나 분모 계산에서 제외하지 않는다. 별도 참조값을 만들지도 않는다. 참조에 있는 단계 0은 현재 생산 집합에 없으므로 0인 population으로 대체하지 않는다.

생산 피복은 관측한 생산 단계·개별 준위 키와 사전에 읽은 생산 집합의 일치로, 비교 피복은 참조 단계별 값 또는 명시적 상태의 존재로 확인한다. `P^S_Z=C_Z` 또는 `P^N_Z=C_Z`를 요구하지 않는다. 등록 생산 집합 밖의 임의 행을 정상 추가 단계로 인정하는 것도 아니다.

판독 재현 명령은 `cat "$BASE/input/model/ionization_energies.csv"`, `head -n 8 data/standart_data1/toy06/ionfrac_{ca,co,fe,ni,si,s}_toy06_cmfgen.txt`, 위 소스·로그에 대한 `sed -n '<시작>,<끝>p' <경로>`다. 조회 소스 SHA-256은 atomic=`cfe80899dab6c67fb00d6e7ea27d28c23af7d739913e7878ff33cfdccf596ae2`, plasma=`90fd73cc51cae34649533fc8ed87f84a39e08521b4fdd6fb8a57b107b959210d`, cuda=`f2eb27a8e408c9ddd768a1acbaddcaea3477b78af1b158950ae8dbb47027e8a5`다. 이 판독은 §2.1의 실물 바이너리 동일성 확인이나 §4.3의 최종 공개 세대 연결을 완료한 주장이 아니다.

- 참조가 제공하는 단계만으로 분모를 재정규화하지 않는다.
- 권위별 생산 집합에 없는 참조 단계는 `NOT_SOLVED`; 생산 집합에 있어야 할 단계·준위 덤프가 없으면 `INPUT_PENDING`이다. 실제 미계산과 관측 결손을 구별한다. 생산 집합 자체가 미확인이면 `NOT_SOLVED`로 추정하지 않는다.
- NLTE 결손을 Saha·LTE 분배·S-역산·관측 준위 외삽으로 메우지 않는다.
- 실제 계산한 NLTE 단계·개별 준위 목록은 코드·덱·실효 구성에서 실행 전에 봉인하고 기존 writer 계약에 둔다. `active_ions.csv` 전체를 계산 집합으로 삼지 않는다. 현 소스에서 `LUMINA_NLTE_SKIP_Z=14`는 nebular tau 유지와 line source 쓰기를 제어하며 Si의 NLTE 계산·준위 덤프 제거 조건이 아니다(`SRC/src/lumina_plasma.c:19907–19920`). 키 이름만 보고 Si를 모집단에서 빼지 않는다. 과거 검수의 skip-Z 해석은 기록으로 보존하되 이 정의의 근거로 승계하지 않는다.
- 정확한 0은 보존한다. 음수·비유한 값은 교정하지 않고 실패 증거로 보존한다.

비교량:

\[
\Delta f^a_{Zq,s}=f^a_{Zq,s}-f^C_{Zq,j_s},
\qquad a\in\{S,N\}.
\]

`Δf`와 `100Δf` percentage point를 크기로 기록한다. 분율 행의 부가 비·dex·절댓값 dex·dex 표현 구간은 생성·검증 대상에서 삭제한다. 원 population·원소 총량·분율·참조 원값은 보존한다. 이 삭제는 §4.2의 전자밀도 비·dex와 §6의 전자밀도 표현 구간에 적용하지 않는다.

### 4.2 전자밀도

최종 공개 상태의 `n_e`를 사용한다.

\[
r_{e,s}=n^L_{e,s}/n^C_{e,j_s},\qquad
d_{e,s}=\log_{10}r_{e,s}.
\]

원값·비·부호 있는 dex·절댓값·표본 위치를 모두 기록한다. 전하 합으로 계산한 수를 실제 공개 `n_e`의 대용으로 쓰지 않는다.

### 4.3 기록자의 세대 정합

O-0 §5는 배선 실존의 근거이며 다음을 증명하지 않는다.

- 반복 번호가 없는 최종 파일의 정확한 공개 세대
- NLTE 덤프 호출 카운터와 수송 반복 번호의 일치
- private trial과 최종 commit의 일치
- 동일 세대의 T·`n_e`·Saha·NLTE 동시 관측

따라서 오프라인에서 **정확한 base 바이너리의 소스 계보**를 대상으로 호출 순서·공개 시점·포인터 복원·출력 도달성을 확인한다. 후보 계산의 덤프를 최종 공개 상태라고 읽지 않는다.

기존 출력으로 이 연결을 입증할 수 없으면 `INPUT_PENDING`이다. GPU 획득런이나 추가 반복으로 조사하지 않는다. 새 생산 계측이 필요하면 변경 범위를 계약 개정으로 먼저 등록한다.

지도에서 결손·미계산·T 불일치·세대 불명은 서로 다른 상태로 표시한다. 한 칸에 여러 사유가 있으면 원값과 사유를 보존하며 T 불일치가 음수·비유한 값의 증거를 덮지 않는다.

`N_Z=0`이면 분율과 분율 차이는 `UNDEFINED`로 남긴다. 전체 생산 피복이 확인되고 해당 원소의 생산 population도 모두 정확한 0인 경우는 원소 부재에 따른 정의 불능이며 덤프 결손이나 물리 실패로 승격하지 않는다. `N_Z=0`인데 양수 population이 있거나 음수·비유한 값이 있으면 정상 원소 부재로 처리하지 않는다. 이 규칙은 전자밀도의 로그 미정의나 E-NE 판정 불능을 면제하지 않는다.

지도 완료는 §4.1의 참조 좌표마다 계산 가능한 값 또는 입증된 미계산·원소 부재 상태가 있는 것을 뜻한다. 미계산·원소 부재 칸을 수치 측정 성공으로 세지 않는다. 필수 관측 결손·세대 불명·새 레인의 T 불일치는 완료를 막되 이미 읽은 다른 셀을 삭제하지 않는다.

selftest 양성·주입별 결과는 §10의 두 selftest 명령에 이미 요구한 stdout·stderr·rc로 보존한다. 도구 해시와 로그 경로는 기존 identity에 연결한다. 별도 selftest JSON을 요구하거나 prepare 안에서 같은 selftest를 재실행하지 않는다. 실제 loader 시험과 생산 경로 시험 의무는 유지한다.

실제 출력 manifest와 등록 게이트 결과의 유일한 결과 저장처는 summary다. summary의 결손·극값 항목은 지도 좌표와 필요한 수치·사유만 가리키며 지도 행 전문을 복제하지 않는다. 별도 output_manifest·gates 파일과 summary의 중복 전체 `status`를 생성하지 않는다. 전체 결과는 TM 분기, 개별 검사는 게이트 결과, 물리 가설은 hypothesis로 구별한다.

계수 기준을 고정한다. 필수 증거파일 수는 이 절의 경로 표 행 수이며 12→9다. 원시 생산 출력·명령 로그·기존 봉인 manifest는 이 수에 포함하지 않으며 삭제 대상이 아니다. 게이트 수는 §8 명부의 독립 판정 ID 수이며 8→5다.

운영 판정 상태필드는 파일별 최상위 status, 게이트별 status, 지도 셀 status, summary의 branch·hypothesis, STAGE_IDENTITY의 state를 각각 하나의 스키마 경로로 센다. 행 반복·시험 fixture 내부 상태·사유 문자열·원시 실행 로그는 중복 계수하지 않는다. 현 구현의 파일별 status 8 + 게이트 status 8 + 셀 status 1 + branch·hypothesis 2 + staging state 1 = 20에서, 개정 후 파일별 status 4(identity·writer·expectations·resource) + 게이트 status 5 + 셀 status 1 + branch·hypothesis 2 + staging state 1 = 13으로 줄인다. 이는 명시한 운영 판정 필드의 수이며 구현 내부 모든 진단 필드의 총수라는 주장은 아니다.

## 6. 사전 기대치와 작동 확인

### 6.1 런에서만 판정할 물리 가설

**E-NE: 선정 표본 전체에서 쌍둥이-T 레인의 전자밀도 차이 중앙값이 base보다 작다.**

\[
M_{\rm twin}=\operatorname{median}_s|d^{\rm twin}_{e,s}|,
\qquad M_{\rm base}=\operatorname{median}_s|d^{\rm base}_{e,s}|.
\]

판정은 원자료와 출력 형식의 자릿수에서 유도한 표현 구간을 사용한다.

- `upper(M_twin) < lower(M_base)`이면 **감소 관측**.
- `lower(M_twin) > upper(M_base)`이면 **증가 관측**.
- 나머지는 **표현 정밀도 내 미분리**.

자의적인 epsilon·floor·맞춤 계수는 사용하지 않는다. 구간 계산법은 합성 수와 독립 산술로 오프라인 검증한 뒤 실행 전에 봉인한다.

**코드·구성에서 강제되는가? 아니오.** T 입력은 강제하지만 CMFGEN `n_e`를 입력하거나 맞추지 않는다. 복사장·단계 분배·밀도 차이 때문에 증가할 수도 있다.

가설의 근거는 O-0 §4와 상위 설계 §2의 T 교란 문제다. 그 근거는 감소의 정리나 감소 배수 예측이 아니다. 결과가 증가여도 지도 측정 자체를 실패로 바꾸지 않는다.

**base 선적용:** base를 자기 자신과 비교하면 구간이 겹치므로 ‘감소’ 조건을 충족하지 않는다. 이 자기비교는 작동 확인이며 물리 기대치가 아니다.

### 6.2 분율의 기대치

실측 base 분율과 독립 예측이 없으므로 **분율 개선 방향·배수·허용오차는 등록하지 않는다**. 이번 런에서 얻을 각 `Δf`가 측정 대상이다.

“Fe IV가 지배할 것”, “분율이 일정 배수 개선될 것”, “Saha와 NLTE가 같을 것”을 기대치로 만들지 않는다. 지도를 얻은 뒤 수리 단의 표적을 정하는 것은 후속 결정이다.

### 6.3 작동 확인으로만 등록하는 항목

| 항목 | 강제 여부 | 분류 |
|---|---|---|
| 선정 원자료 T를 입력 파일에 복사 | 생성기에서 강제 | 작동 확인 |
| 공개 T가 등록 T와 일치 | 고정-T 구현의 계약 | 작동 확인 |
| 지정 표본의 생산 모집단 피복과 참조 단계별 비교값·상태 피복 | §4.1·§4.4의 출력·판독 계약 | 작동 확인 |
| 분율 산식·단계 합·원소 총량 연결 | 정의·보존 관계 | 작동 확인 |
| 반복수·바이너리·실효 exports 일치 | 구성에서 강제 | 작동 확인 |
| CMFGEN 대비 분율·`n_e` 차이 | 강제되지 않음 | 물리 측정 |
| E-NE 감소 여부 | 강제되지 않음 | 반증 가능한 물리 가설 |

## 7. offline-first 집행 순서

### O-1. 기전 오프라인 특정

T를 읽는 위치, 후보 물질 계산, 최종 공개, Saha·NLTE·`n_e` 기록자까지 연결한다. 목표는 **T 불일치라는 비교 교란을 제거할 수 있는지**의 확인이다. 이 단계에서 잔여 어긋남의 물리 원인을 확정하지 않는다.

추가로 확인할 사항:

- 진단용 균일 T 키와 고정 프로파일의 상호작용
- 초기 상태와 후속 공개 상태의 T 적용 시점
- strict env가 덤프 키를 수용하는지
- 기존 stager의 균일 T·진단 비교 전제가 새 레인을 거부하거나 잘못 인증하는지
- `n_e`와 population의 동일 공개 세대 여부

### O-2. 수리안 오프라인 검증

이 단의 수리안은 **입력 T 대응과 판독의 비교 자격을 바로잡는 것**이다. Saha 반복기·율·NLTE 방정식은 변경하지 않는다.

sol은 원자료 직접 선택, 프로파일 생성, 세대 대응, 축소된 지도 산술, 실행 입력 delta, 결함 주입 selftest를 구현한다. 정상·결손에 따라 별도 지도·게이트 판정기를 유지하지 않고 동일한 셀 판독·판정 경로에서 관측 가능한 값을 보존한다. 기존 고정-T loader의 실제 경로를 사용한 CPU 시험으로 입력 소비를 확인한다. selftest의 기대값은 검사 대상 구현에서 생성하지 않으며 실제 생산 경로를 시험한다. 삭제한 물리 지표만을 위한 시험은 범위에서 제외하고, 유지한 산술·구간·집계·가설·보존·자원 검증을 삭제하지 않는다.

기존 출력·기존 바이너리로 계약을 만족시킬 수 없으면 여기서 중단한다. 자료획득 GPU 런을 추가하지 않는다.

### O-3. 기대치·자원·입력 봉인

다음을 모두 확정한 뒤 운전자가 계약 1건의 커밋을 만든다.

- 표본·원자료·T 프로파일·실효 exports
- source·binary identity
- 기록자의 공개 세대 계약
- §6 표현 구간과 가설 판정식
- base 선적용 및 음성대조 결과
- 자원 자격과 신규 출력량
- 사전감사·코드 검수 결과

계약 개정은 `OLD:`/`NEW:` 쌍으로 남긴다. 결과를 본 뒤 표본·분모·문턱·허용오차를 바꾸지 않는다.

### R-1. 판정런 1회

선행조건 충족 후 새 루트에서 한 번만 실행한다.

물리 입력 변경은 등록 T 프로파일이다. 추가 변경은 기존 덤프 활성화와 경로 재배치에 한정하며 전체 실효 exports delta를 봉인한다. 원자 덱·밀도·조성·반복수·수송 설정·NE-closure 상태를 임의로 바꾸지 않는다.

시간 초과·중도 실패·필수 덤프 결손은 그 상태로 보존한다. 자동 재런·관찰런·OFF 인증 GPU 런·반복수 연장은 없다.

## 8. 게이트와 음성대조

아래는 개정 후 게이트 명부이며 사용 자격은 **미확정**이다. 종전 시험·검수 결과는 집행 기록에 보존하지만 개정 구현의 PASS로 승계하지 않는다. 각 게이트는 정상 fixture의 수용과 해당 결함 주입의 FAIL을 실제 생산 경로에서 시연한 뒤에만 사용 자격을 얻는다. 단순히 예상 rc를 출력하거나 실제 관측과 분리된 참/거짓 facts만 시험하는 selftest는 인정하지 않는다. 통합한 게이트에서도 기존 실패 종류를 검증하며, 검사별 실패 사유와 소비 증거를 남긴다.

기존 고정-T 범위 가드는 이 단에서 확대하거나 강화하지 않는다. 정확해가 위반 가능한 새로운 clamp·floor·cap·jitter·유사 가드를 만들지 않는다.

사전등록·발주·문서 정본·운전자 위생·게이트 참조·명부 검사는 기존 기계를 사용하고 내장 selftest 결과를 함께 기록한다. 이 기안에는 실행하지 않은 검사 PASS를 적지 않는다.
