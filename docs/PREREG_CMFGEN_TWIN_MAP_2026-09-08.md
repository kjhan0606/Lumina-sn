### Q-LEAN — 이번 개정의 삭제·통합 근거

다음은 기안자의 범위 제안이며 사전감사 답안을 대신하지 않는다. 새 사전감사는 `CLAUDE.md`의 Q-GOAL과 Q-LEAN L1–L4를 독립적으로 적용한다.

**L1 — 산출과 소비 지점.** 물리 산출은 선정 표본의 권위별 `f_q`, `Δf`, percentage point와 공개 `n_e`의 원값·비·부호 dex다. E-NE와 그 표현 구간은 전 셸을 독립 재현한 경우의 관측 가설로 유지한다. 자동 인증을 소비 지점으로 삼았던 facts·게이트별 PASS·자동 TM 판정을 삭제한다. 원자료→물리량 계산과 운전자 독립 재현에 필요한 원값·키·권위·세대·분모·출력 정밀도는 삭제하지 않는다.

**L2 — 게이트。** 종전 게이트가 지목한 실패는 실재 가능하지만, 게이트 PASS가 그 실패 부재를 인증한다는 주장은 F1–F7로 지지되지 않는다. 물리 관측 채택을 자동 인증하는 다섯 판정 ID는 폐지한다. 확인할 실제 대상은 아래처럼 운전자 독립 재현과 실행 안전 통제로 옮긴다. 같은 자료에서 facts를 만들고 다시 PASS를 계산하는 중복은 남기지 않는다.

| 종전 대상 | 実在する 실패·중복 | 개정 2의 소비 지점 |
|---|---|---|
| G-ID·G-PRESERVE | 다른 계보·경로 침범·봉인 변경; 목적지 확인은 겹치지만 전후 불변은 별개 | 실물 hash·실효 delta의 직접 대조와 봉인 무접촉 실행 통제 |
| G-COORD·G-TE | 잘못된 표본·단위·T 복사·loader 미소비; 셸 피복 확인은 공유 | 원자료 키 재선정·실제 loader 시험·공개 T 전 셸 대조 |
| G-POP·G-EPOCH | 생산·참조 집합 혼동·잘못된 분모·준위 결손·이전 세대 | 코드·덱에서 정한 집합과 실제 원출력의 권위별 직접 재현 |
| G-METRIC | 셀 산술·표현 구간·BASE 및 새 레인 집계 오류; 피복 확인으로 대체 불가 | 원값부터 독립 계산한 수치와 §6 관계식의 재현 |
| G-RUN | 미등록 실행·실패 종단·비용 초과; identity 대조로 대체 불가 | 적격 runner의 사전 통제와 정확한 실행·비용 기록 |

삭제하는 것은 자동 인증 경로다. 실제 원자료를 읽는 경로, 산술, 실패 원값·좌표·사유의 보존, 실행 안전 통제는 남긴다. 생산 판독기는 수치·관측 상태를 출력하고 운전자는 그것을 원자료에서 독립 재현한다. 판정자는 재현 사실과 명시된 한계를 소비하여 채택 범위와 TM 분기를 판정한다. 재현 결과를 다시 참/거짓 facts 벡터로 바꾸는 새 인증기를 만들지 않는다.

**L3 — 단계 구성.** 이 단은 최종목적에 직접 도달하는 단이 아니라, 수리 표적 선택을 위한 진단 한 걸음이다. 내부 실행은 오프라인 준비→등록 런 1회→지도 판독·운전자 독립 재현으로 유지한다. 재현은 같은 원출력의 CPU 판독이며 GPU 반복 실행이 아니다. 준비 전에 실제 참조의 전체 블록과 선정 키를 사용한 사설 정상 시험으로 분율·전자밀도 지도를 판독할 수 있는지 확인한다. F2 때문에 분율 관측 자체가 사라지는 경로를 그대로 두고 GPU 런을 소모하지 않는다. 이 확인에 필요한 최소 판독 수정은 sol의 변경집합 안에서 하되, 자동 인증기 복구를 별도 단계로 추가하지 않는다. 준비 중 BASE 분율 지도와 중복 selftest·증거 직렬화를 생략하면 같은 등록 물리량을 얻을 수 있다. BASE 재런·획득런·추가 반복은 필요하지 않다. D-C-2·D-D는 상위 설계에 있는 더 직접적인 수리 후보지만, 이 지도와 같은 측정량을 이미 제공하는 대안으로 확인된 것은 아니다.

**L4 — 삭제·통합 대상.** 개정 1의 삭제 범위에 더하여 `prepare/analyze`의 인증용 facts 구성, `gate_check`·`gate_result`와 그 전용 `require_evidence_keys`·`fixture` 경로, `decide_branch` 자동 판정, 게이트별 PASS와 summary의 자동 branch·hypothesis 결과 생성을 삭제 대상으로 지정한다. 함수 안에 섞여 있는 실제 값 판독·실패 검출·산술·안전 검사는 해당 소비 경로에 남기며 함수 이름을 단위로 무조건 삭제하지 않는다. facts 사전만 변조하는 시험과 TM-D·게이트 전건 PASS 자체를 성공 기대값으로 삼는 시험은 삭제하고, 필요한 정상·음성 시험은 실제 원자료 판독·산술·안전 경로에서 수행한다.

남기는 것은 anchors·고정 T 입력, 공개 T·전자밀도, 생산 Saha 전체 단계, NLTE 개별 준위와 키, 독립 모델 분모, 참조 헤더·원값, 공개 세대 연결 증거, BASE 전자밀도, 표현 구간·중앙값·극값, 관측 결손·실패 사유, 정확한 identity, 자원·봉인 통제와 직접 재현 로그다. E-NE 규칙과 피연산자는 유지하되 판정 결과의 저작은 판정자에게 옮긴다. 원시 생산 출력·기존 파일·시험 로그·검수문은 삭제하지 않는다. 구현 후 코드량 감소는 실제 diff로 측정하며 기안에서 감소치를 예고하지 않는다.

[저자 실행: 파일 판독] 현 구현은 Python 1,722행·shell 379행, 합계 2,101행이다. 전부를 계측·게이트 코드라고 분류한 수는 아니며, 개정 후 코드량 감소치는 아직 미측정이다. 새 계측·새 게이트·새 기대치·자원 증액은 제안하지 않는다. 필요한 검증을 숨긴 채 코드량 감소를 주장하지 않는다.

3회차 검수 중 생산·비교 모집단의 정의 부재는 §4.1에서 해소한다. 집계 검증·빈 증거 수용·쓰기 보호·부분 참조 보존·신규 저장 총량 누락은 기존 요구를 위반한 구현 결함으로 남긴다. BASE 분율 결손의 전역 차단도 종전 §12와 어긋난 구현이며, 이번에는 소비되지 않는 BASE 분율 처리 자체를 범위에서 삭제한다. 이 기안은 해당 결함의 수정이나 검수 해소 판정이 아니다.

## 3. 보간 없는 표본 정의와 비교 한계

### 3.1 원자료 행 직접 선택

셸 `s`에 대해 다음 집합을 만든다.

```text
A_s = {j : v_inner[s] ≤ CMFGEN.vel_mid[j] < v_outer[s]}
j_s = A_s에서 vel_mid가 가장 작은 원자료 행
```

단위 변환만 허용한다. `A_s`가 비면 `INPUT_PENDING`이며 가까운 다른 셸의 값으로 메우지 않는다.

`phys`와 각 `ionfrac` 파일에서 시각·속도 키가 일치하는 같은 행을 사용한다. 행 번호만으로 조인하지 않는다. 중복 속도·시각 불일치·원소 파일 결손은 해당 비교의 실패이며 전체 필수 지도 완료를 막는다. 실패한 원소·셸 때문에 다른 원소·셸의 판독 가능한 원값과 비교값을 지우지 않는다.

**[저자 실행: 소형 원자료 판독]** 현재 입력에는 이 규칙으로 모든 base 셸에 표본이 존재했다. 선정된 블록 내 0기반 행 인덱스는 다음과 같다.

```text
21,23,25,27,28,30,31,33,36,39,
43,46,50,52,54,56,58,60,61,63,
64,65,66,67,68,69,70,71,72,73,
74,75,76,77,78,79,80,81,82,83,
84,85,87,88,89,90,91,92,93,94
```

운전자는 이 목록을 독립 재현하고 원문 행·파일 해시와 함께 `anchors.csv`에 봉인한다.

### 3.2 T 입력의 의미

각 셸의 입력 T는 **선정된 원자료 행의 T를 그대로 복사**한다.

이는 CMFGEN T 곡선을 보간하거나 셸 평균 T를 추정하는 절차가 아니다. 선정점에서 비교할 새 이산 고정-T 입력을 정의한다. Lumina 셸 값을 그 셸 내부 표본점에서 평가한다는 이산화 규약도 함께 기록한다.

다음은 금지한다.

- 다른 CMFGEN 속도점으로 결과를 확장하기
- 미선정 행에 같은 T가 맞는다고 주장하기
- 셸 평균·연속 프로파일의 일치를 주장하기
- 빈 셸을 최근접값·평균·외삽으로 채우기
- 지도 그림에서 평활화로 미측정 칸을 채우기

따라서 산출 명칭은 **“셸별 원자료 표본점 지도”**이며 전 속도 연속지도가 아니다.

### 3.3 조건 불일치 장부

| 축 | 계약상 처리 | 무효화되는 주장·칸 |
|---|---|---|

| 격자 | 원자료 점 대 Lumina 셸 이산값 | 연속 곡선·셸 평균·격자 수렴 오차 주장 불가 |
| T | 선정점의 입력 T와 실제 공개 T를 확인 | 불일치한 표본의 쌍둥이-T 비교 무효 |
| 밀도·조성 | base를 유지하고 차이를 별도 기록 | 잔차를 원자율·배선 오류 하나에 귀속할 수 없음 |

| population 권위 | Saha와 NLTE를 분리 | 둘을 합쳐 단일 NLTE 분율이라고 부를 수 없음 |
| 수송 레인 | base 레인을 유지 | MC 스펙트럼 재현을 직접 입증하지 않음 |

## 4. 측정량과 출력 계약

### 4.1 단계 분율

Saha 권위:

\[
f^{S}_{Zq,s}=\frac{n^{S}_{Zq,s}}{N_{Z,s}}.
\]

NLTE 권위:

\[
f^{N}_{Zq,s}=\frac{\sum_{\ell\in(Z,q)}n_{\ell,s}}{N_{Z,s}}.
\]

`N_Z`는 해당 실행의 원소 총수밀도다. 모델의 밀도·조성·원자질량 규약에서 독립 산출하고 생산 단계 총량과 대조한다. 원자질량을 임의의 정수 질량수로 대신하지 않는다.

단계 번호 `q`는 전하수이며 `0=I`, `1=II`다. `active_ions.csv`의 분광 단계 열과 혼동하지 않는다. 다음 집합을 구별한다.

- `P^S_Z`: 봉인 덱을 대응 소스가 읽어 생성하는 Saha 권위 생산 단계 집합. 관측 덤프나 참조 열에서 역으로 추정하지 않는다.
- `P^N_Z`: 실효 레인에서 실제 계산 대상이 되는 NLTE 단계 집합. 해당 단계의 개별 준위 집합은 소스의 projection과 기록자 순회에서 정한다.
- `C_Z`: 선정 시각의 공개 ionfrac 헤더가 제공하는 단계 집합. 헤더 라벨·NSTAGES·행 열수의 대응을 읽는다.
- 수치 비교 대상은 권위별 `P^a_Z ∩ C_Z`다. 지도 좌표는 `C_Z`를 유지하고, 생산 집합에 없는 참조 단계도 상태로 남긴다.

[저자 실행: 봉인 덱·대응 저장소 소스·기존 로그 판독] 현재 실물에서 읽은 집합은 다음과 같다.

| 원소 | `P^S_Z` | `C_Z` | Saha 수치 비교 단계 | `P^N_Z ∩ C_Z` |
|---|---|---|---|---|
| Ca | 1–5 | 0–4 | 1–4 | 1, 2 |
| Si | 1–5 | 0–4 | 1–4 | 1, 2 |
| S | 1–5 | 0–4 | 1–4 | 1, 2 |

따라서 Ca·Si·S의 생산 단계 5와 Fe·Co·Ni의 생산 단계 6은 참조 비교 행을 만들지 않지만, 값이 0이든 양수든 생산 피복과 `Σ_(q∈P^S_Z) n^S_Zq`의 원소 총량 대조에 포함한다. 이 행을 덤프에서 제거하거나 분모 계산에서 제외하지 않는다. 별도 참조값을 만들지도 않는다. 참조에 있는 단계 0은 현재 생산 집합에 없으므로 0인 population으로 대체하지 않는다.

생산 피복은 관측한 생산 단계·개별 준위 키와 사전에 읽은 생산 집합의 일치로, 비교 피복은 참조 단계별 값 또는 명시적 상태의 존재로 확인한다. `P^S_Z=C_Z` 또는 `P^N_Z=C_Z`를 요구하지 않는다. 등록 생산 집합 밖의 임의 행을 정상 추가 단계로 인정하는 것도 아니다.

판독 재현 명령은 `cat "$BASE/input/model/ionization_energies.csv"`, `head -n 8 data/standart_data1/toy06/ionfrac_{ca,co,fe,ni,si,s}_toy06_cmfgen.txt`, 위 소스·로그에 대한 `sed -n '<시작>,<끝>p' <경로>`다. 조회 소스 SHA-256은 atomic=`cfe80899dab6c67fb00d6e7ea27d28c23af7d739913e7878ff33cfdccf596ae2`, plasma=`90fd73cc51cae34649533fc8ed87f84a39e08521b4fdd6fb8a57b107b959210d`, cuda=`f2eb27a8e408c9ddd768a1acbaddcaea3477b78af1b158950ae8dbb47027e8a5`다. 이 판독은 §2.1의 실물 바이너리 동일성 확인이나 §4.3의 최종 공개 세대 연결을 완료한 주장이 아니다.

- 참조가 제공하는 단계만으로 분모를 재정규화하지 않는다.
- 권위별 생산 집합에 없는 참조 단계는 `NOT_SOLVED`; 생산 집합에 있어야 할 단계·준위 덤프가 없으면 `INPUT_PENDING`이다. 실제 미계산과 관측 결손을 구별한다. 생산 집합 자체가 미확인이면 `NOT_SOLVED`로 추정하지 않는다.
- NLTE 결손을 Saha·LTE 분배·S-역산·관측 준위 외삽으로 메우지 않는다.
- 실제 계산한 NLTE 단계·개별 준위 목록은 코드·덱·실효 구성에서 실행 전에 봉인하고 기존 writer 계약에 둔다. `active_ions.csv` 전체를 계산 집합으로 삼지 않는다. 현 소스에서 `LUMINA_NLTE_SKIP_Z=14`는 nebular tau 유지와 line source 쓰기를 제어하며 Si의 NLTE 계산·준위 덤프 제거 조건이 아니다(`SRC/src/lumina_plasma.c:19907–19920`). 키 이름만 보고 Si를 모집단에서 빼지 않는다. 과거 검수의 skip-Z 해석은 기록으로 보존하되 이 정의의 근거로 승계하지 않는다.
- 정확한 0은 보존한다. 음수·비유한 값은 교정하지 않고 실패 증거로 보존한다.

비교량:

\[
\Delta f^a_{Zq,s}=f^a_{Zq,s}-f^C_{Zq,j_s},
\qquad a\in\{S,N\}.
\]

`Δf`와 `100Δf` percentage point를 크기로 기록한다. 분율 행의 부가 비·dex·절댓값 dex·dex 표현 구간은 생성·검증 대상에서 삭제한다. 원 population·원소 총량·분율·참조 원값은 보존한다. 이 삭제는 §4.2의 전자밀도 비·dex와 §6의 전자밀도 표현 구간에 적용하지 않는다.

### 4.2 전자밀도

최종 공개 상태의 `n_e`를 사용한다.

\[
r_{e,s}=n^L_{e,s}/n^C_{e,j_s},\qquad
d_{e,s}=\log_{10}r_{e,s}.
\]

원값·비·부호 있는 dex·절댓값·표본 위치를 모두 기록한다. 전하 합으로 계산한 수를 실제 공개 `n_e`의 대용으로 쓰지 않는다.

### 4.3 기록자의 세대 정합

O-0 §5는 배선 실존의 근거이며 다음을 증명하지 않는다.

- 반복 번호가 없는 최종 파일의 정확한 공개 세대
- NLTE 덤프 호출 카운터와 수송 반복 번호의 일치
- private trial과 최종 commit의 일치
- 동일 세대의 T·`n_e`·Saha·NLTE 동시 관측

따라서 오프라인에서 **정확한 base 바이너리의 소스 계보**를 대상으로 호출 순서·공개 시점·포인터 복원·출력 도달성을 확인한다. 후보 계산의 덤프를 최종 공개 상태라고 읽지 않는다.

기존 출력으로 이 연결을 입증할 수 없으면 해당 권위의 최종 공개 상태는 `INPUT_PENDING`이다. 선언상 세대·호출 횟수만으로 이를 완료로 바꾸지 않는다. 오프라인에서 실제 loader 소비와 기록 경로·필드·권위·예상 산출 가능성을 확인한 경우, 런 뒤 실제 연결이 확인되는지 한 번의 등록 런에서 관측할 수 있다. 그 결과도 연결 불명이면 원 덤프의 기록값만 보존하고 해당 값을 최종 공개 상태의 분율·쌍둥이-T 비교로 채택하지 않는다. 이 한계는 다른 권위에서 독립 재현한 관측을 지우지 않는다. GPU 획득런·추가 반복은 금지하며 새 생산 계측이나 바이너리 변경이 필요하면 별도 계약 개정 대상이다.

지도에서 결손·미계산·T 불일치·세대 불명은 서로 다른 상태로 표시한다. 한 칸에 여러 사유가 있으면 원값과 사유를 보존하며 T 불일치가 음수·비유한 값의 증거를 덮지 않는다.

`N_Z=0`이면 분율과 분율 차이는 `UNDEFINED`로 남긴다. 전체 생산 피복이 확인되고 해당 원소의 생산 population도 모두 정확한 0인 경우는 원소 부재에 따른 정의 불능이며 덤프 결손이나 물리 실패로 승격하지 않는다. `N_Z=0`인데 양수 population이 있거나 음수·비유한 값이 있으면 정상 원소 부재로 처리하지 않는다. 이 규칙은 전자밀도의 로그 미정의나 E-NE 판정 불능을 면제하지 않는다.

전 지도 완료는 §4.1의 참조 좌표마다 독립 재현된 비교값 또는 입증된 미계산·원소 부재 상태가 있는 경우에만 주장한다. 미계산·원소 부재 칸을 수치 측정 성공으로 세지 않는다. 필수 관측 결손·세대 불명·새 레인의 T 불일치는 전 지도 완료를 막는다. 다만 판정자는 다른 셀에서 독립 재현된 관측을 범위를 명시하여 부분 채택할 수 있다. 자동 `VALID`·`ELEMENT_ABSENT` 문자열은 채택 근거가 아니며, 재현된 수치·상태와 미재현·불일치·판독 결손을 구별한다. 결손을 0으로 메우거나 남은 셀만으로 전건 완료를 주장하지 않는다.

selftest 양성·주입별 결과는 §10의 두 selftest 명령에 이미 요구한 stdout·stderr·rc로 보존한다. 도구 해시와 로그 경로는 기존 identity에 연결한다. 별도 selftest JSON을 요구하거나 prepare 안에서 같은 selftest를 재실행하지 않는다. 실제 loader 시험과 생산 경로 시험 의무는 유지한다.

실제 출력 manifest의 결과 저장처는 summary다. 결손·극값 항목은 지도 좌표와 필요한 수치·사유만 가리키며 지도 행 전문을 복제하지 않는다. 별도 output_manifest·gates 파일, 게이트별 status, summary의 중복 전체 status와 자동 branch·hypothesis 판정은 생성하지 않는다. 물리량·관측 상태는 지도, 피연산자·증거 참조는 summary, 재현 사실은 명령 로그, 채택 범위·E-NE 판정·TM 분기는 판정문에 둔다. 기록을 옮겨 적는 새 병렬 장부는 만들지 않는다.

필수 증거파일은 이 절의 경로 표 9행을 유지한다. 모두 물리량 산출·독립 재현·실행 보호에 소비되므로 파일 수를 줄이기 위해 원자료를 삭제하지 않는다. 원시 생산 출력·명령 로그·기존 봉인 manifest도 보존한다. 물리 관측 채택을 자동 인증하는 독립 게이트 ID는 5→0이며, §8의 종전 ID는 실패 종류와 재현 대상을 추적하는 참조명으로만 남긴다. 사전등록·발주·정본·운전자 위생 검사와 실행 안전 통제의 폐지를 뜻하지 않는다.

상태필드 개수 자체를 채택 조건으로 삼지 않는다. 게이트별 status와 summary의 자동 branch·hypothesis를 삭제한다. identity·writer·expectations·resource의 최상위 PASS는 인증 소비에서 제외하며, 필요한 결손 사유·직접 증거와 staging의 실행 가능 여부는 유지한다. 지도 셀 상태는 수치·정의 불능·미계산·조건 불일치·관측 결손을 구별하는 데 사용한다. 후속 구현 보고는 실제 삭제 필드와 남긴 필드의 소비 지점을 제시하며, 원시 실패 사유를 없애 상태 개수 감소를 만들지 않는다.

이 값들은 **이번 표본 규칙으로 새로 판독한 수**다. O-0의 기존 수치를 재주장한 것이 아니다.

base의 전자밀도 차이를 “정확도 오차”로 승격하지 않는다. 기존 분율 부재를 직전 설계의 근사 분율로 채우지 않는다.

운전자는 같은 식을 독립 재현하고 원자료의 출력 자릿수에 따른 표현 불확실성 구간을 함께 산출한다. 이 기안의 소수 출력은 그 구간보다 정밀한 물리 측정을 뜻하지 않는다.

## 6. 사전 기대치와 작동 확인

### 6.1 런에서만 판정할 물리 가설

**E-NE: 선정 표본 전체에서 쌍둥이-T 레인의 전자밀도 차이 중앙값이 base보다 작다.**

\[
M_{\rm twin}=\operatorname{median}_s|d^{\rm twin}_{e,s}|,
\qquad M_{\rm base}=\operatorname{median}_s|d^{\rm base}_{e,s}|.
\]

판정자는 원자료와 출력 형식의 자릿수에서 유도하고 운전자가 독립 재현한 표현 구간을 사용한다. 생산 판독기의 가설 문자열이나 BASE expectations 구간을 그대로 신뢰하지 않는다. BASE와 새 레인 각각 전 셸의 원값·키·공개 상태·정의역·표현 구간을 확인하고 중앙값을 별도로 계산한다. 한 셀이라도 필수 전자밀도 비교가 미정의·결손·미재현이면 전 표본 E-NE는 미판정이다. 그 셀을 제외한 중앙값으로 등록 가설을 대체하지 않는다. 표현 구간은 출력 자릿수의 한계이며 통계적 신뢰구간·모델 불확실성·물리적 정확도 경계가 아니다.

- `upper(M_twin) < lower(M_base)`이면 **감소 관측**.
- `lower(M_twin) > upper(M_base)`이면 **증가 관측**.
- 나머지는 **표현 정밀도 내 미분리**.

자의적인 epsilon·floor·맞춤 계수는 사용하지 않는다. 구간 계산법은 합성 수와 독립 산술로 오프라인 검증한 뒤 실행 전에 봉인한다.

**코드·구성에서 강제되는가? 아니오.** T 입력은 강제하지만 CMFGEN `n_e`를 입력하거나 맞추지 않는다. 복사장·단계 분배·밀도 차이 때문에 증가할 수도 있다.

가설의 근거는 O-0 §4와 상위 설계 §2의 T 교란 문제다. 그 근거는 감소의 정리나 감소 배수 예측이 아니다. 결과가 증가여도 지도 측정 자체를 실패로 바꾸지 않는다.

**base 선적용:** base를 자기 자신과 비교하면 구간이 겹치므로 ‘감소’ 조건을 충족하지 않는다. 이 자기비교는 작동 확인이며 물리 기대치가 아니다.

### 6.2 분율의 기대치

실측 base 분율과 독립 예측이 없으므로 **분율 개선 방향·배수·허용오차는 등록하지 않는다**. 이번 런에서 얻을 각 `Δf`가 측정 대상이다.

“Fe IV가 지배할 것”, “분율이 일정 배수 개선될 것”, “Saha와 NLTE가 같을 것”을 기대치로 만들지 않는다. 지도를 얻은 뒤 수리 단의 표적을 정하는 것은 후속 결정이다.

### 6.3 작동 확인으로만 등록하는 항목

| 항목 | 강제 여부 | 분류 |
|---|---|---|
| 선정 원자료 T를 입력 파일에 복사 | 생성기에서 강제 | 작동 확인 |

## 7. offline-first 집행 순서

### O-1. 기전 오프라인 특정

T를 읽는 위치, 후보 물질 계산, 최종 공개, Saha·NLTE·`n_e` 기록자까지 연결한다. 목표는 **T 불일치라는 비교 교란을 제거할 수 있는지**의 확인이다. 이 단계에서 잔여 어긋남의 물리 원인을 확정하지 않는다.

추가로 확인할 사항:

- 진단용 균일 T 키와 고정 프로파일의 상호작용
- 초기 상태와 후속 공개 상태의 T 적용 시점
- strict env가 덤프 키를 수용하는지
- 기존 stager의 균일 T·진단 비교 전제가 새 레인을 거부하거나 잘못 인증하는지
- `n_e`와 population의 동일 공개 세대 여부

### O-2. 수리안 오프라인 검증

이 단의 수리안은 **입력 T 대응과 판독의 비교 자격을 바로잡는 것**이다. Saha 반복기·율·NLTE 방정식은 변경하지 않는다.

sol은 원자료 직접 선택, 프로파일 생성, 세대 대응 자료, 지도 산술, 실행 입력 delta와 직접 관련 selftest를 담당한다. 자동 facts·게이트·분기 인증을 삭제하고 같은 셀 판독 경로에서 관측 가능한 원값과 실패 사유를 보존한다. 실제 참조의 미선정 행을 허용하는 선정 키 조인, 헤더와 열수 대응, 정상 원소 부재와 모순된 population 구별 등 관측 자체에 필요한 최소 판독은 남긴다.

기존 고정-T loader의 실제 CPU 경로로 입력 소비를 확인한다. 정상 기대값은 검사 대상 함수로 만들지 않는다. 남긴 산술·표현 구간·BASE 및 새 레인 집계·셀 보존·실행 보호에 대해 실제 입력을 읽는 경로의 양성·음성 시험을 수행한다. 삭제한 게이트의 PASS를 다시 얻는 것은 목표가 아니다. F1–F7 전건 해소 인증을 반복하는 회차를 자동으로 발주하지 않는다. 보호 통제나 관측 가능성이 확인되지 않으면 정지하며, 필요한 범위 밖 변경·추가 런은 사용자 결정으로 돌린다.

기존 출력·기존 바이너리로 계약을 만족시킬 수 없으면 여기서 중단한다. 자료획득 GPU 런을 추가하지 않는다.

### O-3. 기대치·자원·입력 봉인

다음을 모두 확정한 뒤 운전자가 계약 1건의 커밋을 만든다.

- 표본·원자료·T 프로파일·실효 exports
- source·binary identity
- 기록자의 공개 세대 계약
- §6 표현 구간과 가설 판정식
- base 선적용 및 음성대조 결과
- 자원 자격과 신규 출력량
- 개정 2의 새 사전감사 결과와 사용할 실제 경로에 대한 봉인 접촉 가부·관측 가능성 검수 결과. Q-GOAL·Q-LEAN은 새 사전감사에서 독립적으로 답하며 종전 PASS를 승계하지 않는다. F1–F7은 미해소 한계로 첨부하고, 새 검수의 허용 범위는 자동 인증이 아닌 관측 실행과 실물 보호임을 명시한다.

계약 개정은 `OLD:`/`NEW:` 쌍으로 남긴다. 결과를 본 뒤 표본·분모·문턱·허용오차를 바꾸지 않는다.

### R-1. 판정런 1회

선행조건 충족 후 새 루트에서 한 번만 실행한다. 이 한 번으로 얻을 수 있는 것은 등록 T 입력에 대한 해당 실행의 출력·실패와 재현 가능한 표본 지도이며, 완주·전 지도 완료·E-NE 감소를 보장하지 않는다. 반복 수렴·통계적 반복성·인과적 수리 효과·다른 물리 조건으로의 일반화는 얻지 못한다.

실행 전에 다음을 충족한다.

- 정확한 프로젝트·BASE·source·실행 바이너리·입력·전체 실효 exports delta와 독립 복사 경로를 봉인한다. T·덤프 활성화·경로 재배치 외 물리 입력을 바꾸지 않는다.
- 실제 loader CPU 소비와 남긴 판독 경로의 정상 산출 가능성을 확인한다. 원자료가 100행이고 선정점이 50개라는 이유로 정상 분율 자료를 버리는 경로를 그대로 사용하지 않는다. 최종 공개 연결의 런 후 미확인 가능성은 §4.3대로 사전 명시한다.
- 적격 runner의 실제 제출문·실행 가드·자원 요청·실효 반복수를 읽고 확인한다. GPU 1개·48시간·A100 전용인 기존 runner는 적격이 아니다. H200 우선·H100 차순, Slurm job-per-run, 현행 불량 노드 제외 및 §9의 GPU·CPU·시간 상한을 실제 runner가 집행해야 한다. 가드 이름 변경만으로 자격을 주장하지 않는다.
- F3가 남은 writer·stager를 쓰기 가능한 봉인 실물에 적용하지 않는다. 사용할 전체 경로가 보호대상을 수정할 수 없도록 OS가 강제하는 읽기 전용·격리 경계 또는 해당 쓰기 경로의 안전성을 사설 정상·교체·링크 시험과 별도 검수로 확인한다. 파일 chmod·새 임시 이름·사후 hash만으로는 부족하다. 보호대상의 내용뿐 아니라 권한·링크·디렉토리 엔트리도 보존한다. 이 경계가 제공되지 않으면 INPUT_PENDING이며 제출하지 않는다.
- §9의 신규 총량 16 GiB에 독립 입력 복사, RUN·EVID의 생산 출력, 지도·summary, 명령·재현·감사 로그, 임시파일의 동시 점유까지 포함한다. 쓰기 전 남은 예산에 들어가는 상한 산식을 확인하고 쓰기 후 총량을 직접 대조한다. 사후 초과 검출만으로 상한 집행을 대신하지 않는다. 덤프량이나 동시 점유 상한이 미확정이면 제출하지 않는다.
- 새 사전감사·실물 접촉 가부와 현행 운전자 선행 기계 검사를 충족한다. 이번 사용자 선택은 관측 상한으로의 전환이며 봉인·자원 위험의 면제가 아니다.

GPU 최대 8 GPU-hour, 런 CPU 최대 128 할당 CPU-hour, 오프라인 단일 CPU 누적 1 CPU-hour, 신규 총량 16 GiB를 유지한다. 새 준비·selftest·독립 재현은 이 오프라인·저장 예산 안에 포함한다. 메모리 자격도 §9대로 별도 근거가 필요하다. 부족하면 자동 증액하거나 추가 런을 만들지 않는다.

물리 입력 변경은 등록 T 프로파일이다. 추가 변경은 기존 덤프 활성화와 경로 재배치에 한정하며 전체 실효 exports delta를 봉인한다. 원자 덱·밀도·조성·반복수·수송 설정·NE-closure 상태를 임의로 바꾸지 않는다.

시간 초과·중도 실패·필수 덤프 결손은 그 상태로 보존한다. 자동 재런·관찰런·OFF 인증 GPU 런·반복수 연장은 없다.

## 8. 게이트와 음성대조

아래는 종전 ID로 추적하는 실제 확인 대상과 음성대조 목록이다. 자동 인증 게이트 명부가 아니며 행별 PASS를 합쳐 물리 관측을 채택하지 않는다. 좌표·T·population·산술은 직접 판독·독립 재현에서 확인하고, 실행·비용·봉인 항목은 실행 전후 운영 통제로 소비한다.

음성대조 의무는 유지한다. 사용하려는 거부 통제는 사설 정상 입력을 수용하고 의도한 결함을 실제 경로에서 거부해야 사용 자격이 있다. 판독·재현 경로는 주입한 결함 때문에 해당 값이 불일치·미정의·미재현으로 드러나는 것을 확인한다. 무관한 예외·항상 실패·예상 rc 출력·facts만의 변조는 시연이 아니다. 원자료·source·바이너리 교체, 이전 세대, 부분 목록, 정상 미선정 참조 행, 헤더 모순, 부재 셸의 모순된 population, BASE 집계 변조와 쓰기 뒤 저장 증가를 실제 소비 경로의 시험 대상으로 포함한다. 시험은 메모리 또는 봉인과 연결되지 않은 사설 fixture에서 수행하며 실물 BASE를 변조하지 않는다.

이 의무는 새로운 인증 프레임워크나 게이트 ID를 요구하지 않는다. 남긴 산출·재현·안전 통제를 직접 시험하는 데 필요한 범위이며, 종전 selftest의 건수와 PASS는 승계하지 않는다.

### 직접 재현·실행 통제 대상 끝

표의 G-COORD 등은 과거 지적과 실제 확인 대상을 연결하는 참조명이다. T 연결의 재현은 T의 물리적 정답성을, population 총량 관계의 재현은 CMFGEN 일치를 인증하지 않는다. 공개 세대와 모집단은 실물 증거에서 확인하며 상태 문자열·빈 목록·부분 목록·null 값의 일치를 완전성으로 읽지 않는다. 실행·봉인·비용 통제가 성공하더라도 물리 관측 채택은 §11의 독립 재현과 판정을 거친다.

기존 고정-T 범위 가드는 이 단에서 확대하거나 강화하지 않는다. 정확해가 위반 가능한 새로운 clamp·floor·cap·jitter·유사 가드를 만들지 않는다.

사전등록·발주·문서 정본·운전자 위생·게이트 참조·명부 검사는 기존 기계를 사용하고 내장 selftest 결과를 함께 기록한다. 이 기안에는 실행하지 않은 검사 PASS를 적지 않는다.

조회 명령은 `sha256sum <봉인된 절대경로 목록>`, `sed -n '<고정 행>p' <대응 소스·로그>`, `python3 -B - <봉인된 입력 인자>`와 그標準入力の 직접 판독문을 전문 보존한다. Slurm 근거를 조회할 때는 실제 제출 클러스터를 명시한 `sacct -M <cluster> -j <job> ...`의 명령·필드·출력을 남긴다. 이들은 실행 전 실제 경로·도구 hash·인자로 확정할 명령 형식이며, 이 기안에서 실행하거나 재현 완료했다고 주장하지 않는다.

재현은 채택 후보의 전건을 대상으로 하며 표본 몇 칸의 일치로 전 지도를 대신하지 않는다. 입력 십진값과 정확한 산술 관계는 그대로 대조한다. 로그·구간 계산의 수치 표현 차이는 실행 전 독립 합성 산술에서 정한 계산·출력 규약으로 설명하고, 맞추기 위한 epsilon·floor·재정규화는 도입하지 않는다. 설명되지 않는 차이는 `not-reproduced`다.

각 주장에 `reproduced / not-reproduced / blocked`, 입력·출력·도구 hash, 정확한 명령, stdout·stderr·rc와 최소 결정적 수치를 기록한다. 불일치는 원래 지도·summary를 덮어써 없애지 않는다. 감사의 실행 가능한 주장도 정확한 감사 대상 경로·판본에서 전건 재현하고, 추론만인 주장은 고정 증거와 전제 identity를 대조한다.

판정 전에는 채택 후보 수치의 독립 재현 결과를 제공한다. 완료감사 후에는 판정·감사문이 실제로 인용한 주장과 §6 관계·TM 조건의 일치 여부를 확인하여 최종 재현 상태를 남긴다. 동일 증거의 완료된 계산은 재사용할 수 있지만 새 주장·변경 판본·불일치는 다시 확인한다. 운전자의 부등식·조건 대조는 사실 확인이지 분기 판정의 저작이 아니다.

관측 채택에는 해당 주장 전건의 `reproduced`와 판정자의 범위 명시, 필요한 완료감사가 모두 필요하다. `blocked`·`not-reproduced`인 주장은 채택하지 않으며 독립적으로 재현된 다른 부분의 보존을 막지는 않는다. 후속 수리·추가 런·등급 승격은 이 사실 보고로 자동 승인되지 않는다.

증가분 전부에 소비 지점이 있다(조상 fd 순회 · 세대 모순 분기 · 생산값 실패 목록 · 저장 예약·사후

확인했다. **소비 지점 없는 증가는 발견되지 않았다.**

### ★남은 «폐합 차단» 3 — 전부 **staging·IO 배관**이며 판독 물리 로직이 아니다

| | 내용 | 성격 |
|---|---|---|
| **①** | **새 T 프로파일을 설치할 정상 경로가 중단된다** — `replace_private` 가 목적지에 무조건 `stat` 을 요구하는데 봉인 BASE 에 `fixed_te_profile.txt` 가 **없다** ⟹ 정상 신규 설치가 `FileNotFoundError`. ★**이번 수정이 만든 것이 아니라 직전 판본에도 있었다**(감사가 diff 로 확인) | 실행 차단 |
| **②** | **보호된 writer 에 닿기 전 `mkdir` 이 봉인을 침범할 수 있다** — 경로 검사 뒤 경로 기반 `mkdir`, 하위 검사도 생성 후. stager 의 임시파일 생성·`cp`·정리도 강화 함수 **밖**에 있다 | 실행 선행조건 |
| **③** | **staging 이 첫 저장 검사 전에 이미 쓴다** — manifest·복사·exports·job·profile 쓰기가 첫 `resource_check` 보다 앞. 실측: 쓰기 후 상한 **1,062 byte 초과**. 사후 검사는 순서를 바꾸지 못한다 | 실행 선행조건 |

★**이 셋은 「명시된 한계」로 옮길 수 없다.** ① 은 **실행 자체를 기계적으로 막고**, ②③ 은 감사의 문장
그대로 **「계약이 관측 한계로 면제하지 않은 실행 선행조건」**이다(봉인 무접촉·저장 상한).
⟹ 트립와이어의 「2~3건이면 한계로 옮기고 런」 갈래는 **이 셋에는 적용되지 않는다.**

**«기재로 족함»**: 저장 예약이 보수적이다(실제 최대 임시 18,366 byte 인데 29,133 byte 예약) —
`peak_storage_bytes` 는 실측 최고점이 아니라 **보수적 상한**으로 읽어야 한다.
그리고 summary 의 독립성 고정 선언은 **요구 방식의 선언**이지 실행된 독립 재현의 사실 증거가 아니다.
