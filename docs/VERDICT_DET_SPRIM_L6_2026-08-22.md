## 5. 이 판정이 주장할 수 있는 것 / 없는 것

### 5-1. 주장할 수 있는 것 (전부 판정자 실측)

- **(i) 계측 계약 성립**: 원시량(eta, tau_eff, provenance) 장부가 2반복×297행 100% 유효로
  적혔고(`SPRODUCER-CAPTURE status=CAPTURED cells=109014300` 반복당 1회·
  `physical_values_modified=0`·`publication_authority=NONE`), S_prod 는 **역산·뺄셈 0회**로 유도됐다.
- **(ii) L6 계량**: 고정-T 레인 반복 1 의 생산자 선 소스는 **이 297선**(shell 0·Z=26,27,28·
  ion=3, 대상이온 후보 방출의 90.02% 커버) 기준으로 **LTE(B(10020 K))를 벗어나지 않았다** —
  전 행 |S/B−1| ≤ 9.6e-6.
- **(iii) ★"population 이 갱신되지 않았다"는 반증됐다**: 물질 커밋 gen 2→3(G2), 상류
  LINE-COEFFICIENT-IDENTITY 50줄 iter0↔iter1 상이(G7 의도 검증), 그리고 **행 수준에서** —
  line id 로 짝맞춘 297행 **전부**에서 eta^prod·tau_eff^prod 가 변했다(최대 +4.05e-3;
  n_upper 최대 1.95e-3; J̄·J_cont 최대 1.72e-2).
- **(iv) ★그러나 갱신은 행별 공통모드뿐이다**: 전 297행에서
  |(eta_1/eta_0)/(tau_1/tau_0) − 1| ≤ **6.7e-16**(3 ulp) — **행별 S 는 기계정밀도로 불변**이고,
  iter1 의 S/B 행별 값은 iter0 LTE 시드 서명과 ulp 급으로 일치한다(★감리 정정: 판정자 산법 ≤1 ulp / 감리자 독립 산법 max 6 ulp — **같은 계급이나 자릿수는 산법 의존**). 즉 **밀도/이온화 급 인자만
  움직였고 여기(준위비) 구조는 Boltzmann(10020 K)에 동결**돼 있다.
- **(v) ★이탈 신호는 실재했다**: 얇은 선(tau^prod 최소 2.7e-8, beta≈1 ⟹ J̄≈J_cont)에서
  **J̄/B 최저 0.607 · q10 0.700** — E4 분기 A 가 전제한 입력 범위(0.71~1.0)에 걸치며 **하한 아래 0.607 까지 내려간다**(★감리 정정: 초판 "전제한 범위 그대로" 는 부정확 — 신호는 전제보다 **더 강한** 방향이다). 그런데도 S/B 는
  1−7e-6 에 머물렀다. ⟹ **"복사장이 어차피 열적이어서 이탈할 이유가 없었다"는 대안 해석은
