## 2. 계약 A2-09 — 정본 CPU emissivity publication

### 2.1 `CpuEmissivityPublication`

구현은 하나의 소유 객체를 둔다. 이름은 바꿀 수 있지만 필드와 의미는 보존한다.

```text
CpuEmissivityPublication
  required_emissivity_generation
  committed_emissivity_generation
  radfield_generation
  line_view_generation
  population_generation
  opacity_generation
  te_generation
  atomic_model_sha256
  grid_manifest_sha256
  source_manifest_sha256
  n_shells, n_bins
  nu_edge[n_bins+1]
  eta_bb, eta_bf, eta_ff
  eta_true_total
  eta_scattering_source
  eta_total_for_declared_semantics
  cell_status
  component_status
  transition_block_status
  redistribution_status
```

단위는 `erg s^-1 cm^-3 Hz^-1 sr^-1`, frame은 comoving이다. 주파수는 bin edge로
정의하고 point sample을 정본으로 삼지 않는다. `eta_true_total`과 coherent/scattering
source를 별도 배열로 둔다. CMFGEN `ETA_DATA` writer schema가 둘을 합친다면 그 포함
규약을 manifest에 기록하고 동일 의미끼리만 비교한다.

다음 closure를 compensated summation으로 검사한다.

```text
eta_true_total = eta_bb + eta_bf + eta_ff
eta_total_for_declared_semantics = eta_true_total + eta_scattering_source
```

정확한 물리 0은 `EXACT_ZERO`다. missing, unsampled, OOG, stale, undefined source와
수치 0을 같은 double sentinel로 표현하지 않는다. 한 cell의 필수 성분이 invalid면 total을
게시하지 않는다. shell 일부만 새 generation으로 보이는 partial publish는 금지한다.

### 2.2 물리 생산 규약

Bound-bound는 solved upper population, `A_ul`, line profile/보존 bin deposition과
checked source provenance에서 만든다. stimulated emission은 A2-08의 signed opacity
항이고 true emissivity에 음수로 섞지 않는다. line source가 undefined이면
`B_nu(T_e)`, Jbar 또는 이전 `line_source_S`로 대체하지 않는다.

Bound-free는 모든 등록 target/level의 Milne 상세평형 짝을 합하고, free-free는 실제
`T_e`, `n_e`, ion charge sum과 명시된 Gaunt 자료를 쓴다. A2-08의 signed net opacity와
packet event measure를 eta와 혼동하지 않는다. 원자자료/topology가 부족한 active
channel은 `EMISS_ATOMIC_MISSING`/`BLOCKED_ATOMIC_COVERAGE`이지 Kramers나 한 dominant
edge로 바꿔 PASS하는 사유가 아니다.

모든 성분은 동일 `(shell,nu-bin)` grid, generation, summation order로 한 transaction에
만든다. 구현 중 기존 산식의 정확성을 보장할 수 없는 성분은 0을 게시하지 않고 해당
status로 막는다.

### 2.3 전이확률과 재분배

각 활성 macro state `a`에 대해 방출/내부전환 channel `t`의 비정규 에너지 flow
`w[a,t]`를 계산하고 다음을 게시한다.

```text
p[a,t] = w[a,t] / sum_t w[a,t]
sum_t p[a,t] = 1 within 1e-10
w[a,t] >= 0 and finite
```

복사 internal-up 항은 A2-06 checked `LineJbarCache`와 Einstein 계수를 사용한다.
population factor는 A2-07 committed population/`LTE@T_e` view에서만 얻는다.
`W*B_nu(T_rad)`, raw `jbar_line`, `j_blue`, bin-empty Planck floor/cap, 옛 확률은
production weight가 될 수 없다. signed opacity의 음수값을 확률 weight로 abs/clip해 넣지
않고, 해당 event-law capability가 없으면 `EMISS_NEGATIVE_EVENT_UNSUPPORTED`로 막는다.

빈 block, `sum_w==0`, orphan level, 5,000-hop cap은 마지막 BB channel 강제나 옛 block
유지가 아니라 명시적 실패다. recombination, internal-up, k-packet deactivation을 포함한
모든 경쟁 channel이 같은 분모를 공유한다. block마다 확률합과 흡수→내부전환→방출
에너지 closure를 함께 기록한다.

### 2.4 `eta_reemit`과 유일 CDF

old7897 경로의 새 공급자는 `eta_reemit` view다. 이는 별도 물리 emissivity를 재계산하지
않고 `CpuEmissivityPublication`의 선언된 true-emission channel을 event capability와
교차시켜 만든 read-only view다.

equal-energy packet의 bin weight는 `eta_reemit[s,b] * Delta_nu[b]`이고, channel/line
내 표본은 동일 emissivity deposition의 보존 crosswalk를 쓴다. CDF builder는 다음을
보장한다.

```text
cdf[0] >= 0
cdf[b] >= cdf[b-1]
cdf[last] == 1 bitwise after deterministic normalization
sum(weight) > 0 and finite
cdf_manifest_sha256 binds eta generation, grid, channel mask and summation order
```

CDF와 sampler는 하나뿐이다. `bf_absorption_event`, k-packet free-bound exit,
macro-atom continuum exit은 자신의 event capability가 허용한 동일 게시 CDF/view를
사용한다. `sample_planck_frequency(T_rad)`, 대표 edge, 균등 CDF, last-channel 강제,
이전 generation CDF는 fallback이 아니다. sampler는 고정 RNG에서 draw count와 stream을
artifact에 기록한다. draw count 변화는 §12 allowlist의 exact event identity에 있어야 한다.

| CHAIN | 현재 실행에서 commit된 A2-05/06/07/08 view | 전체 배선·validity 전파 |
| ORACLE_INPUT | 같은 checked API에 같은 generation의 CMF J/Jbar/population/chi를 commit | emissivity/redistribution 층 분리 |

raw 배열 직접 대입은 금지한다. upstream gate 상태가 BLOCKED면 그대로 보존한다.
현 truth에는 `ETA_DATA`/`ETA_DATA_INFO`가 없으므로 두 lane의 최종 L-3/L-5는
`BLOCKED_MISSING_ETA_DATA`, `truth_f_cov=null`, rc 3이다. `GENCOOL`을 대체 truth로
사용하지 않는다.

truth가 도착하면 Lumina 결과를 읽기 전에 writer schema의 true/scattering 포함 의미,
unit, frame, shell/frequency order, channel crosswalk를 고정한다. truth channel의 방출
에너지 기여를 내림차순 누적해 99.9% 최소 활성집합을 만들고 경계 동률을 모두 포함한다.

```text
f_cov = sum(truth eta*Delta_nu of usable matched active channels)
        / sum(truth eta*Delta_nu of all truth-active channels)
```

stale/invalid/unmatched/unsupported는 분자에서 빠져도 분모에서 빠지지 않는다.
Lumina status나 큰 Lumina eta를 본 뒤 분모를 다시 만드는 순환 필터는 금지한다.

L-3는 활성 상태별 확률합 CPU `1+-1e-10`, 음수/NaN 0, 에너지 closure `<=1e-8`,
그리고 표본 eta의 L-5 일치를 요구한다. L-5는 `f_cov>=0.95`, shell total
`E_1<=0.15`, 다섯 대역별 `E_B<=0.15`, 성분합 closure `<=1e-10`을 요구한다.
대역은 `450-918`, `918-1290`, `1290-2000`, `2000-10000`, `10000-25000` Angstrom이다.

MC 95% CI half-width는 합격폭의 1/3 이하, 즉 E1/EB에서 `<=0.05`, L-3 energy
closure 표본 판정에서는 사전등록된 표본 허용폭의 1/3 이하여야 한다. 확률합과 analytic
closure는 결정론이며 CI=0이다. coverage의 95% 단측 하한은 `>=0.95`다.

### 7.1 `ElectronTemperaturePublication`

```text
ElectronTemperaturePublication
  solve_epoch
  required_te_generation
  committed_te_generation
  radfield_generation
  bf_rate_generation, line_view_generation
  population_generation
  opacity_generation, emissivity_generation
```

`committed_te_generation`이 A2-07 §3.3의 `te_generation`이다.
`te_manifest_sha256`는 폐합된 A2-07 함수
`population_te_manifest_sha256(const double *te, size_t n_shells, char out[65])`의 출력을
그대로 사용한다. hash 입력은 domain string
`A2-07:T_e:K:IEEE754:shell-order:v1`, shell 수와 순서, 각 shell index 및 IEEE-754
`T_e` 값뿐이다. geometry나 solve epoch를 이 hash에 추가하거나 A2-07 함수 서명을
바꾸지 않는다. 따라서 A2-07 population stamp의
`te_generation`/`te_manifest_sha256`와 bit-exact로 같아야 한다.

geometry와 solve epoch의 문맥 결박은 별도 `te_context_sha256`에 둔다.

```text
te_context_sha256 = SHA256("A2-10:Te-context:v1" ||
                           te_manifest_sha256 || geometry_sha256 || solve_epoch)
```

문자열 길이와 정수 byte order는 manifest schema에 고정한다. 이 필드는 A2-10 manifest에
병기하고 commit barrier에서 별도로 검사하며 A2-07 stamp의 일부가 아니다.
`T_rad/W`로 만든 seed는 generation 0이며 production population 입력 자격이 없다.

### 7.2 trial과 atomic commit — 순환 금지

복사평형은 `T_e -> population -> opacity/emissivity -> H,C -> T_e` 결합 문제다. 다음
transaction으로 순환 소유권을 끊는다.

1. committed generation `g`의 RF와 물질 상태를 고정하고 새 `solve_epoch`를 연다.
2. trial `T_e`마다 A2-07 solver를 **비공개 work buffer**에서 실행한다. trial token과
   A2-05/06 generation을 검사하고 public population/Te를 쓰지 않는다.
3. trial population으로 A2-08/09 component work view와 A2-10 term ledger를 평가한다.
4. 모든 shell의 열잔차·전하중성·population 잔차가 수렴한 한 trial만 선택한다.
5. `T_e`, A2-07 partition/population/`n_e`, 이에 결박된 opacity/emissivity를 한 commit
   barrier에서 새 generation으로 게시한다. 어느 한 객체 실패 시 전부 미게시다.

iteration 중 `plasma->T_e`를 직접 덮어써 다음 shell이나 다음 항이 읽게 해서는 안 된다.
옛 `T_e`와 새 population, 새 `T_e`와 옛 eta가 섞인 generation은 금지한다.

### 7.3 항별 thermal ledger와 잔차

각 shell에서 상쇄 전 양의 heating vector와 cooling vector를 같은 체적 단위
`erg s^-1 cm^-3`로 게시한다. 최소 항은 다음과 같다.

```text
H = {photoionization, line_absorption, free_free_absorption,
     Compton_heating, gamma_deposition, nonthermal_heating}
C = {radiative_recombination, line_emission, collisional_line,
     free_free_emission, Compton_cooling, adiabatic_cooling}
```

한 물리항이 부호를 바꿀 수 있으면 signed raw term과 `max(Q,0)`/`max(-Q,0)` 보고를
함께 저장하되 net만 저장하지 않는다. photoionization route `r`는 checked canonical
`J_nu`로 `4*pi*n_lower*integral[sigma_r(nu)*J_nu*(1-nu_0/nu) dnu]`를 보존
적분한다. line은 동일 generation의
`4*pi*integral(chi_line*J_nu-eta_line)dnu`, free-free는
`4*pi*integral(chi_ff*J_nu-eta_ff)dnu`를 쓴다. recombination은 A2-09 Milne
emissivity와 같은 population/atomic crosswalk를 사용한다. `eta`가 per-steradian이므로
`4*pi`를 누락하거나 두 번 곱하면 selftest FAIL이다. Compton도 `T_rad` proxy가 아니라
주파수별 radiation energy moment에서 만든다. gamma/nonthermal/adiabatic은 비복사
외부항으로 명시하고 J-derived인 척하지 않는다.

Bound-bound line owner는 shell마다 정확히 하나다. 다음에서 `m_line=1`은 Option-2
integral radiative-line owner, `m_line=0`은 collisional/escape owner이며 다른 값이나
한 shell 안의 혼용은 schema FAIL이다.

```text
A_line = 4*pi*integral(chi_line * J_nu dnu)
E_line = 4*pi*integral(eta_line dnu)
Q_line_rad = A_line - E_line
C_line_ce  = collisional_or_escape_bound_bound_cooling

Q_line_ledger = m_line * Q_line_rad - (1-m_line) * C_line_ce
R_E = sum(H_non_line) - sum(C_non_line) + Q_line_ledger
m_line in {0,1}
m_line * (1-m_line) = 0
```

즉 `m_line=1`이면 ledger의 `line_absorption`과 `line_emission` signed raw term 및 그
heating/cooling split만 합산하고 `collisional_line`은
`REPLACED_NOT_APPLICABLE`로 제외한다. `m_line=0`이면 반대로
`collisional_line=C_line_ce`만 합산하고 radiative `line_absorption/line_emission`은
`REPLACED_NOT_APPLICABLE`다. `REPLACED_NOT_APPLICABLE`는 missing이나 exact zero가
아니며 선택된 owner와 대체 대상의 provenance를 반드시 가진다. 이는 현 코드
`src/lumina_plasma.c:11857-11864`의 “Option-2 radiative line term이
collisional/escape bound-bound cooling을 replace”한다는 계약을 명문화한 것이다.

ledger 합과 독립 owner 식은 모든 shell에서 다음 항등식을 만족해야 한다.

```text
line_owner_closure = (sum(H)-sum(C))
                   - (sum(H_non_line)-sum(C_non_line)
                      + m_line*(A_line-E_line) - (1-m_line)*C_line_ce)
line_owner_scale = sum(abs(all included ledger terms))
                   + abs(m_line*(A_line-E_line) - (1-m_line)*C_line_ce)
normalized_line_owner_closure = abs(line_owner_closure) / line_owner_scale <= 1e-12
line_owner_scale = 0 implies bit-exact line_owner_closure = 0
line_owner_overlap = (radiative_line_included && collisional_or_escape_included) = false
```

```text
R_E(T_e) = sum(H_i) - sum(C_j)
E_balance = abs(sum(H)-sum(C)) / (sum(H)+sum(C))
```

분모 양쪽이 정확히 0이면 `RADEQ_EXACT_ZERO_BALANCE`이고, 한쪽 missing이면 0이 아니다.
root bracket은 물리적으로 양의 유한 trial 범위와 sign change로 증명한다. no-root,
endpoint root가 아닌 pin, `[0.1,2]*T_rad`, 1,000 K floor, 이웃 shell, tail color,
fixed/frozen shell, old iterate publish는 금지한다. damping/line search는 잔차를 실제로
감소시키고 동일 root를 보존할 때만 허용한다.

### 11.2 truth 활성집합, `f_cov`, metric과 CI

released-T O-PHYS가 도착하면 Lumina 결과를 읽기 전에 truth term label/sign/unit/depth
crosswalk를 고정한다. 각 shell 및 전체에서 truth의 `abs(Q_term)` 기여를 내림차순 누적해
99.9% 활성집합을 만들고 경계 동률을 포함한다.

```text
f_cov = sum(abs(truth Q) of usable matched truth-active terms)
        / sum(abs(truth Q) of all truth-active terms)
```

missing/stale/unmatched/unsupported term은 분모에서 빠지지 않는다. 잔차가 작은 shell이나
Lumina status가 OK인 shell만 골라 분모를 다시 만드는 상태필터 순환은 금지한다.

합격선은 ORDER와 동일하다.

- `f_cov>=0.95`, 95% 단측 하한도 `>=0.95`.
- Te 대칭오차 median `<=0.10`, P95 `<=0.20`.
- 양 코드 모든 공통 shell `E_balance<=1e-3`.
- 항별 heating/cooling vector signed `E_1<=0.20`.
- photo, line, FF, recombination 및 외부항을 상쇄 전 별도 보고.
- 각 shell의 radiative-line 대 collisional/escape owner 배타성, overlap 0 및
  `line_owner_closure=0`을 먼저 통과.

MC 95% CI half-width는 Te median `<=0.0333`, Te P95 `<=0.0667`, term E1
`<=0.0667`, E_balance `<=3.333e-4`다. ORACLE_INPUT이 결정적이면 CI=0이다.
