# Co-evolution rewiring — staged implementation plan

## Architecture decision (the whole plan in one sentence)
Keep **loop A** (the deterministic pure-CMFGEN loop, `src/lumina_cuda.cu:4110-4291`) as the master loop; **lift the THEN_MC transport pass into it** so that each iteration's MC field (from the previous iter's just-solved pops) is reduced and written into `nlte.J_nu` at the existing single coupling point (`cmfgen_write_jnu`, `cuda.cu:4167`), letting the already-wired full-state solves (RE@4228, plasma@4232, NLTE@4243) co-evolve off it. The MC loop B (4776-5408) and its freeze gates are **never entered** in co-evolve mode.

**Lag/order per iteration `it`** (resolves the tau/transprob ordering gotcha): `cmfgen_solve_J` (continuum backstop + injection-CDF source, keep) → `cmfgen_write_jnu` fills `nlte.J_nu` from cs.J → **blend in the MC field produced at the END of iter `it-1`** → RE/plasma/NLTE consume the blend → upload fresh pops to device → run transport_kernel on those pops → reduce to `nlte_Jmc` buffer for iter `it+1`. Iter 0 has no MC field: pure deterministic seed (exactly what THEN_MC already does with `use_jbar_line=0`, cuda.cu:4767).

**Master gate: `LUMINA_MC_COEVOLVE`** (static-cached getenv, mirror the `g_simul_on` pattern), default OFF ⇒ byte-identical to champion (loop A untouched, 4665 `return 0` taken).
