# Lumina-sn 업무인수인계 — 2026-10-26

## 현재 결론

최종 Si II/III·S 분포 및 스펙트럼의 CMFGEN 동질성은 **NOT_MET**다.
목표는 active이며 중간 C 시험 통과를 물리해 완성으로 취급하지 않는다.
현재 아래 계산·시험은 모두 종료됐고 새 GPU 수송은 실행하지 않았다.

승인된 직접평가 CMFGEN 참조1220560은 준비 포함1720초 한도에서 종료했다.
84851/197291개 주파수(약43%)만 완성했고 전체 장 완료 표지는 없다.
native MaxRSS 약5.5GiB로 OOM이 아니다. 단회 승인은 사용됐고 연장·재시도하지
않는다. 의존 후처리1220644도 실행 없이 취소됐다. 부분 자료는 보존했다.

완료 prefix의3점×5주파수에서는 새 native와 자체 직접평가의 χ/진η가
0.006% 이내지만 J 차이는 남는다. native49의611.125/611.098Å에서
기존 자체 J_A/새 참조 J는3.09405/3.30797,714.985Å에서는2.11035다.
따라서 continuum 계수 재사용 차이만으로 큰 J 초과를 설명할 수 없다.
J_A는 F(0)이며 산란 공동수렴 장이 아니다. 부분 장으로 전체 광흡수율이나
새 자기일관 해를 계산·판정하지 않았다. 원 자료 해시는
[정확 수송 기록](LUMINA_FROZEN_SWEEP_2026-10-26.md)의 마지막 절에 있다.

## 이번 실제 코드 변경과 직접시험

Astra가 정정한 기존 계획에 따라 새 toy·공간256/주파수8 세분 대신,
실제 점값 J의 원자율→SE/RE 소비 연결을 구현하고 있다. 운전자가 직접
코딩·시험했으며 추가 모델 호출·정례 감사는 없었다.

- `bf_rate_jnu.c/h`: 점값 ν/J/단면과 **전역 적분 가중치**를 받는 C 적분.
  광흡수·자발·유도 재결합 및 문턱 기준 열량을 분리한다. 하위 FL 입자당

  기존 bin 경로가 유지된다. 물질/복사장 세대·T/ne가 오래됐거나 실제 target이
  pair 밖이면 실패하며 Kramers/bin 경로로 대체하지 않는다.

  PHOT 확률·하위 FL fraction·이미 상위 SL 기준인 inverse를 중복 적용하지 않는다.
  기존 CI/C3는 PHOT grid 선택과 점유확률 포함 Saha 비로 유지한다. 다른 실제
  물리율(DR 등)은 제거하지 않는다. 기존 bin 주파수 한도로 점값 율을 잘라내지 않는다.

## 아직 미구현인 핵심과 다음 작업

이번 변경은 **bound pair 연결만** 완료했다. 최종 묶음은 미완이며 자체
판정은 REWORK다. 구체적으로:

1. EW의 terminal scalar·coverage는 아직 점값 율 경로로 이관하지 않았다.
   현재 point snapshot+EW 조합과 legacy bin top-stage reservoir 혼합을 명시적으로
   거부한다. terminal을 버리거나 가짜 FL로 만들지 말고 실제 scalar 인구 변수로
   연결한다. PHOT/pseudo-continuum의 서로 다른 소비 지지도 유지한다.
2. 현재 `nlte_population_candidate_begin`은 `model_level_occupation`이 있으면
   이전 프로필 차용을 거부한다. 이 보호를 삭제해서 진행하지 않는다. 먼저 실제
   T/ne/양이온 총수에서 occupation을 재생산하고 private 후보가 배열을 소유하도록
   구현한다. 양이온 총수는 전하 가중 합이 아니다. 공개 배열을 후보와 공유하지 않는다.
3. occupation은 within-SL·partition·Saha/율 snapshot 및 물질 신원과 함께
   갱신해야 한다. 현재 원자모형 해시가 occupation을 포함하지 않는 점도 고려해
   오래된 프로필을 새 물질로 인증하지 않도록 한다. 공개 물질 게시 권한과 구현
   완료를 혼동하지 않는다.
4. 전 경로 point snapshot 생산기와 같은 실제 점값 장에서의 BB Jbar·
   전 bound/terminal/pseudo BF·CI/C3·기타
   물리율을 조립하고 native49의 SE/RE 잔차와 **미게시** 인구 후보까지 연결한다.
   원래90점의 r/v/T/ne·occupation·단위를 유지한다. 점값을 bin 평균으로
   재명명하거나 한 점을 가짜 셀/경계로 만들어 adiabatic 항을 계산하지 않는다.
5. 이 경로가 완성돼야 전90점·released T/ne·SE/전하/RE/에너지 폐합·자기일관
   수송·관측자 스펙트럼의 최종 동질성을 판단할 수 있다. 지금은 분포 개선율이나
   해결 ETA를 주장할 근거가 없다.

현재 GPU 승인2회는 소진됐고 직접평가 native 단회도 소진됐다. GPU 원장
