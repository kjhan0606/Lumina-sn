# S III 바깥 잔차의 주파수 연산자 분리 — 2026-10-23

## 묶음 목적과 현재 판정

최종 목적은 CMFGEN과 Si/S 자기일관 분포·물리량·스펙트럼의 동질성을
입증하는 것이다. 이 묶음에서는 고정 물질70/J71의 native49에서
남은 S III 600–750Å 광흡수율 초과 `168.172803 cm⁻³ s⁻¹`에
**주파수 수송 연산자 차이가 실제로 기여하는지**를 판별한다.
기존 C 4→8 공간분할은 초과분을 약6.0%만 줄였다. 이번 단계의
국소 광선 계산·코드 시험을 최종 자기일관 결과로 바꾸지 않는다.
현재 원인 기여율은 **미판정**이고 최종 목표는 `active/NOT_MET`다.

## 수정된 다음 묶음과 중단선

Astra의 보정 의견은 **C의 동일 등간격 주파수·110 ray·8분할
경로에서 두 주파수 연산자의 조건부 민감도**를 먼저 비교하는 것이다.
원 CMFGEN 비등간격 엔진을 즉시 새로 만들지 않는다. signed χ,
비음수 η, 같은 고정 J·청색 입력·경계·각도 가중치·PHOT/Milne를
유지하고, C의 촘촘한 간격뿐 아니라 CMFGEN 기본 간격 규모의
등간격 시험도 포함한다. 이것은 원 CMFGEN의 105광선·비등간격
수송을 재현한 비교가 아니므로 실제 잔차의 연산자 기여율로
환산하지 않는다.

사용자 요청으로 Astra 의견을 전달받은 Muse도 이 제한된 비교
방향에는 동의했으나, `CMFGEN식 upwind`의 공간/주파수 도함수,
계면 χ·광학깊이·source, χ≈0 및 음수, 청색 경계 처리를 식과
분기로 먼저 고정해야 결과를 해석할 수 있다고 지적했다. 작은
해석해 시험(단일 광선·무속도·상수 양의 χ) 후 부호 변화·도플러
이동으로 넓히라는 제안이다. 그 시험만으로 실제 S III 초과의
원인을 선언하지 않는다. Muse 역시 원자료를 직접 재현하지 않은
자문이며 운전자가 정의·구현·결과를 검증한다.

따라서 다음 첫 작업은 기존 코드와 원 packet에서 CMFGEN의 실제
이산식을 **정확히 특정**하고, 같은 물리량·경계의 비교 연산자로
구현 가능한지를 확인하는 것이다. 동일 입력을 확보하지 못하거나
새 비등간격 엔진·대형 전주파수 재실행이 필요하면 조건부 결과만
보고하고 자동 확대하지 않는다. 기존 완성 자료와 실행 한도는
유지한다. 최종 Si/S 자기일관 분포·물리량·스펙트럼은 아직 미달이다.

같은 C 경로의 실제 대역 비교를 진행할 때에는 두 방식에 **같은
공간 물질 복원·구적·경계**를 적용하거나 공간분할 민감도를
별도로 수렴시켜, 주파수 차이와 공간 source 적분 차이를
혼합하지 않아야 한다. 이를 보장하지 못한 시험은 조건부
혼합연산자 민감도까지만 보고한다.

### 2026-10-23 격리 비교기 구현과 실행 보류

운전자가 `src/lumina_upwind_p0.c`에 동일 P0 구간 `χ,η,ds,Δlnν`와
입사 전주파수 강도를 받는 1차 청색 상풍식을 구현했다. 각 빈의
`χ+(3+1/Δlnν)b`와 이전 청색 빈의 입력/출구 강도를 사용하고,
구간 내부의 이전 빈 강도를 끝점 선형으로 적분한다. 가장 청색
빈은 원 CMFGEN처럼 이전 빈 결합0이다. signed χ를 허용하고
η·입사강도는 비음수로 검사하며 floor/clip은 없다.
`scripts/lumina_upwind_outer_variant.py`는 봉인된 기존 native
고정-J C 경로에서 **구간 커널 호출 하나만** 교체해 새 root에
격리 빌드한다. 아래 반례 확인 전에는 실제 물질70/J71·110 ray·
8분할·native49/50의 전주파수 F 실행에 연결했으나,
**그 CLI 연결은 이후 제거했다**. 현재 합성 전용 직접시험 코드다.

Lageunha CPU1 합성 직접시험 13개 통과(구간 해석해, 3b+청색
결합 상수장, signed χ, 고정-J 광선 반복, 속도0에서 기존 연속
커널과 같은 결과, 속도 있는 진공에서 청색→적색 이동의 주파수
격자 세분 수렴). 격자 재적분 시험4개까지 합해 17개 통과다.
이는 봉인 CMFGEN Bézier SC 재현이나 실제
S III 광흡수율 검증이 아니다. 현재 Lageunha 32코어에서
별도 LagForce MPI 작업이 상당한 CPU를 소비해 **16스레드
실제 F를 중복 투척하지 않았다**. 새 수송 결과·실제 잔차
판정은 아직 없다. 아래 반례가 실행 보류의 더 강한 이유다.

### 2026-10-23 반례 — 현재 8분할 상풍 비교기 실제 실행 폐기

같은 P0 상수 `χ,b`, `η=0`에서 이산 청색 상풍 연립 ODE의
정확한 Green 함수는 입사 한 빈 spike에 대해
`I_{k-r}=exp[-(χL+3Δ+λ)] λ^r/r!`, `λ=Δ/dlogν`다.
715Å 실제 native49–50 중앙광선의 `Δ=0.0018759549664`,
C `dlogν=1.1267110173509078e-5`를 쓰면 `λ≈166.5`다.
`χL=3.2`, 512빈의 청색 spike를 같은 구간에 넣어 원식을
직접 평가했다. 위 endpoint-linear 청색 강도 근사를 써서
8/32/128 공간분할을 했을 때, 정확한 이산 P0 해의 최대값으로
정규화한 전빈 최대오차는 각각
`0.7709682955 / 0.5096507833 / 0.1126127016`이다.
이는 실제 물질의 오차 측정이 아니라, **현재 커널 자체가 의도한
이산 연산자를 8분할에서 재현하지 못한다는 합성 반례**다.
매끈한 진공 특징의 격자 세분 시험 통과는 이 반례를 덮지 못한다.

운전자는 `diagnose_lumina_native_position.py`에서
`--upwind-p0` 실제 F 옵션을 제거하고 기존 연속 실행 경로만
보존했다. 잘못된 비교 F를 생산하지 않았다. 관련 직접시험은
새 반례를 포함해 18개 통과했다. Astra도 현재 B 구현의
물질70/J71 실행 폐기에 동의했다. 다음 물리 판별은 여전히
같은 청색 입사 스펙트럼·물질·경계에서 바깥 native49–50의
600–750Å S III율에 대한 **주파수 연산자**의 영향이다.
이를 위해서는 먼저 endpoint-linear 근사가 아닌 정확한 P0
이산 상풍 Green 적분의 구현·비용을 입증해야 한다. CPU16·
64GiB·1시간을 넘는 전주파수 실행이나 두 주파수 packet만의
외삽으로 대역 원인 판정을 자동 확대하지 않는다.

`scripts/lumina_upwind_p0_oracle.py`에 소형 임의 주파수별 signed
χ·비음수 η의 **고정계수 이산 상풍 연립식**을 sparse 행렬지수로
푸는 기준해를 추가했다. 입사 spike의 위 Poisson 해,
signed χ 정지해, 음수 방출 거부의 3개 직접시험이 Lageunha
CPU1에서 통과했다. 이것은 원 CMFGEN 공간 SC가 아니고
8192빈 상한의 작은 기준해다. 단일 상수 사례의 실측 시간은
512/4096/8192빈에 약`0.019/0.034/0.052초`였지만,
이를 1,115,020빈·모든 광선·모든 구간의 실행 시간 보증으로
외삽하지 않는다. 실제 비교에는 광선별 **완전한 청색 입사
스펙트럼**과 지역 χ/η/b가 여전히 필요하다.

### 추가 판별: CRAM16은 실제 드리프트의 대체 적분기가 아니다

고정계수 sparse 행렬지수의 합성 성능을 실제 광학깊이까지
외삽할 수 없어, 상삼각 역대입 IPF CRAM16 후보를 소형 음성
대조군으로 구현했다. `scripts/lumina_upwind_p0_cram.py`는 물리
수송에 **연결되지 않았다**. Lageunha CPU1에서 실제 중앙광선의
주파수 이동량 약166.5빈을 쓴 두 직접 대조가 모두 원 기준해
수용에 실패했다. 512빈 입사 spike는 음수 출력으로 fail-closed,
256빈의 주파수별 양의 χ 사례는 최대 상대오차 `0.01647942`였다.
따라서 이 후보를 실제 S III율 또는 스펙트럼 생산에 쓰지 않는다.
대응 반례 시험은 실패 사유를 재현하는 **음성 대조군**으로 둔다.
이는 큰 실제 광학깊이에서 sparse 기준해가 효율적이라는 주장도
아니다.

사용자 요청에 따라 최신 Astra 의견을 Muse에 요약 전달했다. Muse는
8분할 근사의 물리 실행 기각에는 동의하고, 음성 대조군 보존을
권했다. 정확한 Green 적분의 작은 시험만으로 전주파수 실행을
승인할 수 없고, 실제 광학깊이·청색 경계·속도구배·S III 가중율
오차·비용까지 봐야 한다고 지적했다. 원자료 직접 검증 없는
자문이며, 특히 현재 sparse 행렬지수는 **이미 Green 기준해를
계산하는 방식**이므로 둘의 결과를 비교하는 것만으로 독립
검증이 되지 않는다. 다음 판별은 실제 계수의 크기와 안정성
범위를 먼저 한정하고, 독립 해석해/구현과 동일 가중율을 대조한다.

### 원 계수의 광학깊이와 실제 S III 율 잔차의 겹침

Lageunha CPU1에서 봉인 원 장 `FORMAL_PRIMARY_FIELDS.bin`
(SHA256 `d9073ac830d8a70beffc731dc919140b2b97ccff7e8d960060d42a7f7ca60563`),
완성 F `F-native-positions.npy`
(SHA256 `d000593d1c41474e9b10399cda6643e72a869b82d9204977b6518d211149095e`),
물질70/복사장71의 동일 shell39 인구·S III 생산 PHOT route를
읽기 전용으로 재사용했다. 원 장의 `field[4]`가 기록된 χ이며
native49–50 반경 차는 `9450.138449578284`(1e10 cm 단위)다.
원 주파수 600–750Å의 5196점에서
`τ=.5(χ49+χ50)Δr`를 계산했다. 이는 **원 native 두 점 사이
방사 방향의 χ 깊이**이지 전체 광선의 실제 광학깊이가 아니다.

원 격자 전체의 `photon_weights`를 유지하고, 완성 F를 logν-선형
투영하여 각 점에서
`dRν = χ_abs,SIII(shell39,ν) × (F49ν−J49ν) × photon_weightν`를
합산했다. `χ_abs`는 기존 `continuum_grid`와 활성화된 준위 용해
경로를 사용했고, 보간·구적·인구는 기존
`compare_lumina_native_node_rates.py --compare-grids`와 같다.
구간 합 `168.20066844676882 cm⁻³ s⁻¹`는 봉인 원격자 결과
`168.200668446768`을 재현한다. 자료 위치와 전체 율 결과 SHA는
위 「완성 장 재적분」 절을 따른다.

| 원 native49–50 방사 χ 깊이 τ | 점 수 | 서명된 S III율 잔차 (cm⁻³ s⁻¹) |
| --- | ---: | ---: |
| 0–1 | 1671 | 62.399687 |
| 1–10 | 1094 | 40.159772 |
| 10–100 | 1096 | 34.005004 |
| 100–1000 | 781 | 23.833709 |
| 1000–10⁶ | 472 | 7.721319 |
| ≥10⁶ | 82 | 0.081176 |

따라서 **완성 장의 현재 잔차** 약81.2%는 τ<100의 점에서,
약95.4%는 τ<1000의 점에서 나온다. τ 중앙값은 `8.181994`,
최대값은 `2.72005e8`이다. 이 표는 어느 주파수점에서 **이미
생산된 F−J를 가중했는지**만 분해한다. 두꺼운 선의 상풍 결합이
다른 주파수의 강도에 미치는 영향을 상한 짓지 못하므로, τ가 큰
점을 수송 계산에서 자르거나 바닥값으로 대체할 근거가 아니다.
반대로 실제 S III 가중율과 무관한 최대 τ만으로 전체 연산자를
선택해서도 안 된다. 다음 비교는 이 동일 생산율 가중치와
완전한 청색 입사 스펙트럼을 유지한 채, τ<100의 주 기여 영역과
두꺼운 선의 비국소 영향을 함께 포괄해야 한다.

### 단순 반경·주파수 오프셋 가설의 한계

위와 같은 봉인 F49, 원 J49/J50, 동일 S III 생산 `χ_abs`와 원격자
`photon_weights`에서 완성 장의 **주파수점별** 가중 절대차
`Σν wν |F49ν−J49ν|`는 `168.473622151259 cm⁻³ s⁻¹`다.
서명된 합 `168.200668446769`과 구별한다. 한 개의 반경 혼합
계수 `t∈[0,1]`로 `J_t=(1−t)J49+t J50`를 만들고 동일 가중
L1을 최소화하면 `t=0.31426689`, 남는 절대차는
`89.216558655893`(원래의 **52.96%**)다. 이것은 실제 F49가
native49–50 사이 31% 위치에서 채취됐다는 뜻이 아니라
**반경 오프셋 가설의 최선 단순 템플릿**이다. 10Å별 생산율
합으로 추정한 t도 약`0.194–0.365`로 일정하지 않다.

원 CMFGEN J를 `logν+δ`로 이동해 같은 PHOT 가중 L1을
격자 탐색했다(`δ∈[−0.003,0.003]`, 간격`5e-5`; t는 0–1을
0.05 간격 탐색한 뒤 선택 δ에서 연속 최소화). **주파수 이동만**
허용하면 탐색 최선은 `δ=0`, 즉 절대차가 줄지 않는다.
반경 혼합과 함께 쓰면 탐색 최선 `δ=5e-5`, 정련한
`t=0.32526670`, 잔차 `84.813732385661`(원래의 **50.34%**)다.
이 탐색은 고정된 완성 장의 경험적 형태 대조이지 실제 속도장,
계면 위치, 청색 입사 또는 원 CMFGEN 수송을 재실행한 결과가
아니다. 따라서 **단일 상수 반경 오프셋/전역 주파수 이동만으로
잔차 스펙트럼을 해소하지 못한다**는 제한된 결론만 낸다.
분광 모양의 나머지는 공간·주파수 연산자 및 비국소 청색 결합을
동일 입력으로 비교해야 분리할 수 있다.

### 광학적으로 두꺼운 native 점에서 확인한 공간 표본 오차

원 장의 native49 총원천함수를 원 기록 그대로
`S49=(eta_true49+es49*J_source49)/chi49`로 계산했다. 같은
완성 F4/F8·원 J를 원격자에 logν-선형 투영해, 위 방사 방향
`τ=.5(chi49+chi50)Δr`로 묶었다. F4와 F8의 `execution.json`은
서로 **11/11개 입력 SHA와 source_rule이 같고**, native49/50
관측 반경도 같다. 따라서 이 직접 비교에서 바뀐 것은 내부
공간분할 4→8이다. 각 비율의 중앙값은 해당 τ 집합에서 점별로
구했으며, 율 가중치 중앙값은 아니다.

| τ 하한 | 점 수 | median(F4/S49−1) | median(F8/S49−1) | median((F4/S49−1)/(F8/S49−1)) |
| --- | ---: | ---: | ---: | ---: |
| 1000 | 554 | 0.0443924 | 0.0220888 | 1.99096 |
| 10⁴ | 232 | 0.0239207 | 0.0118471 | 2.00807 |
| 10⁶ | 82 | 0.0238606 | 0.0118175 | 2.01909 |

같은 τ≥10⁶ 점에서 원 CMFGEN `median(J49/S49)=1.00000000573`다.
F8은 아직 `1.01181746`이고 점별 최대 편차는 약`0.1131`이다.
F4/F8의 1/N에 가까운 감소와 `2F8−F4`의 τ≥10⁶ 중앙
`S49` 상대 편차 `−0.0002257`은 **소구간 중점에서 선형 보간한
χ/η를 출구 native49 관측점의 계수로 사용한 공간 표본 오차**와
부합한다. 실제 `NativeSpatialGeometry._path`의 `weight`는
`z` 소구간의 중점 반경에서 계산되고, 원래 C 수송은 그 고정
계수로 소구간을 통과한 뒤 끝점에서 강도를 관측한다. χ가 큰
한계에서 F가 중점 원천함수를 기억할 수 있다. 이 해석은 코드
구조와 분할 수렴을 함께 근거로 하지만, 각 광선별 기여를 따로
포획한 직접 인과 실험은 아니다.

실제 S III 생산 PHOT 가중치로 원 F8−J의 τ≥1000 부분은
`7.8024955251 cm⁻³ s⁻¹`(전체 `168.200668`의 약4.64%)이며,
그중 F8−S49는 `5.2078326482`다. τ≥100의 F8−S49를
더해도 `16.6377196929`다. 국소 원천함수 대조는 공간
표본 오차의 존재를 보여주지만 **전체 잔차의 주원인을 확정하거나
전부 제거하지 않는다**. 특히 τ<100과 청색 비국소 결합은
별도의 동일 입력 연산자 비교가 필요하다. 출구 원천함수로
강도를 사후 치환하거나 χ를 자르는 방식으로 이 수치를
인위적으로 맞추지 않는다.

### 같은 native 계수 대조와 공간분할 잔차의 크기

기존 완성 F4/F8의 같은 물질70/J71 입력에서, 원격자 S III
생산 PHOT 가중치로 outer49 600–750Å `F−J`를 다시 계산하면
각각 `178.948054750060 / 168.200668446769 cm⁻³ s⁻¹`다.
점별 선형식 `2F8−F4`를 **진단 템플릿**으로만 적용해도
`157.453282143477`이 남는다. 이는 분할무한대의 수송해를
인증한 Richardson 외삽이 아니다. 공간 중점 표본 오차를
고치는 일이 필요하지만, 4→8 추세만 더 밀어서는 현재

### 강성 P0 기준해와 조건부 국소 민감도

운전자는 고정 공간구간의 주파수별 χ/η와 청색 상풍 결합을
`scripts/lumina_upwind_p0_bdf.py`의 sparse BDF로 풀었다. 이것은
봉인 CMFGEN의 Bézier 공간 short-characteristic도, 실제 광선별 입사
이력을 사용한 계산도 아니다. 2빈의 강한 청색 흡수(`χL=10⁶`)와
약한 적색 흡수의 해석적 과도해를 상대 약`3.5e-8`로 재현했고,
주파수별 χ의 소형 행렬지수 기준해 및 signed χ 정지해와 대조했다.
따라서 이전 8분할 endpoint-linear 커널의 합성 반례를 피하는
**국소 이산 P0 기준해**로만 사용한다.

한 차례 Strang 분할 후보는 흡수 깊이가 공간 분할 수보다 훨씬
큰 2빈 사례에서, 분할 수를 늘려도 실제 출구 강도
`2.703206098470242e-7` 대신 사실상 0에 자기수렴했다.
자기수렴이 정확성을 보장하지 않는 반례이므로 그 후보는
새 생산 경로로 연결하지 않았다. BDF 역시 원 연산자를
재현했다는 뜻은 아니다.

봉인 native49/50 χ·η의 한 방사구간을 고정하고, 실제 광선 대신
CMFGEN `J50`을 **프록시 입사**로 사용했다. 중앙광선 drift와
동일 PHOT 생산율 가중치를 적용한 600–750Å 국소 시험에서
연속 주파수 특성선과 이산 P0를 같은 입력으로 비교했다.
대상 전체에 대해 경계 겹침창을 사용했다. 수치는 다음과 같다.

| 등간격 격자 | 빈 수 | 연속율 | P0 BDF율 | P0−연속 서명차 | 점별 절대차 가중 합 |
| --- | ---: | ---: | ---: | ---: | ---: |
| C 간격 | 19805 | 731.534005 | 730.344709 | −1.189297 | 6.178812 |
| C 간격 4배 | 4952 | 730.572934 | 726.118100 | −4.454834 | 18.207567 |

율 단위는 `cm⁻³ s⁻¹`이며, 이는 한 공간구간·J50 프록시의
**조건부 결과**다. 더 성긴 격자가 국소 연산자 민감도를 키웠지만
원 CMFGEN의 실제 비균일 격자는 아니다. BDF 상대허용오차를
`1e-7→1e-9`로 바꾸었을 때 생산 가중 절대변화는 각각
`3.33e-5 / 2.82e-5`였고, 입력에는 최대 `χL≈3.19e8`이
포함됐다. 이 전대역 수치는 일회성 탐색 계산으로 얻었으며,
동일 입력을 자동 재현하는 runner와 겹침창의 청색 경계 오차
인증은 아직 없다. 따라서 원 잔차의 상한이나 종료감사 증거로
쓰지 않는다.

완성 장의 실제 `F−J=+168.200668`과 위 `P0−연속`은 입사,
광선·공간경로, 격자 및 비교 방향이 다르다. 크기·부호를 직접
대조해 원인 비율이나 배제 판정을 내릴 수 없다. 실제 연산자
기여를 판정하려면 원 formal의 광선별 입사·청색 이력과 공간
stencil을 확보해 동일 입력에서 원 강도→J→율을 먼저 재현해야 한다.

### Astra 계획과 Muse 교차 자문: 다음 묶음의 조건

Astra는 원 formal의 **compact ray capture를 통한 최소 재실행**을
권고했다. 기존 저장 자료에서 같은 정보를 온전히 재구성할 수
있다면 그것이 우선이다. capture 자체가 완료 조건은 아니며,
실제 입사·원격자·각도·χ/η·drift·공간 stencil을 고정한 재현
후에만 원/대체 연산자의 조건부 비교를 수행한다. 2×2 교체의
교차항을 단독 효과로 억지 분해하지 않는다. 기존 봉인 F/J는
불변으로 보존하고, 원 재현 실패·청색 경계 민감성·자원 한도
초과 시 기여율 판정을 중단한다.

사용자 요청으로 이 의견을 Muse에 전달했다. Muse는 실제
광선별 입사 포획의 필요성에는 동의하고, 주파수·공간 연산자의
결합 및 비선형 제한자 때문에 2×2 혼합 이산화의 해석을 특히
경계하라고 했다. 또한 정의·정규화·PHOT 가중치의 선행 대조와
청색 절단 민감도 기준을 권했다. 이 자문은 원자료를 직접
재현한 감사가 아니다. Muse가 위 국소 조건부 차이와 실제
`+168`을 크기·부호만으로 직접 대조한 해석은 입력과 연산자
방향이 달라 채택하지 않는다. 완성 장의 동일 가중·원격자
재적분은 이미 위에서 수행되어 후처리 재표본 차이를
`0.027866`으로 한정했으나, 수송 내부의 정의·입사 차이는
여전히 열려 있다.
