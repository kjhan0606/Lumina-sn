# S III 바깥 잔차의 주파수 연산자 분리 — 2026-10-23

## 묶음 목적과 현재 판정

최종 목적은 CMFGEN과 Si/S 자기일관 분포·물리량·스펙트럼의 동질성을
입증하는 것이다. 이 묶음에서는 고정 물질70/J71의 native49에서
남은 S III 600–750Å 광흡수율 초과 `168.172803 cm⁻³ s⁻¹`에
**주파수 수송 연산자 차이가 실제로 기여하는지**를 판별한다.
기존 C 4→8 공간분할은 초과분을 약6.0%만 줄였다. 이번 단계의
국소 광선 계산·코드 시험을 최종 자기일관 결과로 바꾸지 않는다.
현재 원인 기여율은 **미판정**이고 최종 목표는 `active/NOT_MET`다.

## 기존 자료로 확정한 비교 경계

- CMFGEN 실제 715Å packet의 광선은 전체 `NP=105`, native49/50을
  통과하는 광선은 각각 `56/55`개다. C 8분할의 실제 광선은 전체
  `110`, 해당 두 점을 통과하는 광선은 `59/57`개다. 따라서 두
  완료 J장을 직접 빼는 것은 주파수 연산자 **단독** 비교가 아니다.
- CMFGEN 600–750Å 원격자는 1-based 주파수 인덱스
  `40286–45481`의 `5196`점, C는 0-based `624907–644711`의
  `19805`점이다. 715Å packet의 `dLOG_NU=4.507060464033018e-5`,
  C 격자는 `1.1267110173509078e-5`로 간격비 `4.000192`다.
  공통 주파수 격자를 정하지 않은 차이도 연산자 단독 효과가 아니다.
- CMFGEN의 `(χ+(α+3)b, η+αb I_blue)` 이산 upwind와 C의
  연속 주파수 특성선은 물리적 이동을 서로 다르게 이산화한다.
  715Å 중앙광선의 실제 주파수 대각 깊이는 양방향 약`41.6`이고,
  source의 청색측 기여는 `88.8–99.3%`다. 그러나 기존 packet은
  두 주파수·중앙광선뿐이라 600–750Å 전각도 광흡수율의
  원인·기여율을 산출할 수 없다.
- 실제 원 장에서 1-based 인덱스 `1–45481`의 주파수별 formal 호출은
  `2회 17727점 / 3회 26085점 / 4회 1669점`이다. 목표 대역도
  `2회 38점 / 3회 5158점`이다. 따라서 마지막 호출을 언제나
  `JIT2`라 가정하는 포획은 불완전하다.
- 기존 full-packet writer는 누적 `268435456B` 한도를 갖고
  주파수마다 여러 파일을 만든다. 선택 범위만5196점으로 늘리는
  방식은 이 계약을 위반하고 메타데이터 부하를 낳으므로 사용하지 않는다.

## 715Å 각도 대조: 읽기 전용 조건부 증거

원 packet `FORMAL_44361_02`의 실제 강도와 기하를
`compensated_moments`로 합산한 native49/50 J는
`1.1638397927833626e-8 / 3.864721577547988e-8`이다.
**같은 원 광선 강도·μ 위치**에 C `moments`의 μ-선형 적분을
적용하면 두 값이 상대 `3e-16` 이내에서 재현된다. 즉 이 packet의
각도 적분식 자체는 52.6% 바깥 차이의 설명이 아니다.

원 강도를 μ에서 선형 보간하여 **C의 impact 위치만** 바꾸면
바깥/안쪽 J 비는 각각 `0.9998838107 / 0.9999915896`이다.
C 위치의 β는 원 C 속도장에서 `0.04128207857 / 0.03940917778`로
계산했다. 이 재표본은 **CMFGEN 강도를 보간한 조건부 값**이지
실제 C 광선 강도 또는 600–750Å 전체 각도오차의 상한이 아니다.
한 주파수의 작은 재표본 차이를 이유로 광선 차이를 통제됐다고
가정하지 않는다.

이 판독의 봉인 입력 SHA256은 CMFGEN packet 기하

## Astra의 묶음 계획과 운전자 보정

Astra는 전달 수치만을 사용한 조건부 계획에서 CMFGEN 원 광선·
원주파수 격자를 공통 입력으로 택하고, 동일 signed χ·η·고정 J·
산란 source·경계·반경·각도 적분 아래 두 주파수 연산자만 비교하라고
권고했다. 초기 답변의 `110 ray 동일`과 `χ 비음수`는 위 원자료를
전달하자 명시적으로 철회했다. 원 계약은 **signed χ 허용**이며,
η·강도 비음수와 유한성을 확인하되 새 χ floor/clip은 넣지 않는다.
Astra는 코드·원자료를 직접 재현하지 않았고 구현·실행도 하지 않았다.

## 다음 내부 작업과 중단선

먼저 CMFGEN 원격자·`NP=105` 광선과 C의 연속/이산 방식을 같은
공간계수 표현에서 계산할 수 있는지를 소형 합성자료로 확인한다.
원 packet의 2점만으로는 대역을 닫을 수 없다. 실제 자료가 필요하면
기존 writer를 넓히지 않고, **주파수당 고정 크기 compact record**로
원 formal의 해당 광선 입사·청색 입력·출력과 χ/η·기하를 모은다.
가변 2/3/4회 호출에서는 마지막 호출의 record가 남도록 하되 원
formal 결과를 변경하지 않아야 한다. 상류 주파수 절단을 gain 없는
감쇠 가정으로 정당화하지 않는다. 필요하면 목표 대역의 청색
시작점부터 원 주파수 인덱스1까지 포함해 빈틈없이 보존한다.

입력·자료 포획만으로 연산자 기여율을 선언하지 않는다. 두 연산자를
**같은 ray·주파수·계수·공간 보간·경계**에 놓고, 먼저 원 CMFGEN
packet의 endpoint/J를 독립 재현한다. 이후 같은 PHOT/Milne·셀39
고정 인구로 native49의 600–750Å 광흡수 변화를 `168.172803`과
같은 정의로 비교한다. 마지막 셀 한 구간만 바꾼 계산이라면
`국소 조건부 민감도`라고 기록하고 전 경로 연산자 기여율로
확대하지 않는다. 전대역을 실제 계산하지 않으면 `1.525951`과의
전대역 비율 판정도 하지 않는다.

계측·계산은 새 빈 root, Lageunha 수동 CPU≤16/GPU0,
메모리≤64GiB, 벽≤3600초, compact 출력≤512MiB,
한 번의 원 formal 실행·자동재시도0을 상한으로 계획한다.
원본 물질·장·packet·C 결과는 덮어쓰지 않는다. compact 기록을
이 한도에서 검증할 수 없거나 같은 공간/격자 입력으로 두 연산자를
평가할 수 없으면 `기여율 미판정`으로 남기고 전주파수 재실행으로
자동 확대하지 않는다. 현재 새 빌드·새 formal 실행·연산자
교체·SE/RE 갱신은 **0**이다.
