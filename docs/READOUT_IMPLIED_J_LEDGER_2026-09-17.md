## 0. 결론 (세 줄)

1. **율·폐합은 결백하다.** Lumina 의 이온비 `Γ(J)/(n_e α)` 를 같은 σ_bf 표·준위·LTE 가중으로 직접 재적분하면
   런의 Saha-stage 비를 **0.5–3 %** 로 재현하고, `Γ(B)/α = Φ_LTE` 가 **0.1 %** 로 성립한다(S II·Ca II). 과이온화는 전부 **σ-가중 J** 다.
2. **σ-가중 J 의 초과는 몇 개의 «창 빈»이 만든다** — 557.7 / 696.7 / 856.6 / 922.5 Å 등 단일 빈에서 `J/B(T_e)` = 10³–10⁶,
   그 빈은 셸 21–40 에서 **투명**(χ_tot = n_eσ_T, τ_shell ≈ 10⁻⁴) 하다. S II 광이온화의 45–85 % 가 이 빈들에서 나온다.
3. **광원은 외곽 고온층(셸 41–49, T_e = 12→24 kK)** 이다. 거기서 Lumina 는 S V·Si V·Ca V(LTE) 이고, 그 이온들의 EUV 선이
   **S_l = B(T_e)** 로 방출한다(η_bb/χ_bb = 1.02 B; 선 불투명도는 Saha 이온밀도 + Boltzmann 으로 **3자리 재현**). 에너지 수지:
   창 빈 방출력의 96–99 % 가 셸 41–49 에서 나오고, 관측 J 가 요구하는 공급의 ×2–10 안이다. 대조 빈(623 Å, 창 아님)에는 그 방출도 초과도 없다.

⟹ **원인 열(cause column)**: `NLTE 미포함 이온(≥ IV) 의 선 소스함수 = B(T_e)` × `twin 핀이 준 외곽 고온층` × `EUV 창(선·bf 불투명도 부재)`.
CMFGEN 은 같은 T 프로필에서 외곽이 S III/IV·Si III/IV 에 머문다(희석 장이 이온화를 정함) — 그 차이가 이 지도의 중간 셸 과이온화(S·Si·Ca 한 단계)를 만든다.

## 1. 함의 J 장부 (σ 무관·대역 평균) — 세 열

세부균형: `n_{q+1}n_e/n_q = Φ_LTE(T)·Γ(J)/Γ(B(T))` ⟹ 공개 CMFGEN 의 비 r_C 를 내려면 σ-가중 대역평균으로
**J_req/B(T) = r_C/Φ_LTE(T, n_e)** 가 필요하다(분배함수 = NLTE 덤프 준위 E·g 로 계산, T·n_e = 공개 CMFGEN 앵커 행).
같은 잣대로 Lumina 의 비(09-14 지도 SAHA_STAGE)를 나누면 «Lumina 함의 J/B» 가 된다. 셋째 열은 자체런 J 표를 σ∝ν⁻³ 가중한 값.
`implied_J_ledger.csv` 300 행; 아래는 셸 구간 median.

10³–10⁵ 배 높다 — **자체런 J 표는 이 대역의 잣대가 아니다**(대장의 「이온화 oracle 부적격」이 EUV 에서도 성립). 이후 절은 표를 쓰지 않는다.

  채움 자체는 별도 루틴이 아니라 **LTE 선 소스(S_l = B) 가 불투명 빈에서 J → B 를 만든 결과**로 읽는 것이 맞다(§4).

### 4-1. 기전 사슬 (전부 오프라인 실측)

```
twin 핀: T_e(sh41–49) = CMFGEN 프로필 12→24 kK
  → 외곽층 Saha stage: S V / Si V / Ca V (LTE(T_e)-급; CMFGEN 은 III/IV)
  → 그 이온은 NLTE 밖 → 선 준위 Boltzmann → S_l = B(T_e) (η/χ = 1.02 B 실측)
  → 외곽층이 자기 선(557.7 Ca V, 696.7·922.5 S V …)에서 20 kK 흑체로 방출 (Σ4πηV 의 96–99 %)
  → 셸 21–40 은 그 파장에서 투명(χ_tot = n_eσ_T) → 안쪽으로 비춤 (J/B 10³–10⁶ 창 스파이크)
  → σ-가중 Γ(S II·Si II·Ca II) 가 Γ(B) 의 3→5,000 배 → 중간 셸이 III/IV 로 밀림 (지도의 「한 단계 과이온화」)
  → (자기강화) 외곽층 불투명 빈은 J = B(T_e) 이므로 외곽 자신의 이온화도 LTE 로 잠긴다
```

CMFGEN 은 같은 T 프로필에서 (i) 모든 이온이 NLTE 라 희석 장 아래서 S_l ≪ B 이고 (ii) 외곽 이온화가 T_e 가 아니라 희석 장으로 정해져 III/IV 에 머문다.
⟹ 이 지도의 중간·외곽 어긋남은 **원자자료·율·수송 수치**가 아니라 **「NLTE 밖 이온의 열적 선 소스」+「외곽 T 핀」** 의 곱이다.

## 5. 주장의 상한

- **기전은 실측, 크기는 twin 조건부.** 외곽 20 kK 는 핀이 준 것이다. 자유-T_e 런에서 외곽층이 얼마나 뜨거운지·같은 창이 열리는지는 이 판독의 범위 밖이다(기존 대장의 「far-outer hot branch」가 같은 자리일 가능성만 기재).
- 창 빈의 J 가 외곽 방출로 **충분히 설명되는가**는 에너지 수지(×2–10 안)로 보였고, formal solution 재계산은 하지 않았다.
- 이 사슬의 첫 고리(외곽 S V·Ca V 자체)가 창 조명의 결과인지 T 핀만의 결과인지는 순환이라 오프라인으로 못 가른다 — 그러나 **두 경우 모두 S_l = B(T_e) 폴백이 필요 고리**다.
- Si II 의 Kramers 비대칭(5–9 %)·`T_NOT_TWIN` ulp·Fe 행 UNDEFINED(조성 0 의 표기)은 별건으로 기재만.
