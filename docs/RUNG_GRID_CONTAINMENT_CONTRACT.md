# 단 — 주파수 격자 포함 계약 (사전등록, 2026-08-08)

R6 폐합으로 결정론 팔이 처음 A2-10 에 도달했고, **두 팔이 같은 지점에서 막혔다**.
계측 한 번으로 확정했다.

---

## 계약 (하나)

> **격자들 사이의 포함 관계가 계약으로 선언되고 검사된다.
> 소비자 격자의 모든 빈은 생산자 격자가 **완전히 덮는** 영역 안에 있어야 하며,
> 위반은 **발행 시점**에 이름 있는 사유로 거부한다 — 소비 시점에 조용히 막히지 않는다.**

---

## 1. 실측 — 1000개 중 **2개**가 전체를 막는다

```
[A2-10][REBIN-DIAG] first_fail shell=0 em_bin=0 nu=[1.500000e+14,1.507969e+14]
    rf_validity=4(OUT_OF_GRID) | em_bins_blocked=2/1000
    hist(0..7)=0,3068,0,0,2,0,0,0        <- VALID=3068 · OUT_OF_GRID=2 · 나머지 0
    em_range=[1.500000e+14,3.000000e+16]  rf_range=[1.440293e+12,4.032418e+16]
```

방출률 범위 전체에서 겹치는 canonical 빈 **3,070개 중 3,068개가 VALID** 다.
막는 것은 **2개**, 그것도 **양 끝**이다.

## 2. 기전 — 격자 끝점이 빈 경계에 놓이지 않는다 (오프라인 계산)

| 격자 | 정의 |
|---|---|
| canonical 복사장 | 4000 log 빈, `[1.4402928950097124e12, 4.032418413741097e16]` (`radiation_field.h:9-11`) |
| 방출률/BF | 1000 log 빈, `[NLTE_NU_MIN=1.5e14, NLTE_NU_MAX=3.0e16]` (`lumina.h:547-548`) |
| CMFGEN 결정론 원격자 | `cs->nu`, 위 BF 범위 |

방출률 끝점을 canonical 빈 좌표로 환산하면:

```
NLTE_NU_MIN = 1.5e14  ->  canonical 빈 좌표 1814.786   (빈 1814 **내부**)
NLTE_NU_MAX = 3.0e16  ->  canonical 빈 좌표 3884.470   (빈 3884 **내부**)
```

⟹ canonical 빈 1814·3884 는 **원격자 밖으로 삐져나간다.**
commit 이 그것을 `OUT_OF_GRID` 로 표시한다 — 소스 주석이 스스로 적은 대로
*"Coverage shortfall means the target bin extends beyond the source grid:
**structural, not statistical**"* (`radiation_field.c:386-390`).
그 두 빈이 방출률 빈 0·999 와 겹치므로 `a210_rebin_checked_J` 가 거부하고
A2-10 전체가 `RADEQ_TERM_MISSING` 으로 막힌다.

**차단은 옳다.** 모르는 빈을 0 으로 적분하면 안 된다.
틀린 것은 **세 격자 사이의 관계를 아무도 소유하지 않는다**는 것이다.

## 2.1 ★결정적 사실 — 생산자와 소비자는 **같은 격자**다

`cmfgen_init`(`lumina_cmfgen.c:1464-1467`):
```c
cs->n_bins = NLTE_N_FREQ_BINS;   cs->nu_min = NLTE_NU_MIN;   cs->nu_max = NLTE_NU_MAX;
```
방출률 발행도 같은 `NLTE_*` 격자를 쓴다. ⟹ **생산자 격자 == 소비자 격자**(1000 log 빈).

그런데 둘 사이에 canonical 복사장(4000 빈, 더 넓은 범위)이 **중개**한다.
그리고 canonical 은 BF 격자의 **세분이 아니다**:

```
canonical dln = 0.0025599650      BF dln = 0.0052983174
비율 = 2.069683   ← 정수가 아니다
```

⟹ **같은 격자인데 canonical 을 경유하는 왕복에서 양 끝 두 빈이 파괴된다.**
내부 빈들은 살아남지만(VALID 3068) 그것도 정렬돼 있지 않아 재빈닝이 **근사**다.

이것이 이 단의 실체다: 중개 격자가 양 끝에서는 **정보를 잃고**, 내부에서는
**정렬되지 않은 재집계**를 한다.  두 팔의 비교를 "동일 1000-bin 격자" 라고 부른 것도
이 층위에서 다시 봐야 한다(Fable E 의 공통모드 지적과 같은 자리).

## 3. 왜 캠페인의 표적인가

고리는 세 격자를 **소비**하는데 그 **포함 관계를 생산하는 주체가 없다.**
각 격자는 자기 헤더에 상수로 선언돼 있고, 서로의 정합은 **런타임에 우연히** 성립하거나
성립하지 않는다.  오늘은 성립하지 않았고, 그 사실이 **A2-10 도달 전까지 6개월간 보이지 않았다**
(도달한 적이 없으므로).

## 4. ★수리 방향 — 하지 말아야 할 것부터

⚠**`OUT_OF_GRID` 를 0 으로 취급하는 수리는 금지다.**  그것은 클램프 계급이다 —
모르는 값을 아는 값으로 바꾼다.  판별식: 정확해가 위반할 수 있는 가드는 잘못된 것이다.

## ★user 결정 (2026-08-08): **안 B**

세 줄에만 나오고, 불투명도는 주파수 조회이며, `atom->cmfgen_sigma_bf` 는 `lumina_cmfgen.c`

   다만 실패 시 진단은 유지한다(이 단이 심은 `[A2-10][REBIN-DIAG]`).
4. 선택된 안(A 또는 B)의 구현.

# 안 B 구현 명세 (user 결정 2026-08-08)

## 격자 정의 — **파생**한다, 따로 선언하지 않는다

```
K = 2                                   /* 정수 세분 계수 */
dln_canon = ln(NLTE_NU_MAX/NLTE_NU_MIN) / (K * NLTE_N_FREQ_BINS)
j_lo = floor( ln(현 RADFIELD_NU_MIN / NLTE_NU_MIN) / dln_canon )      = -1754
j_hi = ceil ( ln(현 RADFIELD_NU_MAX / NLTE_NU_MIN) / dln_canon )      = +2112
canonical 빈 수 = j_hi - j_lo = 3866
canonical edge[i] = NLTE_NU_MIN * exp((j_lo + i) * dln_canon)
```
실측값: `dln=0.0026491587`, 범위 `[1.439090e12, 4.036258e16]`, **3866 빈**.
BF 빈 `b` ↔ canonical 빈 `[1754+2b, 1754+2b+1]` — **정확 집계, 잔차 0**.

★핵심: 상수를 **세 벌 따로 선언하지 않는다.**  canonical 은 BF 격자에서 **파생**되므로
포함·정렬 관계가 구성상 성립하고, 나중에 어느 한쪽만 바뀌면 컴파일 시점에 깨진다.

## 기대 변경집합

1. `radiation_field.h` 의 세 상수를 **`lumina.h` 의 `NLTE_*` 에서 파생**되게 바꾼다.
   리터럴 유지 금지 — 파생식으로 쓴다.
2. 초기화 시 **정렬 단언**: `NLTE_NU_MIN`·`NLTE_NU_MAX` 가 canonical 빈 **경계**에
   정확히 놓이는지, `K` 가 정수인지 확인하고 위반 시 이름 있는 사유로 종료.
3. **왕복 항등식 자가검사**: 알려진 J 를 소스 격자에 놓고 → commit → 방출률 격자로 재빈닝
   → **소스와 기계정밀도로 일치**해야 한다(결정론 팔은 소스 격자 == 소비자 격자).
4. `a210_rebin_checked_J` 의 **판정 로직은 그대로**(fail-closed 유지) + 이 단이 심은
   `[A2-10][REBIN-DIAG]` 진단 유지.

**변경하지 않는 것**: `NLTE_N_FREQ_BINS/NU_MIN/NU_MAX`(⟹ 덱의 `cmfgen_sigma_bf.bin` 무영향),
방출률 격자, `cmfgen_init` 의 소스 격자, 어떤 물리식도.
