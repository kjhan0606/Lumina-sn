## 2. 공통 원자 재결합 상태 치환 (주 산출 2, 등급 COMMON_ATOM)

d_k = log₁₀(n_e^O α_k(T^O) / n_e^C α_k(T^C)). **이 값은 CMFGEN 의 실제 율이 아니다**(같은 원자 처방을 두 열적 상태에서 평가한 진단값).

- 고정 T 레인이라 **T^O/T^C = 1.000**(전 행). 따라서 d_RR = d_DR = log₁₀(n_e^O/n_e^C) 이다.
- 범위: −0.15 … +0.28 dex(Si·Fe·Co·Ni, 정의 가능한 82행씩). 철족 셸에서는 −0.14 … −0.03 dex(n_e,O 가 0.72–0.94 배).
- 계수 출처(`evidence.json`):
  - RR = 덱 단면적의 Milne 계수, III 바닥상태 핵. CMFGEN 링크가 각 II 이온의 A 경로만 쓰고 그 최종 상태가 III 바닥상태(들뜸 0.0)임을 PHOT 파일 헤더로 확인했다. Si II 는 Nahar 비평활 단면적이라 `MILNE_WITH_RESONANCES`, Fe·Co·Ni II 는 `MILNE` 다.
  - DR = DR_TABLE 첫 일치 항목(배율 1): Si BADNELL, **Fe NORAD**, Co·Ni AUTOSTRUCT. 소스 주석이 NORAD 를 「R-matrix unified RR+DR total」로 적으므로 Fe 는 `TOTAL_RECOMB` 다.

**판정 문장:** 같은 원자 처방 안에서 O 의 열적 상태(n_e)는 철족·Si 저전리 셸에서 **재결합을 공개 상태보다 약하게** 만든다(−0.03…−0.15 dex). 관측된 III/II 결손(−1…−3 dex)과 방향이 반대이고 크기가 1–2 자릿수 작다. 따라서 **이 열적 상태 차이는 저전리를 설명하지 못한다.** 실제 CMFGEN 재결합 처방과의 차이는 이 단의 대상이 아니다.

## 5. 판정 문장 (§6 순서)

1. **전리비:** Fe·Co·Ni 의 III/II 는 철족이 있는 12셸 모두에서 공개보다 0.1–3.1 dex 낮다. Si 는 셸 4–33 에서 0.39–3.52 dex 낮고 셸 34–49 에서 0.42–1.66 dex 높다.
2. **재결합 상태 치환:** T 가 같아 n_e 비만 남는다. 저전리 셸에서 O 의 재결합은 공통 처방 기준으로 오히려 약하다(−0.03…−0.15 dex) — 저전리를 설명하지 못한다.
3. **조건부 필요 총 전리율:** Co·Ni 만 얻었다. O 쪽 비교값은 없다.
4. **남는 미식별:** 광이온화·비열적·충돌 전리의 CMFGEN 값, O 의 철족 채널, O 의 Si 채널(정확 대응 없음), Fe·Si 의 RR/DR 분리. 공통 원인 질문에서 Si 와 철족이 함께 적격인 채널은 III/II 와 재결합 상태 치환뿐이고, 둘 다 같은 부호(III/II 낮음, n_e 낮음)다 — 공통된 열적 상태 반응과 양립할 뿐 공통 원인의 입증이 아니다.
