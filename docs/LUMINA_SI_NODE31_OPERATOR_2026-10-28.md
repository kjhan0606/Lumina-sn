# 원31점 Si 선 계약과 정상해 영향 — 2026-10-28

F2의 Si III 최대 차이가 발생한 원31점에서 기존 원70 물질·같은 장의 BF율과
전쌍 충돌을 재사용하고 native 이산 선율을 적용한다. Si 원 입력에 대한
행별 작용을 native witness와 비교하고, 고정 T/ne/J의 Si 정상 후보를
기존 생산 선율 후보 및 원70 입력과 비교한다. 새 수송·공개 물질 갱신이나
다른 원소·전하·RE 공동해는 없다. 생산 선율 후보와 native 선율 후보가
같은 원70 조건임을 확인하되 원70을 정상해라고 가정하지 않는다.

실행은 Lageunha CPU1·4GiB·최대180초·GPU0·단회, 별도 디렉터리에서 한다.
이는 특정 점의 원인 분석이며 90점 분포와 최종 스펙트럼의 수용판정이 아니다.

결정되지 않았다. 고정장 정상해의 성분별 잔차는 `7.42e-17`이며 전하·RE
