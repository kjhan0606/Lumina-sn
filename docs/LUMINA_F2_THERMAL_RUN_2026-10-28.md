# F2 고정장 T/ne 물질 보정 — 승인 단회

## 목적과 판단 범위

최종 목표는 Si II/III·S 분포, 물리량과 observer 스펙트럼의 CMFGEN
물리 동등성이다. 이 실행은 그 목표를 위한 같은 자체장 F2의 전90점
전원소 SE·공통 전하·온도 보정이다. 한 방향의 수용이나 고정장 내부
수렴을 수송/산란·공동수렴 또는 최종 동등성으로 바꾸지 않는다.
원70은 released-T 수렴 정답이 아니므로 원70 분율에 가까워지도록
온도를 조정하지 않는다. 후보의 잔차 감소와 Si/S 참조 차이를 함께 보고한다.

## 사용자 승인·실행 위치

사용자 「한도 승인함」에 따라 Lageunha CPU16·32GiB·빌드와 종료 유예
포함 최대12시간·단회·열보정 최대5평가·GPU0·새 수송0·재시도0을 적용한다.
원 수용 온도에서 완료 F2 ne를 시작값으로 SE·열을 실제 재평가하고,
필요한 기존 전하 초기화 뒤 열보정을 수행한다. 현재 내부42600초,
부모 timeout43170초와 종료 유예30초로 전체12시간 이내로 제한한다.
Slurm 기본4시간 경로와 기존 실행 권한은 늘리지 않는다.

승인 단회의 고유 실행 root 이름은 `lumina_F2_thermal_12h_20261028`이다.
Lageunha에서 기존 관련 프로세스가 없는지 확인하고 이 root를 새로
만든다. 이미 존재하면 다른 root로 몰래 재시도하지 않고 실제 PID·결과를
확인한다. 입력·기존 F2·다른 프로젝트 프로세스는 수정하거나 종료하지 않는다.

## 봉인 입력과 변경

기준 F2는 `lumina_F2_response_lageunha_20261028-bBbs8U/run`이며 보고서
SHA256은 `b6d411ff28971492280275d2201e9d84a65315c0ad2613f04444e7b270b5fbea`다.
준비 보고서 SHA는
`4707762a819fee7f013fb8655ad5d6a738c9f64cfd1ddc897e5138caa9478887`,
F2 J SHA는 `fc66fc815d7e8c67028c269944e01227611497f7bdfa129bff863a18c1f69308`다.
실행 전에 원 되먹임 기록과 입력을 다시 검증한다. 코드 commit을 봉인하고
그 commit의 source snapshot과 바이너리를 새 root에서 생산한다.

BF/BB/FF 기준 계수만 재사용한다. 현재 후보의 occupation·Saha/Milne·
충돌·전원소 SE·광자/외부열·깊이 결합 단열은 기존 생산자로 평가한다.
바뀐 온도 BF는 전체 적분하며 새 T에 기존 T의 bound율을 대입하지 않는다.
감쇠 알고리즘이나 물리식은 바꾸지 않았다.

각 완료 후보의 response/balance와 호출 순서를 보존한다. 네 섭동 뒤에는
Jacobian·원 잔차·log 방향·척도와 기준/섭동 후보 신원을 방향 평가 전에
저장한다. 이는 동일 기준점에서 비싼 섭동을 다시 계산하지 않기 위한
자료이며, 후보를 수용했다거나 재개 실행이 승인됐다는 의미가 아니다.
이 실행은 아직 Newton 중간 재개 소비 코드의 완성을 주장하지 않는다.

## 해석·보존과 다음 결정

5평가는 중앙차분4개와 방향 후보1개다. 첫 후보 거부만으로 방향 전체가
틀렸다고 결론내리지 않으며, 수용돼도 내부 RE/전하가 닫혔는지 따로 읽는다.
거부 시 기존 수용 물질과 모든 완료 평가를 보존한다. 현재 승인으로
6번째 평가나 추가 실행을 자동 수행하지 않는다. 수용점이 달라지면 이전
Jacobian을 새 점의 정확한 Jacobian이라고 사용하지 않는다.

출력에는 같은 상태의 전하/SE·열잔차, 실제 T/ne·Si/S 전90점 분포와
비수렴 CMFGEN70 비교를 포함한다. 전하가 미폐합이거나 열이 정체하면
수송으로 문제가 해결됐다고 보지 않는다. 기존 F2 모멘트는 새 온도
후보의 수송 잔차가 아니다. 실제 수용 물질의 새 계수·산란 수송 및
공동수렴·observer 비교는 이후 원래 목표에 남는다. 원본과 실패 출력을
보존하며 자동 재시도나 결과 삭제는 하지 않는다.

초기 BF 재사용 후 첫5평가 시도는 과거 실측 기준 약6–9시간 추정이며
상계나 공동수렴 완료 예상이 아니다. 추가 후보는 새 온도 BF 전적분이
필요하므로 같은 비용으로 간주하지 않는다. 운영 비용·시간·평가 횟수는
운전자가 판단하고 Astra에 비용 대비 효용 자문을 추가 의뢰하지 않는다.
