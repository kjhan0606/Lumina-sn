1. «폐합 차단» 공통 입력 결함이 전체 상태 미산출로 전달되지 않음 — F0 는 빈 미정의·정지 목록으로 조립됐고, 개입 상태는 대상의 미정의만 검사했다. 바닥 준위(비대상) BF 진술의 방향 결함은 공통 조립기가 상위 바닥을 `gh_fl` 로 쓰기 때문에 다시 막히지 않는다 → BF 연결 검사에서 시작하는 `bf_states` 를 두었다. 미정의 Si II BF 진술이나 Si II 밖 BF 진술이 하나라도 있으면 F0 포함 일곱 상태 모두 조립·풀이·수치 반환을 하지 않는다. 범위 소속이 불명이면 여섯 개입을 정지한다. 음성 대조는 실제 연결 검사에서 바닥 준위 방향 결함을 주입해 전 상태 미산출과 풀이기 미호출을 확인한다(72cd4a4).
2. «폐합 차단» 양의 기록 곱이 0 으로 소실되는 경우를 정확한 영값과 구분하지 않음 → `bf_check` 가 R_bf·f_lev 와 n*·I_rec 에서 양의 인수 곱이 0 이 되면 `REPRESENTATION` 미정의로 기록한다. 정확한 영값 I_rec 는 유효하다. 직접시험을 추가했다(72cd4a4).
