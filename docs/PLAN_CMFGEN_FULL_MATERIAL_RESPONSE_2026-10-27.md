# 전90점 공통 물질응답 묶음 — 깊이 결합을 보존하는 원소 SE 제거

## 목적과 현재 상태

최종 목적은 Si II/III·S 이온화 분포, 물리량과 스펙트럼의 CMFGEN 동질성이다.
이 문서는 이미 계획한 전90점 공통장 SL-SE·전하·RE 물질응답 묶음의 해법을
구체화한다. 고정 물질의 계수 생산이나 한 점의 SE 잔차 통과를 완료로 바꾸지
않는다. 최종 기준은 `CODEX_CMFGEN_EQUIVALENCE_PLAN_v2.md`를 유지한다.

계획 평가 담당은 **Astra**, 구현·실행·자체시험·재현은 **운전자**다.
Astra agent `01a1797c-ec37-76f1-a046-5e27e4c04d11`의 읽기 전용 평가를
운전자가 전사했다. 초기 도구 실행 실패 뒤 읽기 전용 실행 권한 경로로
공유 맥락·프로젝트·정확한 소스와 원 MODEL을 확인하고 평가를 완료했다.
평가는 조건부 승인이지 아래 미구현 항목의 실행·완료 증거가 아니다.
작은 내부 확인마다 재평가를 요청하지 않는다.

## Astra 결론: 원소 SE 제거는 지지, 90개 독립 T/ne 루트는 반대

고정 J와 trial T/ne에서 원소별 정규화 SE가 유일하고 모든 계수가 다른
원소 population에 의존하지 않으면 `n_Z=phi_Z(T,ne)`로 제거하는 것은
원래 연립방정식의 정확한 제거다. 전체 Newton과 해집합은 같지만 수렴
경로나 안정성까지 같다고 보장하지 않는다.

원 물질70의 MODEL은 **INC_AD=T**다. `src/cmfgen_adiabatic.c`는 이웃 깊이의
T·전자분율·내부에너지 기울기를 사용한다. 따라서 외부 문제를 **90개 독립
2변수 문제로 바꾸면 안 된다.** 원소 SE를 내부에서 제거해도 바깥의 T/ne는
깊이 결합을 보존한 최대180변수 계로 둔다. 경계 조건에 의한 실제 독립
변수 수와 방정식 선택은 구현 시 원 계약과 대조한다.

## 원소별 선형성의 근거와 남은 적용범위 확인

- 현재27개 bound ion은 양이온이다. terminal까지 완전히 소유하고 원소총수를
  고정하면 occupation의 양이온 **입자수 합**은 stage 재분배에 불변이다.
  전하가중합과 전자밀도는 불변이 아니며, 모든 원소에 공통인 미지수다.
- 확인한 BB/BF·직접 CI/C3·용해·Omega(T)는 고정 trial의 occupation·SL 분율·
  역률에서 population에 선형이다. 이것만으로 전체 활성 과정의 완결성을
  증명한 것은 아니다.
- 원 MODEL에서 CE와 nonthermal은 꺼져 있다. CE의 반응상대 인구나
  population 의존 전자감속을 켜면 원소 간 추가 결합이 필요하다.
- radioactive decay와 즉시 deposition은 켜져 있다. nonthermal 비활성을
  외부 열원 부재로 해석하지 않는다.
- SE 시간·이류 스위치는 꺼져 있지만 RE 단열항은 켜져 있다.
- FF는 보통 SE 독립성을 깨지 않으나 실제 이온별 전하가중 열률을 RE에
  포함해야 한다. INC_TWO·DR 등 남은 채널의 적용/비적용도 확인해야 한다.
- Penning은 스위치가 켜져 있어도 확인한 native 구현이 요구하는 HI/HeI가
  현재 roster에 없다. 이 사실을 다른 원자모형에 일반화하지 않는다.

## 최소 구현 경로와 에너지 소유권

기존 private 후보, 일반 원소 블록 및 GTH를 재사용한다. legacy pair/Saha
경로의 model-aware 거부를 없애지 않고 별도 full-model residual을 둔다.
trial마다 T/ne→occupation·partition·SL 분율→동적 율→전원소 SE→전하·
전체 RE를 평가한다. 원소총수·terminal·원자주소·복사/물질 세대 및 고유
trial 신원을 유지하고 실패 후보를 공개 물질로 게시하지 않는다.

복사 에너지 장부에는 BF 전체 광자 에너지, BB 광자, FF와 실제 외부 열원·
단열항이 들어간다. BF 광자=전자 운동에너지+문턱×복사 순천이율이다.
직접 CI/C3·용해 충돌 열량을 복사 RE에 다시 더하지 않는다. 내부에너지와
SE 잔차를 통해 두 장부의 off-root 관계를 검증하며, 같은SL 내부 과정과
온도 의존 SL 평균에너지를 버리지 않는다.

미분에는 `A_Z*dphi_Z=-(dA_Z)*phi_Z`, `sum(dphi_Z)=0`가 포함되어야 한다.
전하 루트의 유일성·단조성을 가정하지 않는다. 원소 해의 연결성·유일해와
입자 보존을 확인한다. sigma는 route/frequency 블록으로 공유하고 모든
FL쌍×90점×반복의 거대 상주 배열이나 전체 반복 파일을 만들지 않는다.

## 입력·제외·증거와 수용

원 물질70·원197291점 J70·전90점·27이온 및 terminal을 공통 입력으로
유지한다. BF90 결과는 고정 물질의 입력이지 trial 역률을 재생산하지 않아도
되는 캐시가 아니다. 원 J의 물리 BB 미표본은 계속 미완으로 유지한다.
native 미사용 선의 비교 재현을 물리 선 누락 해소로 표시하지 않는다.

같은 원자주소·J·물질에서 제거 전의 항별 SE/전하/RE와 population/T/ne/
혼합 centered Jv를 native와 대조한다. 제거 후 민감도와 Schur complement
대응도 확인한다. 내부 FD 시험만으로 native Jv 동등성을 주장하지 않는다.
입자·전하1e-10, 최종 SE1e-8, RE1e-3 및 기존 v2 율/E/Jv 기준은 유지한다.
부족한 native 대응 증거는 검증불가로 남기고 기준을 낮추지 않는다.

신규 수송·native anchor 계산·공개 물질 게시를 이 계획 평가만으로 추가하지
않는다. 새 완성장과 자기일관 수송, matched-physics released-T reference
anchor는 후속으로 필요하며 원 고정T70은 certified anchor가 아니다.
최종 스펙트럼·물리량 및 격자 수렴 전체 수용 범위는 유지한다.

실행 자원은 기존 CPU16·OpenMP16·32GiB·2시간·GPU0·retry0 이내다.
직접시험은 CPU1·4GiB·10분 이내이며 로그인 노드에서 계산하지 않는다.
봉인 입력·원본·실패/부분 결과를 보존하고 새 디렉터리에서만 실행한다.
실측 비용 확인 없이 2시간 수렴을 보장하거나 자동 한도 확대/재실행하지
않는다. 실제 실행 신원·재현 명령·출력·해시와 미해결 사항은 당일
인수인계서에 합쳐 기록한다. **현재 공동해법과 최종 목표는 미완료다.**

## 에너지 계약 보완 — Astra 추가 평가와 동일율 후처리

이 계획의 물리 광자 장부와 실제 native 열방정식은 자동으로 같지 않다.
운전자의 소스 추적 뒤 Astra `01a178b2-657c-7ba1-ab5a-637a898d5198`가
원 MODEL·정확한 코드의 읽기 전용 평가로 확인했다. `SCL_LN=T`는
온도·인구 비의존 g-평균 SL 문턱으로 선 열량을 바꾸며, 잔차 STEQ_T와
열행 BA 모두에 적용된다. 단순 전처리나 Jacobian만의 차이가 아니다.
정적 평균은 native 단열 내부에너지에도 들어간다. 기존 코드의 실제 hν와
온도의존 SL 평균에너지를 조용히 이 규칙으로 덮어쓰지 않는다.

물리 `physical_photon_ledger`와 별도 `native_compatible_thermal_ledger`를
분리하고, matched-native 열응답을 풀 때 어느 장부를 선택했는지 명시한다.
호환 장부의 계수는 원 설정대로 `s=(평균 EDGE_lower−평균 EDGE_upper)/nu`이고,
`abs(s−1)>0.5`이면1, 각 점의 원자 총수 POP_ATOM이1e30 이상이면1이다.
POP_ATOM을 ne로 바꾸지 않는다. same-SL의 s=0도 범위 밖이므로 fallback1이다.
순 광자 에너지·A·율·opacity/emissivity 자체는 바꾸지 않는다.

기존 BB90과 BF90의 동일 인구/율에 두 선 에너지 규약만 적용한 첫 정량
결과는 `LUMINA_LINE_THERMAL_LEDGER_2026-10-27.json`이다. 전790493선 중
568606개는 계수가1에서1% 넘게 다르다.90점 모두 밀도 해제 분기 밖이다.
이는 계수 적용범위이지 모든 선의 열 기여가 크다는 뜻이 아니다.
S 원소 순선열 차이/gross 최대1.03414e-5, Fe3.61644e-3 등이며, 전체 RE의
분모나 이온분율 오차로 바꾸어 해석하지 않는다. native 이산 Jbar와 새
선형장 Jbar의 차이도 이 후처리에서 동시에 바꾸지 않았다.

다음 실제 공통 residual을 연결하기 전에, 같은 후보의 정적/동적 내부에너지·
깊이 결합 단열 차이와 off-root SE 에너지 관계도 확인한다. native 대응
잔차/Jv가 없는 항은 여전히 검증불가다. 이는 현재 물질응답 묶음 내부의
물리 계약 보완이며 별도 작은 묶음 종료나 추가 수용 게이트가 아니다.
새 RT/native·공개 물질 게시·자원 확대를 승인한 것으로 해석하지 않으며
released-T 앵커·실제 격자 수렴·최종 물리량/스펙트럼 요구를 유지한다.
