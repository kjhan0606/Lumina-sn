# 연속 양수 재구성 후보 — CPU 준비, 원 급선 기준 미달·생산 미채택

## 목적·선택·범위

원목표는native90 자체J1/J2·J1잔차·생산Si/S율을거쳐CMFGEN의이온분포/스펙트럼/물리량동질성을검증하는것이다. 기존7차재구성의부호오판정및정확한limiter의불연속을 [합성 반례](LUMINA_RAY_ERROR_RECONSTRUCTION_2026-10-22.md)에서확인했으므로,이를기록만하고넘기지않고연속양수후보를준비했다. 현재434043 구간수송·원소스·봉인입력·수치기준은전혀변경하지않았다. 새후보를실제GPU나전체장에연결하지않았다.

Astra `01a161e4-570d-77c0-8f33-a29ed21acf73`를동일수리설계범위로재개해공개추상계획을검토했다. 선택은 `CONTINUOUS_MONOTONE_CANDIDATE`다. 계수정밀도수리만으로원수학적limiter의불연속이없어지지않으므로연속양수·범위보존후보를별도CPU경로로준비하되,고정밀산술/이산화차이/격자수렴/실제PHOT1e-4를구별하고경로오차carry는별도로해결하라는기획판단이다. 자문은완료·닫았으며실제실행승인/수치수용이아니다. 구현과직접시험은운전자Codex가수행했다. 다른모델이나반복감사/게이트를추가하지않았다.

## 구현과 원 경로 보존

`cmf_monotone_reconstruction.hpp`는균일logν의4점cubic Hermite후보다. 내부미분은같은부호인두secant의조화평균이며부호가다르거나0이면0,양끝미분은인접secant다. 내부공식의배경은 [SciPy의 공식 PCHIP 설명](https://docs.scipy.org/doc/scipy/reference/generated/scipy.interpolate.PchipInterpolator.html)과같지만,그라이브러리의단측끝공식을사용하지않으므로**SciPy PCHIP와동일한구현이라고하지않는다**.

조화평균은작은기울기/큰기울기비로계산해곱의overflow를피한다. cubic control과양의혼합은각각독립Positive가수/지수로유지해극소중간값을공통밝기에나누어없애지않는다. native절점/큰이동의청색끝상수연장·평탄값은유지한다. 물리I에clamp/floor를적용하지않으며수학적범위를벗어나거나double로양수를표현못하면실패로남긴다. `one_scaled`는그양수와지수를보존해후속gain으로회복할수있다. 미래GPU컴파일용선언은있지만이번에장치컴파일/실행을검증한것은아니다.

기존 `cmf_gpu_reconstruction.hpp`/실제수송선택은변경하지않았다. 이산화가다르므로원7차비트동일성을판정기준으로삼지않는다. 특히 `[144,36,4,0,0,4,36,144]`의중간값은새범위보존후보도0이다. 이는인접두0을상수로보간하는새정의이며,**원7차의정확한0.0625를복구한산술수리라고표시하지않는다**. 이차이는테스트에서명시적으로확인한다.

## CPU 직접시험 — 실패를 그대로 보존

root `/gpfs/kjhan/cmfgen_runs/lumina_monotone_recon_CPU_20261022-1XLvy3`, CPU1/4GiB/전체작은시험3분이내만사용했다. GPU0·물리수송0이다. 후보헤더SHA256 `0f220a80d6f99bfc427c159c9567db6221d9513bc3520f02a11390bb90022a17`.

첫시험은 **17통과/1실패·0.87초**다. 독립900자리Decimal Hermite와극소상수·약한/큰스케일·급변/평탄/역방향·정확한절점·범위보존·분기근방연속성·부적합입력canary·표현불가양수의scaled보존을확인했다. 매끈한합성함수는513점의최대개별상대차1.28674146e-5다.

원급선시험의4097점은개별최대상대차 **1.07615978e-4 > 1e-4**로미달했다. 이실패를없애거나기준을완화하지않았다. 실패한원테스트와로그를그대로남겼으며후보를생산에채택하지않았다. 단순양의가중합은3.42699317e-8이지만그것으로개별출력실패를덮지않는다.

같은식·같은합성함수에서격자만미세화한별도조사 **1통과/0.62초**를추가했다.

## 현 판정과 다음 실제 목표

**CPU 선택후보 준비·원 급선 기준 미달·생산 미채택·자체장/Si-S율/CMFGEN 목표 NOT_MET**다. 후보의작은안정성통과를기존7차수리완료/전체장정확도/스펙트럼합격으로표시하지않는다. 광선사이입사오차carry·재구성결함/반올림·관측점/PHOT축약오차는아직연결되지않았다.

현재434043을그대로마무리하고원미세3열/완결/비용을확인한다. 다음의미있는결정은실제자료의분해능과경로오차를포함해자체J1/J2·생산Si/S율을산출할수있는수리안을선택하는것이다. 이CPU준비만으로새GPU/전체장/과학적기준/자원을확대하지않는다.
