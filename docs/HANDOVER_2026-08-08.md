# 최신 추기 — SH-RADEQ/MC-EVT (2026-08-08)

이 추기는 아래 본문의 역사적 `eta_bb=0`, `RADEQ_NO_BRACKET`, “감리 대기” 상태를
대체한다.

- A2-09 line emission은 `chi*line_source_S`가 아니라
  `n_u A_ul h nu beta_esc/(4 pi Delta_nu)` 직접 생산자다.
- raw Sobolev τ production writer는 3개로 census됐고 모든 writer가 세대를 자체
  증가/완료한다. A2-09는 소비 양끝에서 generation view를 재검사한다.
- NLTE τ authority predicate와 LTE line population routine은 writer/reader 공용이다.
- `RE_INTEGRAL`만 T_e producer이고 `EHB_THERMAL`은 diagnostic이다.
- 불완전 전자 병진 단열항은 diagnostic으로만 남고 fixed/free-T 모두
  `RADEQ_INCOMPLETE_ADIABATIC`으로 publication을 차단한다.
- 실제 덱에 기존 grid 하한 아래 default-active CMFGEN BF edge 707개가 있으므로
  OOG exact-zero 안은 기각됐다. SH-GRID는 1178-bin migration 계약으로 재개방됐다.
- Fable 최종 중요 재심:

```text
IMPLEMENTATION_CLOSURE = ACCEPT
FLIGHT_STATE = BLOCKED_INCOMPLETE_ADIABATIC
```

# 7. 인수자가 반드시 알아야 할 함정

오늘 하루에 실제로 데인 것들이다.

| 함정 | 실제 사례 |
|---|---|
| **"빌드 OK" 가 CPU 만 뜻했다** | DET-R6·SH-GRID 두 단 연속.  `.cu`·공유 헤더·API 시그니처를 건드리면 **`make cuda` 도** 돌려야 한다 |
| **`make` 는 최신이면 rc=0 으로 무작동** | 플래그만 바꿔 다시 부르면 무효.  `rm -f <target> && make ...`.  **타임스탬프·sha 로 확인** |
| **env 를 넘겼다 ≠ 그 env 로 돌았다** | 하니스가 런처 env 를 `eval` 로 덮어써 **DET 를 MC 라 불렀다**.  `T3_LANE` 신설로 해소 |
| **그 env ≠ 그 팔의 온전한 구성** | DET 런처 env 로 MC 를 돌려 전송이 전멸했다 |
| **바이트-parity 검사기를 병합 로그에 쓸 수 없다** | 같은 바이너리를 두 번 돌려도 stdout/stderr 끼어듦 위치가 다르다 |
| **다중집합 비교는 byte 비교가 아니다** | 순서·셸 위치를 버린다.  값 교환을 못 잡는다 |
| **주입한 결함의 실재를 먼저 확인** | 안 하면 음성대조가 무효.  "주입했는데 통과" 를 "결함 없음" 으로 읽으면 안 된다 |
| **게이트는 양방향으로 갈려야 자격** | 부재→차단(NC1)과 **정당한 0→통과**(NC3)를 둘 다 시연해야 한다 |
| **판정 기준 = 단 경계** | 넓히면 남의 단의 실패를 내 단의 실패로 적는다(오늘 2회) |
| **빌려온 계약은 원래 양의 불변식을 데려온다** | 침착률을 온도 매니페스트로 해싱 → `te>0` 이 따라와 **모든 덱에서 발행 불가** |
| **`pgrep -f` 자기매칭** | 오늘까지 4회.  PID 기반 `kill -0` 을 쓴다 |
| **`run_in_background` + `nohup &` 겹치면 죽는다** | `make cuda` 가 컴파일 도중 끊겼다.  memory `reference_background_launch_patterns` |

### 38c. CMFGEN ion별 emission/absorption 분해

- CMFGEN `LINEHEAT`/`NETRATE`의 789,775 numbered Sobolev record를 순서와 line ID,
