## 1. 채움은 두 겹이고, 둘 다 코드 위치가 특정됐다

| 겹 | 어디서 | 실측 | 코드 | 소비자 |
|---|---|---|---|---|
| ① **불투명 빈 채움** | bf-불투명 EUV 빈(100–912 Å 의 65–100 %, 셸 0–36) | J/B(T_e) = **1.000** 인데 S_tot/B = 0.05–115 (`opaque_source_check`) ⟹ J 는 소스함수를 따르지 않는다 | `cmf_fine` 고정 소스 `S_fixed = (χ_abs·B(T_e) + η_line)/χ_tot` (`lumina_cmfgen.c:5686`) — **연속체 방출 = Kirchhoff-LTE**. 기록된 NLTE η_bf(S_bf/B = 3–500)는 솔버가 쓰지 않는다 | 중간 셸(9–24) 이온화의 **LTE(T_e) 고정** |
| ② **창 빈 램프** | 투명 창 빈(557.7 Ca V·696.7/922.5 S V …), 셸 24–40 | J/B 10³–10⁶; 방출력 96–99 % 가 셸 41–49 | `cmf_fine_line_material` parity 분기(`:4498–4540`): η₀ = n_upper·A·hν/4π, n_upper 는 `lumina_line_upper_population_fill_for_tau` → `a209_upper_population_for_tau` 의 **`lte_level_density`**(NLTE 밖 이온 = `used_nlte==0`) ⟹ S_l = B(T_e) 정확히 | 셸 12–40 의 σ-가중 Γ 초과(3→5,000×) |

- `planck_census`: 불투명 빈 중 |J/B−1|<1 % 인 분율 — 100–912 Å 에서 셸 0–8 **1.00**, 12–36 **0.65–0.94**, 40+ 0.01–0.12(창이 열림); 912–2000 Å 은 0.08–0.42; 광학은 0.
- ② 의 방출 이온은 **S V·Ca V**(Lumina 외곽 LTE 상태) — NLTE 표적은 31 슬롯 전부 **ion II·III**(런 배너), `LUMINA_NLTE_STAGE4` 는 Si·Fe·Co·Ni·Ti·Cr·Al **IV** 만이고 S·Ca IV·어떤 V 도 없다 ⟹ 승격으로는 램프 이온에 닿지 않는다.
- ε 기전은 코드에 **이미 있다**: legacy 분기 `emit = line_eps<1 ? line_eps·B : source`, `radeq_line_eps_phys(line,n_e,T_e,τ)` = C_ul/(C_ul + A_ul β_esc)(전 이온 표). **parity 분기는 ε 를 전혀 보지 않는다** — 그래서 외곽 n_e 10⁵ 의 S V 선이 20 kK 흑체로 방출한다(물리 ε ≈ 10⁻⁷).

## 2. 램프 제거의 예측 — 정적 formal solution (`formal_predict.py`)

구면 정적 formal solution(산란 무시: 창 빈 τ_es/셸 ≈ 2×10⁻⁴; 소스 = 솔버와 같은 χ_abs·B + η_bb; 내경계 B(T_e(sh0)); λ<1300 Å 전 빈).

**검증(발행 J 재현)**: 창 빈 sh28–44 에서 ×0.3–1(557.7 Å sh32 0.98, sh36 0.56; 922.5 Å 전 셸 0.25; 696.7 Å 0.4), 그러나 **sh20–24 는 10³–10⁴ 배 과대**.
원인: `cmf_fine` 은 comoving-frame — 안쪽으로 가는 램프 광자는 속도차(Δλ/λ ≈ 5 % ≫ 빈폭 0.5 %)로 **이웃 빈의 선숲**(551.8 Å τ 385–5,280 등)을 지나며 흡수된다. 정적 단일-빈 해는 그 흡수를 못 본다.
⟹ 이 예측기는 **방향과 자릿수**만 준다. 아래 수치는 상한/하한 표기로 읽는다.

## 3. ① 에 대한 메모 (다음 rung, 이 계약 밖)

① 을 NLTE η_bf 로 바꾸면 확산 극한에서 `J → S_bf = B·(r/Φ)` 이고 율 방정식은 `r = Φ·Γ(J)/Γ(B)` 이므로 단일 문턱 근사에서는 **어떤 r 도 고정점**이다(퇴화). 실제 상태를 고르는 것은 퇴화를 깨는 항 — DR(이 런 `FROZEN_DR=0`), 비열적 이온화(미설정), 충돌, 비국소 광자 — 이다. ⟹ ① 의 수리는 「η_bf 교체」만으로는 결과가 초기값(seed = B(T_inner))에 끌려갈 수 있어 **퇴화-파괴 채널과 함께** 계약해야 한다. 기재만 한다.

## 4. 주장 상한
- ② 의 코드 귀속(LTE 상준위 채움 → S=B)은 소스 직독 + 재현(χ_bb 3자리·η/χ = 1.02 B)으로 확정. ① 의 코드 귀속은 소스 직독 + 「J≠S_tot 인데 J=B」 실측.
- 예측 수치는 정적 formal 의 자릿수이며 sh≤24 에서는 CMF 선숲 흡수를 못 본다(검증 표 기재).
- 방출력의 「4 %」 잔여(셸 0–8, τ≈200 아래)는 실제로 탈출하지 못한다 — 상한 스케일링(`predict_lamp_removal.py`)이 이를 과대 유지해 폐기했다.
