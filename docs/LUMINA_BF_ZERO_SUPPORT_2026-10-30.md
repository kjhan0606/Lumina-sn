# BF 적분의 정확한 영기여 생략 — 2026-10-30

## 목적과 변경

온도·전자밀도 갱신에 필요한 전주파수 BF 적분의 비용을 줄인다. 실제
주파수 블록과 원자 경로에서 bound 단면이 전부 0이고, 용해항의 지지도
전혀 없는 경우에만 해당 경로의 모든 깊이 결과를 정확한 0으로 낸다.
기여가 있는 경로는 원래 적분식·더하기 순서·원자료를 그대로 쓴다.
입력 전체의 유한성·부호·주소 검사를 생략하지 않으며, 새 물리 근사나
수렴 문턱을 추가하지 않는다. 경로별 유효성은 깊이와 무관한 단면/지지로만
결정한다. 이 변경은 진행 중인 봉인 작업 1243823에 소급 적용되지 않는다.

## 직접시험과 제한된 실물 비교

- grammar `debug` CPU1 및 CPU4에서 다음 두 시험 파일을 각각 실행해
  **33개 모두 통과**했다. 0 지지와 실제 용해 기여가 한 블록에 섞인 경우,
  점별 독립식과 여섯 율의 비교, 비유한 입력의 출력 비게시도 포함한다.
- 완료 F2 복사장의 실제 주파수 격자·90개 깊이·원자 단면을 읽고,
  문턱 분포를 대표하도록 128개 경로를 선택했다. 세 1024점 블록에서
  수정 전후 bound/total의 모든 값이 **배열 원소별 정확히 같았다**.

### 실제 S II 전주파수 비교

같은 완성 F2 J와 선택 물질의 원점50에서 S II의 **322개 전 경로와
1,115,020개 주파수**를 수정 전후 각각 적분했다. 모든 경로의 bound/total
여섯 율이 배열 원소별 정확히 같았다. 인구와 경로 확률을 적용한 총
광이온화 흐름은 `56827.7432173518 cm^-3 s^-1`로, 기존 저장 장부의
`56827.74321735181`을 재현했다. 선택 응답의 실제 온도·전자밀도와
occupation/준위분율을 사용했고 새 물질 정상해나 수송은 풀지 않았다.

grammar `debug` CPU1·8GiB에서 두 적분의 단발 시간은 기존 `25.93초`,
변경 `25.80초`다. 차이가 약 0.5%이므로 이 사례에서 의미 있는 전체
가속을 입증했다고 보지 않는다. 위 세 블록과 달리 이 전주파수 비교는
한 원점·S II만 대상이다. 모든 원소·90점의 실제 속도와 새 수송의
물리 결과는 아직 측정하지 않았으며, 이를 CMFGEN 동질성으로 표시하지 않는다.
