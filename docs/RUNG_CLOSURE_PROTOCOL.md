## 감리 고정 질문 3개

★08-08 의 세 건이 **전부 이 셋으로** 잡혔다.

1. **사전등록 게이트 중 미실행이 있는데 단 PASS 로 적었는가**
   - 실제 사례: SH-GAMMA 가 NC2·NC4·Γ4 미실행인데 "폐합" 으로 적음
2. **각 게이트의 증거가 사전등록이 요구한 강도에 도달하는가**
   - 실제 사례: "byte-동일" 요구에 **순서·위치를 버린 다중집합 비교**로 답함
   - 실제 사례: "byte-parity" 요구에 **필터된 로그 줄 비교**로 답함
   - 실제 사례: "어디서 얼마나 움직였나" 요구에 **"표면화 안 됨" 유보**로 답함
3. **판정문의 주장 중 근거 없이 단정한 것이 있는가**
   - 실제 사례: "CMFGEN 은 Newton 을 쓴다" — 파일명만 보고 단정
   - 실제 사례: "양 끝이 음수이므로 어디에도 근이 없다" — **수학적으로 틀림**
   - 실제 사례: "CMFGEN 회색 해가 이 모델에 없다" — 호출 0회를 부존재로 읽음

## 감리 발주 형식

- **read-only**.  코드·패치를 내게 하지 않는다.  산출은 의견서 하나
- 판정문·사전등록·관련 소스를 **스테이징에 인라인**으로 준다(개방 탐색 금지)
- `[실측]/[추정]` 구분과 **파일:행 근거** 요구
- **"모르는 것은 모른다고 적어라 — 추측으로 채우지 마라"** 를 명시
- 의심스러운 지점을 **운전석이 먼저 지목**한다(자기가 약점을 아는 것부터)


## ★빌드 게이트 (2026-08-08 추가)

**"빌드 OK" 는 두 타깃을 다 뜻해야 한다.**

```
make OMP=1 lumina     CPU
make cuda             GPU   ← 생산 경로(런처 299개)
```

근거: DET-R6(`3ca077d`)가 `radiation_field_line_jbar_view` 에 인자를 추가하고
GPU 호출부를 안 고친 채 커밋됐다.  운전석이 **CPU 타깃만 빌드**하고 "빌드 OK" 로
적었기 때문이다.  SH-GRID 도 CPU 만 빌드했다 — **두 단 연속**이다.

- `.cu`·공유 헤더·공용 API 시그니처를 건드리는 단은 **두 타깃 다** 빌드해야 게이트 통과
- 빌드 산출은 **타임스탬프와 sha 로 확인**한다.  `make` 는 최신이면 아무 일도 안 하고 rc=0 이다
- API 시그니처를 바꾸면 **호출부를 전수 grep** 한다(컴파일러가 못 보는 타깃이 있다)

★이 결함은 감사가 지목한 세 건과 같은 계급이면서 더 무겁다.  증거의 강도가 아니라
**아예 안 본 것**이고, 하필 못 본 쪽이 생산 경로였다.
