**말하지 않는 것:** 공개 CMFGEN 재현·어느 가지가 물리적으로 옳은가·쌍안정의 존재/부재 일반론·「Lumina 방정식이 차가운 가지를 지지한다」는 수렴 주장(6반복·미수렴 x_hot 창의 유지/복귀 관측까지만)·차가운 상태의 물리적 안정성(해제 후 이동은 솔버 반복이지 시간진화가 아니다)·NT/시간의존 효과·Si/Ca/철족 판정·자유 T_e·**고정 창의 S II 바닥 b·S_bf 가 차갑다는 것**(고정은 이온 총량뿐이고 준위 분율은 잠금 해가 정한다 — §0-3; 개정 3 은 그것을 **보장하지 않고 기록**한다) ⟹ 이 단은 「S 이온 총량을 공개 분율에 고정한 출발」의 유지/복귀 시험이고, S_bf=B/b 기전에 대해서는 **해석 증인**(매 커밋의 S II 바닥 b_g·창 S_bf/B — §2 준위 증인 writer·§5 b 증인)을 기록할 뿐 기전의 인과 증명이 아니다: HOT-RETURN 을 「소스 되먹임이 되돌렸다」로, COLD-STAY 를 「차가운 소스가 유지됐다」로 **판정하지 않고**, b 궤적이 그 읽기와 정합하는지(후보)·모순하는지(배제)만 기재한다. 총량이 차가운데 b 가 뜨거운 출발이었는지는 해제 직전 커밋(gen 4)의 b_g 가 가른다(§5 ①).

## §2. 초기화 규칙과 주입 설계 — pin-then-release (env 2개, 기본 OFF)
- **env** `LUMINA_INIT_IONFRAC_DIR` = 6 공개 파일 사본 디렉토리(스테이징에 복사, sha256 = repo 원본). 미설정 = OFF: 진입 조건은 이 키 하나이고 평가 지점은 둘(build_bundle 진입의 armed 판정·커밋의 준위 증인 writer, 같은 static helper 로 getenv) — 미설정이면 두 지점 모두 getenv 뒤 어떤 문장도 실행되지 않는다(byte-동일의 근거 = 진입 조건 하나·평가 지점 2). `LUMINA_INIT_IONFRAC_PIN_ITERS` = N_pin(정수 ≥1) = 고정을 유지하는 논리 반복 수; DIR 설정 시 필수(미설정·0·비정수 = fail-closed 종료, 조용한 기본값 없음). **이 런 = 2**(SEED + 반복 0·1 고정, 반복 2 해제). 설계 선택 근거: (a) 준위까지 LTE 분배로 주입하는 안은 뜨거운 rad gen 1 위에서 SEED 준위 해가 곧바로 다시 나누므로(§0-3) 한 반복도 차갑지 않다; (b) 주입을 bootstrap 으로 앞당겨도 rad gen 1 하나만 차가운 물질을 보고 SEED 해는 여전히 자유라 ALI 8 회 초기장 의존(XSHELL 판정문:41)을 못 벗는다; (c) pin-then-release 만이 첫 자유 물질 solve 직전까지 차가운(총량) 물질 위에서 J 를 세 번 풀게 하고(SEED 물질 위 1회·고정 커밋 위 2회; 물질 계수는 매번 다르므로 「일관되게 이완한 상태」의 보장이 아니다 — astra 2회차 4) 고정 커밋을 표준 덤프(ion.csv iter0000·0001)로 증언한다.
- **속도 보간**: 셸 v_mid=(v_in+v_out)/2. 19.480 블록에서 v_mid 를 감싸는 두 행(i,i+1)으로 **각 단계 k 의 ln f_k 를 ln v 에 선형 보간**, 그 뒤 Σ_k f_k=1 재규격화. 범위 밖(v_mid<1,025 또는 >40,325; 현 격자엔 없음)·블록 부재·열 수 불일치 = fail-closed 종료(floor·대체 없음).
- **단계 사상**: Lumina II ← 공개 I+II(합, 총량 보존); III..최상단 ← 공개 같은 단계. 원소별 「공개 단계 수 = Lumina 단계 수 + 1」 검사, 아니면 종료.
- **armed 판정(1곳)**: `nlte_population_candidate_build_bundle`(:22615) 진입에서 armed ← (DIR 설정) ∧ (`request->public_nlte->current_iter` < N_pin), 모든 반환 경로(정상·실패·조기 반환)에서 해제 — armed 는 env 정적 캐시(:11433)에 섞지 않고 호출마다 평가한다. `current_iter` 는 init pass(SEED)=0·논리 반복 k=k(cmfgen.c:8871) ⟹ N_pin=2 는 SEED·반복 0·반복 1 의 후보 solve 전부를 고정하고 반복 2 부터 armed=0 = 생산 해 그대로(그것이 시험). `lumina_cmfgen.c` 는 건드리지 않는다.
- **주입 지점 ① 단계 배열(1곳)**: `compute_ion_populations_shell` 이 원소 e·셸 s 의 단계 밀도를 쓴 직후(:3800–3822 블록 끝, 같은 호출) — armed 일 때만 n_ion(k) ← f_k·n_element(n_element = 그 호출의 율 해가 분배한 총량 ⟹ 원소 총량 보존). 후보의 n_e 폐합 루프·ionization_at_ne 서브반복 전부가 같은 주입 해를 되받는다.
- **주입 지점 ② 준위 합 고정(기존 잠금 경로 재사용, 판정식 3곳에 OR)**: 준위 해의 잠금 판정식 세 곳 — 보존 행 선택(:20027 `ion_lock_mode`)·generator 캡처 조건(:20457)·해 뒤 재규격화(:20674 `lock`) — 에 armed 를 OR 한다(static helper 1개; 잠금 경로 본문은 무변경). armed 이면 S II·S III 준위 합이 각각 주입된 단계 총량에 묶이고(:20238–20263 의 두 보존 행) 재규격화도 이온별 ⟹ 준위합비 = 단계비 = x_pub, Milne S_bf 의 n_III 도 주입값. b_ground(S II) = f_ground/(x_pub·n_e·Φ_1(T_e)) 에서 고정되는 것은 x_pub 뿐이고 f_ground 는 잠금 해가 정한다 ⟹ **b·S_bf 의 차가움은 보장도 인증도 하지 않는다**(astra 2회차 1a; 주장은 총량으로 한정 — §1·§4 G-COLD). **주의**: 고정 창의 준위 해는 두 보존 행 선형 해(legacy ION_LOCK 경로, generator 캡처 OFF)이고 해제 후 = 생산 경로 — 창 안 준위 분포는 측정 대상이 아니다. **고정 창의 방정식은 base 와 다르다**(astra 2회차 2): 두 보존 행은 base 의 단일 합 보존 행에 더해 율 방정식 한 행을 대체하고, generator 캡처 OFF 는 GTH 경로 대신 rank 검사·equilibrated dense solve(:20581 부근)를 택한다 — 실제 수치 경로 변경이다. 정확한 서술 = 「고정 창은 제약된 준비 과정이고, 반복 2 부터는 base 와 동일한 생산 연산자를 **다른 초기 상태**(6원소 인구·준위·n_e·J·반복 이력 전부)에 적용한다」. 새 폐합 규칙은 없다(n_e 폐합 = 기존 NE_CLOSURE). `LUMINA_NLTE_ION_LOCK`·`LOCK_START_ITER`·`PER_ION_RESCALE` 은 398939 값(0) 그대로(§0-3: 재사용 불가). 구현자 확인 항목: XSHELL 캡처 게이트(cmfgen.c:8899/8913/9004)가 generator 캡처 경로에 의존하지 않음(J 솔브 쪽) — 의존하면 보고 후 정지.
- **n_e 폐합**: 기존 NE_CLOSURE 가 혼합 전하합(§0-3)으로 폐합한다. 고정 창에서는 준위 합 = 주입 단계 총량이므로 Q_closed = Σq·n_inj(재규격화 부동소수 오차 내) — ② 의 귀결이지 새 규칙이 아니며, ② 없이는 성립하지 않는다(astra 2).

## §5. 기대치·분기
**판정 통계**: s∈J, k∈{3,4,5}: r_s(k) = ln(x_s(k)/x_pub,s) / ln(x_hot,s/x_pub,s). x_s(k) = iter k ion.csv `Z16_stage_q2/q1`; x_pub,s = §2 보간의 S III/S II(= 고정 상태의 비 — ln 보간이라 재규격화와 무관); x_hot,s = 398939 반복 3–5 기하평균. 0 = 차가운 고정 상태, 1 = 뜨거운 기준. **절대 조건** d_s(k) = |log10(x_s(k)/x_pub,s)| ≤ 0.5 — r 띠만으로는 sh24 x ≤ 4.16·sh30 x ≤ 30.2 도 「차가운」이 되므로(astra 3) COLD 는 공개값 반 자릿수(3.16×) 안까지만 인정한다(0.5 dex 는 도출값이 아니라 선택: 잰 어긋남 1–4 dex 의 최소 gap 의 절반). **셸별 분류**(k=3,4,5 전부로): COLD_s ⟺ 전 k 에 r ≤ 1/3 ∧ d ≤ 0.5; HOT_s ⟺ 전 k 에 r ≥ 2/3; 그 밖 MID_s. 방향 = sign(r_s(5) − r_s(3)), |Δr| > 0.1 이면 UP/DOWN, 아니면 FLAT. 해제 반복 r_s(2) 도 기록(첫 자유 결과; HOT-RETURN 의 다음 걸음이 소비).
**판정 셸 J**(규칙: gap=log10(x_hot/x_pub) ≥ 1.0 ∧ 뜨거운 산포 log10(max/min, 반복 3–5) ≤ gap/3 ∧ 차가운 띠 |log10 x_pub(v_out)/x_pub(v_in)| ≤ gap/3) = **{10–15, 19–30}, 18 셸**. 제외: 9(차가운 띠 0.68 > 0.34, IGE 혼재), 16(산포 0.88 > 0.50), 17(gap 0.84), 18(산포 0.97 > 0.48).
Referent(sh: x_pub / x_hot / gap dex; 저자 계산, 판독기가 `coldstart_referents.csv` 로 재생성해야 함): 10: .241/15.4/1.80 · 11: .181/20.1/2.05 · 12: .186/5.27/1.45 · 13: .197/3.74/1.28 · 14: .210/3.00/1.15 · 15: .233/2.50/1.03 · 19: .349/18.9/1.73 · 20: .392/24.8/1.80 · 21: .490/45.6/1.97 · 22: .572/33.6/1.77 · 23: .696/42.8/1.79 · **24: .744/130/2.24** · 25: .880/369/2.62 · 26: .959/1.51e3/3.20 · 27: 1.10/2.52e3/3.36 · 28: 1.19/3.74e3/3.50 · 29: 1.30/8.75e3/3.83 · 30: 1.43/1.33e4/3.97.
**경계 근거**: [1/3, 2/3] 띠는 gap 의 1/3 을 해상도 단위로 잡은 **선택**이다 — J 선정이 뜨거운 자기 산포를 gap/3 이하로 묶으므로 뜨거운 쪽 1/3 은 그 산포 안이고, 차가운 쪽 1/3 은 절대 조건 0.5 dex 가 다시 좁힌다. 두 우물·분리선 1/2 같은 쌍안정 모형에서 도출한 것이 아니다. 한계(문면): x_hot 는 미수렴(sh30 창 산포 0.91 dex, sh24 66–150)이고 창은 3반복이라 「안정 가지」·「이완 완료」를 증명하지 않는다 — 결과는 이 창의 유지/복귀 관측이다. 반복 창 3–5 = 뜨거운 referent 와 같은 반복 지수(지수만 같고 ALI·DJDN 이력은 다르다 — 고정 창 2반복이 끼므로 「동지수 비교」는 근사). 자유 반복 = 2,3,4,5(4회). ITER 6 근거: (i) Picard 몫 무감쇠라 복귀는 1반복이면 보이나 (ii) 준위 NLTE 되먹임(S II 바닥 b)이 커밋을 거쳐 장에 들어가는 데 ≥2반복, (iii) 대조군과 같은 창. N_pin=2 근거: 첫 자유 물질 solve(반복 2 후보) 직전까지 차가운 총량 물질 위 J 풀이 3회 — iter0 의 J ← SEED gen 2, iter1 의 J ← 고정 gen 3, iter2 의 J ← 고정 gen 4(SEED 의 J 는 bootstrap gen 1 위라 0회; cmfgen.c:8873·9032, 398939 iter1 manifest rad gen 3·pop gen 4). 물질 계수가 매번 다르므로 동일 문제의 ALI 24회가 아니고, G-COLD 가 읽는 iter0000·0001 은 그중 앞 2회의 물질만 증언한다(astra 2회차 4). ALI 8 초기장 의존을 벗었다는 주장은 하지 않는다. N_pin 을 더 늘리면 자유 창이 3–5 에서 줄어든다.
**구성상 참**: r_s(k), k≥2 는 런 없이 못 얻는다(방향 예측 미등록, 갈림길 시험). 예외 명시 — G-COLD 의 고정 창 값(r=0)과 NC-HOT 의 합성 결과는 **구성상 참**(고정 조건의 귀결)이며 판독기 배선 시험이다(astra 6; HOT 픽스처는 개정 2 에서 삭제). 기록(분기 밖, 같은 ion.csv 파싱): r_s(2)(해제 반복; HOT-RETURN 의 다음 걸음이 소비). 임의 기재(판독기 필수 파싱 아님, 판정문이 원하면 기재; grok 2회차 L4): spectral.csv 에서 S II 바닥 엣지(23.34 eV = 5.643e15 Hz)를 담는 bin 의 J_nu, s∈J, iter0000→0001 상대 변화 — 단일 bin 의 국소 증인일 뿐 이온화 적분·다른 주파수·장 전체의 이완 증명이 아니고 398939 대비 비도 수송 잔차가 아니다(astra 2회차 4). 준위 해상 증인 = 매 커밋의 `coldstart_levels_gen%03u.csv`(§2 준위 증인 writer, gen 2–8) — S II 바닥 b_g·창 S_bf/B 를 커밋마다 기재한다(개정 3, 아래 **b 증인**). 뺀 것(grok L4): SEED n_e 대 공개 n_e 비 · Si/Ca/Fe r. (S II 바닥 분율은 개정 2 에서 뺐다가 user 결정으로 b 증인으로 되살렸다.)
**b 증인(개정 3, 해석 층 — 게이트·분기 판정식 아님)**: s∈J, gen g∈{2,…,8}(2 = SEED, 3·4 = 고정 커밋, 5–8 = 자유 반복 2–5 의 커밋). **(a) S II 바닥 b_g,s(g) = n_g / n_g***: n_g = 준위 파일의 (Z 16, ion 1, level_idx 0) n_pop; n_g* = n_e·n_III·(g_g/(2 U_III(T_e)))·(h²/(2π m_e k T_e))^{3/2}·exp(χ_II/kT_e) — n_e·T_e 는 같은 행, n_III = 같은 파일 S III 행의 n_ion_total(단계 배열 = Milne 방출이 쓰는 값, §0-3), g_g = 4, χ_II = 23.3378804222 eV(deck `ionization_energies.csv`), U_III(T_e) = deck `levels.csv` 의 S III 전 준위 Σ g e^{−E/kT_e}, 상수 CODATA 2018(h 6.62607015e-27·k 1.380649e-16·m_e 9.1093837e-28·eV 1.602176634e-12; `window_decomp.py` 와 동일). **(b) 창 S_bf/B(S II, 500–611 Å)** = Σ_bins η_bf / Σ_bins χ_bf·B_ν(T_e); 준위 l 마다 χ = σ_l(ν)(n_l − n_l* e^{−hν/kT}), η = (2hν³/c²) σ_l(ν) n_l* e^{−hν/kT}, n_l* 은 (a) 와 같은 Saha–Boltzmann(E_l·g_l 반영), σ_l = 봉인 입력 `cmfgen_sigma_bf.bin`(magic 0x434D4644·v1·헤더 32 B = nlev 24,542·nfr 1,234·ν_min·ν_max, has 플래그 int8[nlev]·8 B 정렬 패드·σ f8[nlev×nfr], ν_i = ν_min(ν_max/ν_min)^{(i+0.5)/nfr}; 고정 창 잠금 해가 낸 b 가 뜨거웠다는 관측); **(B)** 차가운 b 출발이고 어떤 g* ≥ 5 에서 b_g 가 1 아래로 건넜다 = 되먹임 복귀 **후보**(인과 증명 아님; g* 와 r_s(k) ≥ 2/3 이 처음 성립한 반복의 선후만 기재); 그 밖(셸별 혼재·차가운 b 출발인데 b > 1 유지한 채 총량 복귀) = 셸별 표 기재·해석 보류. ③ COLD-STAY 일 때 b_g,s(g) > 1 이 gen 4–8 내내 유지됐는지(전 셸/일부/아님) 기재. ④ 창 S_bf/B 는 (a) 의 부차 증인: 부호 규칙은 같으나(S_bf/B < 1 ⇔ 차가운 쪽) σ·준위 가중 합이라 b_g 규칙과 동치가 아니다 — 둘이 어긋난 셸은 기재하고 b_g 를 우선한다. ⑤ b_g 는 준위 권위(분자)와 단계 권위(n_III)를 코드의 bf 흡수(:9113)·Milne 방출(:9082) 정의대로 섞은 비다 — 해제 후 두 권위는 다시 갈라지므로(398939 gen 8 sh24: S II 준위 합 772.5 대 단계 1.633e4) b_g 는 「S II 바닥 엣지의 코드 내 S_bf 가 B 의 어느 쪽인가」의 증인이지 단일 자기정합 인구의 이탈계수가 아니다. 이 규칙은 r·d 분기 판정식을 바꾸지 않는다 — 분기표 「뜻」열의 「…로 읽지 않는다」를 「b 증인이 후보/배제로 좁힌다」로 보강할 뿐이다.
