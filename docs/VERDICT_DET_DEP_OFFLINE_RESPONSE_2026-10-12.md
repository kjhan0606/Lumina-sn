## 3. 이 결과가 가르는 것과 가르지 못하는 것

- **가르는 것:** 고정 상태에서 요청 침적을 Planck 모양 원천으로 더하면, 정적 전달 해 J 가 안쪽 셸 청색과 바깥 셸 EUV 에서 크게 바뀌고, 관측 광도는 공통 지원에서 D 의 약 10 % 만큼 늘어난다. 증가분은 적색·적외선에 몰리고, 청색 결손은 거의 줄지 않으며, 적외선 초과는 커진다. 이 응답은 기준 민감도와 수치 상한보다 수 자릿수 크다.
- **가르지 못하는 것:** 셸 1–49 의 전달 원천·eta_c 가산 소비가 등록 기준(1e-10)을 만족하는지(직접 가산 소실로 미정의), B 의 전체 지원 광도·정적 경계 광도, 생산 setter 배선의 정합, 같은 상태의 물질 가열·냉각 장부, 비열적 소비, 물리적 이중 계산의 해소, 흡수된 몫이 물질 T·인구를 바꾸는 자기일관 응답.
- B 의 광도 증가를 결손 해소나 정당한 물리로 보지 않는다. 주 결손 대역(청색)에서 이 원천의 지렛대는 작다는 것이 이 단의 측정 범위 안의 사실이다.
