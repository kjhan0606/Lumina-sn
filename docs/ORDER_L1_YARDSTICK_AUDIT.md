## 0. 왜 항목을 쫓지 않고 잣대부터 보는가

2026-08-03 하루의 실측:

| 쫓은 불일치 | 결말 |
|---|---|
| `n_e 1.92×` | **잣대 사고.** 기준 파일이 CMFGEN이 아니라 `build_toy06_epoch.py:117`의 ⟨Z⟩=1 placeholder. 07-23 Dig A가 이미 기각했으나 인덱스에서 부활 |
| 조성 "3.33% / 67% / 204%" | **표본 규칙의 산물.** 같은 두 배열이 보간 규칙에 따라 61배 흔들림. 총 원소 질량은 0.06% 일치, 대역 불투명도 기여 ≤1.7% ⟹ **풀에서 제거** |
| I2a `A_ul` "4,336선 중 2건" | **분모 함정.** 4,336은 전체가 아니라 양쪽에 다 있는 선. 실제로는 CMFGEN 72,223선 중 67,887선이 부재 |

**2/2 + 1건.** 층 1은 9/9 불일치다. 같은 사전확률이면 **먼저 잣대를 봐야 한다.**

이것은 항목을 봐주자는 것이 아니다. **잘 정의되지 않은 대조는 제거도 확정도 할 수
없으므로 풀이 영원히 안 닫힌다.** 소거법 수렴의 전제다.

## 1. 계약

**층 1의 각 불일치에 대해, 그 대조가 잘 정의되어 있는지 판정한다.**
불일치를 해소하지 않는다. **판정만** 한다.

세 판정값:

| 값 | 뜻 | exit |
|---|---|---|
| **WELL-POSED** | 분자·분모·좌표·단위·표본규칙이 모두 확정. 불일치는 실물 | 정식 확정 불일치로 승격, 수리 대상 |
| **ILL-POSED** | 대조 자체가 규칙 의존. 값이 규칙에 따라 유의하게 변함 | **결판 요건**을 명시하고 그것부터 |
| **ARTIFACT** | 잣대가 틀렸음이 확증. 불일치가 실재하지 않음 | **풀에서 제거** |

## 3. 각 항목에 대해 답할 것 (형식 고정)

```
항목 / 판정(WELL-POSED · ILL-POSED · ARTIFACT) / 근거(명령과 출력) /
  ILL-POSED 면 → 결판 요건 1문장 / ARTIFACT 면 → 잣대 결함의 정체
```

**추가로 각 항목마다 반드시 명시**:
- **분자와 분모가 각각 무엇인가** (I2a의 4,336 같은 함정 방지)
- **좌표·단위·정의가 양쪽에서 같은가** (I8의 `L(r)` 같은 함정 방지)
- **표본·평균 규칙이 결과를 바꾸는가** (조성 61배 같은 함정 방지) —
  바꾼다면 **대안 규칙 최소 2개로 재계산해 폭을 보여라**
- **임계가 데이터의 유효숫자보다 엄격한가** (I2의 1e-6 의심)

## 4. 규율

1. **불일치를 해소하지 말라.** 판정만 한다. 수리는 별건이다.
2. **운전석의 §2 가설을 믿지 말라.** 전부 가설이라고 표시했다. 반증하면 그렇게 적어라.
3. "확인"으로 적으려면 **실행한 명령과 그 출력**을 붙여라. 안 붙인 확인은 무효.
4. 모르면 **미결**. 추론이면 추론이라고 표시하라.
5. **ARTIFACT 판정은 가장 강한 주장이다** — 잣대 결함의 정체를 코드/파일 수준에서
   특정하지 못하면 ARTIFACT로 적지 말고 ILL-POSED로 적어라.
6. 파일 수정 금지. read-only.
