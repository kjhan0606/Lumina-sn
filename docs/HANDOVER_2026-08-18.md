## 1. 한 문장 요약

핵심 구현과 K36 결정론 baseline은 닫혔지만, A2-10의 물리적 원인 귀속은 아직
닫히지 않았다. 현재는 독립 `J_cont`/`S_probe`와 III-stage negative-control을
얻기 위한 A100×2 수동 Stage-4 진단이 `syn101` GPU 6/7에서 실행 중이며,
아직 R1/R6 완료 marker나 최종 capture 결과는 없다.

## 2. 프로젝트의 목표와 운전 원칙

LUMINA-SN은 toy06 @ 19.48 d 기준으로 CMFGEN 수준의 Ia 초신성 스펙트럼 복사수송을
구현한다. 결정론 CMFGEN 대응 팔과 Monte Carlo 팔은 같은 물질 상태를 공유한다.

현재의 우선 원칙은 다음과 같다.

- CMFGEN에 대응물이 있는 경로는 더 나은 알고리즘으로 개선하지 않고 CMFGEN의
  순서·근사·발자국을 재현한다.
- MC 고유의 사건 측도·패킷·추정자는 LUMINA의 계약으로 검증한다.
- 두 팔의 차동 일치는 공통모드 오류에 눈멀 수 있으므로, CMFGEN 동종 출력과의
  외부 비교를 별도 잣대로 유지한다.
- `RADEQ_NO_BRACKET`은 그 자체로 물리적 근 부재나 최종 PASS를 뜻하지 않는다.
- source edit, 물리값 floor/cap/clamp/jitter, 최종 non-census K-final은
  독립 Stage-4 증거와 원인 귀속 전에는 진행하지 않는다.

- `ION_LOCK=0`, `PER_ION_RESCALE=0` single-total A/B에서 double/80자리 모두

  실증했다.
- 조성표에 없는 원소/ion은 Z-inert exact-zero로 닫고, active pair와 invalid pair는
  fail-closed한다. 관련 CPU self-test와 전체 battery가 PASS다.

## 5. A2-10 Stage-4 원인 귀속 상태

### 5.1 현재까지의 관측

Fable의 Stage-4 잠정 분류는 선택된 IV line 1,282개 전부 `J` 후보였다.

```text
Fe IV 482
Co IV 426
Ni IV 374
O    0
```

선택 line은 optically thick인데 Lumina의 `Jbar/S`가 `1-beta(tau)`보다 훨씬
작았다. 이는 finite-value discrepancy이지 zero-output이나 숫자 floor의 증거는
아니다.

### 5.2 Codex read-only source audit

`src/lumina_cmfgen.c`의 producer는 private `upper_population_cache`를 bulk-fill한
뒤 line `Jbar`를 생산한다. A2-10 consumer는 trial candidate에 대해 별도로
`n_upper`를 재계산한다. 현재 line view는 radiation generation은 운반하지만
population generation은 운반하지 않는다.

따라서 producer의 line-material population과 consumer의 trial population이 같은
물리 상태라는 증명이 없다. 이것은 J 후보를 구조적으로 지지하지만 J가 유일한
원인이라고 확정하는 증거는 아니다.

정본 감사:

- `docs/CODEX_AUDIT_A210_STAGE4_JO_2026-08-17.md`
- `docs/FABLE_VERDICT_A210_K30_PROOF_RUNG_2026-08-17.md`

### 5.3 아직 필요한 증거

기존 sealed stderr의 1,282 saturation row는 `Jbar=beta*Jcont+(1-beta)*S`의
대수적 복원은 가능했지만 독립 `J_cont`와 `S_probe` 필드가 사실상 없었다.
따라서 당시 verdict는 `INSUFFICIENT_INDEPENDENT_FIELDS`였다.

필수 증거는 다음과 같다.

- 같은 K36 line/population/tau/state에서 독립적으로 계산한 `J_cont`와 `S_probe`;
- IV per-line prediction;
- III per-line negative-control/stability table;
- population/radiation generation provenance;
- finite comparison;
- floor/cap/clamp/jitter/repair counter 0;
- 자연 `RADEQ_NO_BRACKET`이 독립 probe에서 실제 bracket으로 바뀌는지에 대한
  사전등록 prediction.

## 6. 독립 capture 구현

`LUMINA_A210_INDEPENDENT_CAPTURE=1`을 opt-in으로 추가했다.

- 정상 line-inclusive exact solve 뒤, 같은 owner solver를 untouched continuum
  array만 사용하여 다시 실행한다.
- continuum probe는 `chi_tot=chi_es+chi_abs`와
  `S_fixed=chi_abs*B/(chi_es+chi_abs)`를 사용한다.
- production Jbar/rate는 교체하지 않는다.
- capture가 완전히 끝난 경우에만 row에 numeric `J_cont`, profile error bound,
  `S_probe`를 기록한다.
- `mode=2`는 Fe/Co/Ni IV 각각의 scaled emission 90% 최소 prefix union을
  사용한다.
- current diagnostic manifest는 다음을 봉인한다.

independent_J_cont=LINE_FREE_EXACT_CONTINUUM
independent_S_probe=LINE_MATERIAL_SOURCE_FUNCTION

selection_mode=PER_ION_UNION
