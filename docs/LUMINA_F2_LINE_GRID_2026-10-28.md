# F2 장에서 Si/S 선 적분의 격자 민감도 — 2026-10-28

완료 F2 복사장과 1115020점 주파수 격자에서 Si/S 선의 기존 선형장 적분을
재현하고, 같은 nodal J를 이용한 점표본 사다리꼴 적분과 비교한다. 31점과
34점, Si/S 전체 선택 선이 범위다. F2 선형 율 재현으로 원자 roster 및 장
정체성을 확인하고, 정상/격자 밖/미표본 선의 개수와 프로파일 질량·율 차이
분포를 기록한다. 이것은 F2 격자에서의 수치 민감도이며 CMFGEN의 원 정수
공명구간을 재현하거나 관측된 선 내부 복사장을 복원하는 시험이 아니다.
새 수송·물질 정상해는 수행하지 않는다. Lageunha CPU1·4GiB·최대180초·
GPU0 단회 실행으로 원본을 보존하고 새 디렉터리에 결과를 쓴다.
