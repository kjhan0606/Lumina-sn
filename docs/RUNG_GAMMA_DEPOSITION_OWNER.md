# 단 — 방사성 침착의 소유권 (사전등록, 2026-08-08)

발견 경위: R7 검사 중.  Codex 가 R7 패치에 결정론 팔의 `compute_gamma_deposition` 호출을
**신설**해 넣었고, 운전석이 "왜 신설인가"를 따라가다 나왔다.  R7 에서 분리했다.

---

## 계약 (하나)

> **방사성 붕괴 침착은 세대 도장을 가진 단일 소유자가 발행하며,
> 소비자는 미발행·구세대·이중발행을 침묵으로 통과시키지 않는다.**

이 단은 "빠진 호출 하나를 넣는" 단이 **아니다**.  빠진 호출은 증상이고,
같은 계급의 결함이 지금까지 **세 번** 났다(§2).  계약을 세우지 않으면 네 번째가 난다.

---

## 1. 왜 이 단이 필요한가 — 실측

| 확인 | 결과 | 근거 |
|---|---|---|
| `compute_gamma_deposition` 호출부 전수(CPU) | `lumina_main.c:603` **하나뿐** | grep 전수 |
| 그 603 의 도달성 | DET 분기는 `lumina_main.c:338` `cmfgen_run` → **370 `return 0`**.  603 은 MC 루프 안 | 소스 |
| `lumina_cmfgen.c` 안의 호출 | **0건** | grep 전수 |
| 초기값 | `gamma_deposition_init` = `calloc` ⟹ 전 셸 **0** | `lumina_plasma.c:16052` |
| A2-10 이 쓰는 자리 | `qg=(c->gamma&&c->gamma->heating_rate)?c->gamma->heating_rate[s]:0;` | `lumina_plasma.c:12060` |
| 결측 검사 | **없음**.  `blocked_missing_term` 은 J 재빈닝 실패만 센다 | `a210_production_solve` |
| 비열 이온화도 같은 운명 | `nonthermal_ioniz_rate = pref·heating_rate/W` ⟹ 0.  소비자 둘 다 `> 0.0` 로 가드해 **조용히 건너뛴다** | `:16047` · `:14686` · `lumina_element_wide.c:2279` |

⟹ **결정론 팔의 복사평형은 `q_γ ≡ 0`, 비열 이온화 ≡ 0 으로 풀려 왔다.**
19.48일 Ia 에서 국소 에너지원은 ⁵⁶Ni→⁵⁶Co→⁵⁶Fe 붕괴가 사실상 전부다.

**왜 안 걸렸나** — 이것이 「고리 밖 감사」의 표적 그 자체다.
감마 침착은 A2-10 이 **소비하되 결정론 팔에 생산자가 없고, 세대 도장이 없다.**
동세대 삼중항 검사는 opacity·emissivity·radiation 만 본다.  감마는 그 시야 밖이다.
그리고 소비자들이 **0 을 "할 일 없음"으로 읽는다** — "생산자가 안 돌았음"과 구별하지 않는다.

## 2. 같은 계급의 결함 — 이미 세 번째다

| # | 사례 | 상태 |
|---|---|---|
| (a) | 외부 침착 파일 경로가 `heating_rate` 만 싣고 비열률을 안 만들어 **비열 이온화가 조용히 0** | **기왕 수리됨** — `gamma_deposition_compute_nonthermal()` 로 분리. 소스 주석이 "without this the non-thermal ionization is silently ZERO in ARTIS-comparison runs" 라고 스스로 적고 있다 |
| (b) | **결정론 팔에 생산자 없음** ⟹ `q_γ≡0` | 이 단 |
| (c) | CUDA 에서 `LUMINA_DEPOSITION_FILE` 주입값을 **반복 1부터 내부 Bateman 이 덮어쓴다** | 이 단 (§2-1) |

### 2-1. (c) 상세 — ARTIS 비교의 전제가 반복 1부터 깨진다

`lumina_cuda.cu:7808` 이 루프 **앞**에서 외부 파일을 `gamma_dep.heating_rate` 에 싣는다.
주석: *"INSTEAD of compute_gamma_deposition … our model is an already-decayed
post-snapshot state, so the internal Bateman decay would double-count"*.

그런데 `lumina_cuda.cu:10679` 의 `compute_gamma_deposition` 은 `else if (iter > 0)` 안에
있을 뿐 **`!depf` 가드가 없다**.  ⟹ 반복 0 만 ARTIS 침착, 반복 1부터 내부 Bateman.

**소스가 스스로 이중계산이라고 적은 그 계산이 조용히 되돌아온다.**
ARTIS-parity 캠페인의 다중반복 GPU 런은 "동일 가열원" 전제가 반복 1부터 성립하지 않았다.
⚠결론이 실제로 달라졌는지는 **측정 전이다** — 주장하지 않는다.

## 3. 생산자 자신의 부채 (이 단에서 **고치지 않는다** · 대장 기재)

수리 대상은 소유권 계약이다.  아래는 `compute_gamma_deposition` 자체의 근사·가정으로,
`docs/CLASSIC_DEBT_CENSUS.md` 자매 항목으로 기재하고 별도 단에서 다룬다.

| 부채 | 내용 |
|---|---|
| **동위원소 미분리** | `X_ni`=**원소** Ni 전량을 ⁵⁶Ni 로 본다. IGE 코어의 안정 ⁵⁸Ni·⁵⁹Co 를 붕괴시킨다 |
| **덱 규약 의존** | 현재 존재비를 `t=0` 초기값으로 넣고 Bateman 을 다시 돌린다. 덱이 **초기** 조성이면 옳고 **현재** 조성이면 이중계산이다. 검사 없음 — (c) 의 주석이 후자라고 말한다 |
| **회색 1방향 탈출** | `f_dep = 1-exp(-κΣ_out)`, κ=0.025 고정. 감마 수송 해가 아니라 외향 컬럼만 쓰는 한쪽 근사 |
| **양전자 채널 없음** | ⁵⁶Co 양전자(붕괴에너지의 ~3.5%)는 국소 침착 f=1 인데 분리 안 됨 |

## 4. 기대 변경집합 (사전등록 — 이 목록 밖의 변경은 실패로 본다)

1. `GammaDeposition` 에 발행 도장: `generation` · `epoch` · `provenance`(INTERNAL_BATEMAN /
   EXTERNAL_FILE) · `manifest_sha256`(heating_rate 배열).
2. 단일 발행자 `gamma_deposition_publish(...)` — 내부 Bateman 과 외부 파일이 **같은 문**으로
   들어온다.  두 번 발행하면 `GAMMA_DOUBLE_PUBLISH` 로 **차단**(외부 주입을 덮어쓰지 않는다).
3. 소비자 3곳이 도장을 요구한다:
   - A2-10 (`qg`) — 미발행/구세대 ⟹ `blocked_gamma_unpublished` 증가 + `RADEQ_GAMMA_UNPUBLISHED` 로 BLOCKED
   - `lumina_plasma.c:14686` 비열 이온화
   - `lumina_element_wide.c:2279` 비열 이온화
   ⟹ **0 을 "할 일 없음"으로 읽지 않는다.**
4. 결정론 팔(`cmfgen_run`)이 발행자를 부른다 — 반복 위상은 R7 이 정한 자리(물질 갱신 앞).
5. CUDA `else if (iter>0)` 의 무가드 호출을 발행자 경유로 바꾼다(= (c) 폐합).

**변경하지 않는 것**: `compute_gamma_deposition` 의 물리(§3 부채는 그대로 둔다).
이 단은 **틀린 값을 고치는 단이 아니라, 값이 없는데 0 으로 읽히는 것을 막는 단**이다.

| # | 주입 | 기대 | 무엇을 시연하나 |

| **NC1** | 결정론 팔의 발행자 호출을 제거 | `RADEQ_GAMMA_UNPUBLISHED` 로 **BLOCKED** | 오늘의 결함을 재현하고, 새 게이트가 그것을 **잡는다**는 증명 |

## 6. 측정 — "얼마나 틀렸나" (R6 를 기다리지 않는다)

결정론 팔은 R6 착지 전까지 A2-10 에 도달하지 못한다.  그러나 **MC 팔은 감마를 늘 가져왔다.**
같은 덱·같은 에폭·같은 셸에서 MC 팔의 A2-10 에너지 장부를 찍으면,
결정론 팔이 **빠뜨려 온 항의 크기**를 지금 잴 수 있다.

| 측정 | 산출 |
|---|---|
| **M1** | MC 반복 0, 셸별 `q_γ` 대 A2-10 가열 총합의 비 → 결손 분율 프로파일 |
| **M2** | 같은 장부에서 비열 이온화율 대 광이온화율 비 → 이온화 채널 결손 |
| **M3** | (R6 착지 후) 결정론 팔 T_e: 감마 ON/OFF 단독 A/B | **이월** |

★M1/M2 는 **주장이 아니라 잣대**다.  "심부 T_e 결손의 원인" 여부는 M3 전까지 판정하지 않는다.
내부 경계 광도가 총 에너지를 이미 나르므로, 틀린 것이 **국소 침착 분포**이지 총량이 아닐 수 있다.
`TE_TABLE` 로 T_e 를 핀한 twin 런들은 radeq 를 쓰지 않았으므로 **영향 밖**이다.
