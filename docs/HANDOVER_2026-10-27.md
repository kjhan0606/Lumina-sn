### 전90점 동적 BF 생산자의 배치화 (동일 묶음 내부 구현)

새 생산자는 공통 J·실제ν·평가ν·전역 가중치를 소유하고, σ는 경로×주파수
블록에서 한 번 평가해 여러 점에 재사용한다. route×점×주파수 3D 배열은
만들지 않는다. C kernel은 해당 블록에서 점별 열적 인자를 공유하고 기존
native-SE 용해 fit과 actualν 지수/문턱 열량을 함께 적분한다. 블록 내부
지수 폭32는 수치 표현을 위한 분할이며 전 주파수/경로를 삭제하지 않는다.

private trial마다 SL 인구·T/ne를 복사해 기존 occupation fit·SL 분율·Saha·

### 전90점 BB 응답의 결손 없는 공통장 표현

Astra는 기존 nodal J를 **주파수 ν에 대해 구간별 선형인 장**으로 명시하고,
그 장과 기존 유한지지 Gaussian의 곱을 적분하도록 권고했다. 프로파일 내부
노드가 없더라도 지지 전체를 둘러싼 유효 노드가 있으면 적분할 수 있다.
실제 장 범위 밖의 선은 외삽·0 채움 없이 별도 결손으로 남긴다. logν/logJ
보간이나 질량 재정규화는 하지 않고 물리 Einstein A도 바꾸지 않는다.
기존 native 점표본 연산자·그 비교 결과는 별도로 보존한다. 이는 미해상
선 내부 J의 측정이나 새 수송 결과, native E-동등성 증명이 아니다.

운전자는 별도 C 적분기와 Python 소유자를 구현하고, 원자주소·장/선 블록
