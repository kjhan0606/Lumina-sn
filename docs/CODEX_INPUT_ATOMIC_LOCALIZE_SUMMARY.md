### 공통 이온 표기

- `ion0`: 데이터 원문의 0-기반 이온값
- 분광표기: `ion0 + 1`

### I2 판정

비교 대상은 엄격 준위 결합에 성공한 선이다.

- 정규화한 configuration 문자열 일치
- statistical weight `g` 일치
- `|ΔE| ≤ 1e-6 cm⁻¹`
- 상대차:
  \[
  r_A=\frac{|A_{\rm Lumina}-A_{\rm CMFGEN}|}{|A_{\rm CMFGEN}|}
  \]
- 불일치: `r_A > 1e-6`
- 큰 차이: `r_A ≥ 1`

임계는 분석 전에 고정했으며 결과를 본 뒤 조정하지 않았다.

## 5. UNRESOLVED

1. I2의 Lumina 선 중 1,240,871선은 현재 엄격한 configuration/`g`/energy 결합으로 비교되지 않았다. 결판에는 별도의 준위 crosswalk 또는 대응 CMFGEN 입력이 필요하다.

2. I3의 CMFGEN photoionization type 2, 3, 8에 대응하는 2,084준위는 이번 동일주파수 evaluator 범위 밖이다. 해당 타입 evaluator가 결판 요건이다.

3. 선행 요약의 “CMFGEN 양수/Lumina 0 = 197,231점”은 이번에 headline 총계 3,953,894점과 1,233,529점을 정확히 재현한 비교 우주에서는 553점으로 계산됐다. 이전 계산의 분석 스크립트 또는 ‘0’ 정의 없이는 두 수치를 통합할 수 없어 `UNRESOLVED`로 남긴다.

4. sigma binary 헤더만으로는 bake 당시 원자자료 revision과 선택 옵션 전체를 복원할 수 없다. 정확한 bake manifest가 결판 요건이다.
