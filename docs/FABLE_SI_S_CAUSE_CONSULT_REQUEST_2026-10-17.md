# Si/S 불일치 해석 자문 요청 — 2026-10-17

읽기 전용 해석 자문이다. 공식 감사/실행 승인/목표 통과를 요청하지 않는다.
첫 줄에 실제 모델 정체성을 보고하고 한국어로 간결하게 답하라.
주어진 증거와 추측을 분리하라. 도구/파일 접근은 없다.

## 질문

1. 아래 증거에서 현재 진단의 가장 중요한 논리적 구멍은 무엇인가?
2. 큰 S 부족의 원인을 구분할 다음 최소 실험을 최대2개 제안하라.
   각 실험의 고정량/변경량/서로 다른 결과가 가르는 가설을 명시하라.
3. 새 공동해를 얻기 전에 버려야 할 주장과 유지할 수 있는 주장을 구분하라.

## 목표와 현재 상태

최종 목표는 공개 CMFGEN toy06과 Si II/III·S 전체 분포 및 실제19.48일
시간진화/절대 스펙트럼의 동질성이다. 현재는2일 고정 hydro T 초기 NLTE
자기일관해조차 미완료다. 새 전체 BB 범위 계산이 A100에서 진행 중이다.
공개 자료에는 이온분율/T/ne/스펙트럼이 있으나 내부 J나 준위별 인구는 없다.
로컬 CMFGEN 내부 J/POP는19.48일 미수렴 실행이라 기준으로 쓰지 않았다.
공개 원자모형과 현재 판본/준위 수/배경 Fe/Co가 완전히 같다는 증명도 없다.
