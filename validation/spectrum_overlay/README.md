## 2026-10-22 정정 — 절대 비교의 단위 누락 수정

아래는 당시 기록이며 보존한다. 현재 스크립트는 생산 formal CSV의
`L_lambda [erg/s/cm]`를 `1e-8`배하여 공개 CMFGEN과 같은 `erg/s/Å`로 비교한다.
생산 근거는 `src/lumina_plasma.c`의 formal 광도 변환 및
`src/lumina_main.c`의 CSV 기록이다. 파장 열은 이미 Å이므로 바꾸지 않는다.
임의 정규화가 아니라 단위 변환이며 CMFGEN 열에는 재적용하지 않는다.

동일한 **2026-08-05 과거 Lumina 파일**과 공개 19.48일 참조를 재계산하면
3000–10000 Å 대역 광도는 CMFGEN `1.09430876885e43 erg/s`,
Lumina `2.623340335395e42 erg/s`다. 따라서 CMFGEN/Lumina는
**4.1714327115**, Lumina/CMFGEN은 **0.2397257895**다.
과거 `4.171e-08`의 10⁸ 차이는 비교 코드의 단위 누락이 원인이다.
남은 4.17배 차이는 단위 보정으로 사라지지 않으며, 이 기록만으로
새 계산의 정확성이나 남은 물리 원인을 입증하지 않는다.

단일 대역 정규화 후 형상은 변하지 않는다. 점별 비의 q10 `0.122`,
중앙값 `1.390`, q90 `4.173`이며 과거의 청색 결손·적외선 초과는 여전히 남는다.
현재 수송 결과나 최신 이온분포와 혼동하지 않는다. 기존 PNG는 덮어쓰지 않았다.

직접 회귀 시험은 `tests/test_plot_spectrum_vs_cmfgen.py`의 3개다.
cm→Å 변환, 공개 참조의 단위 유지, 정규화 형상의 불변성을 확인한다.

## 절대 규모는 맞지 않는다 — 단위/정규화 문제로 보인다

## 읽히는 것 (진단 수준 — 판정 아님)

**UV/blue 결손 + IR 초과** 라는 기울기가 그대로 보인다. 이는 프로젝트가 오래 추적해 온
「too-red」 서사와 **부호가 같다**. 6000–10000 Å 은 1에 붙어 있으나 그 대역이
정규화 기준에 포함되므로 **독립 증거가 아니다.**
