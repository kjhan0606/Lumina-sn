## 1. 무엇을 재려 했고, 왜 비교자가 바뀌었나

구 I2(880,406선 중 75,075 불일치)의 상위 기여 이온 Ni III·Ni II·Co III·Ca IV·S III을
`_ftos`에서 **동일-원본 조건**으로 다시 잰다(R-1이 27이온 동일 원본을 확정했으므로
구 감사의 교차-vintage 교란이 없다).

비교자는 Fable L3 검수의 발견 때문에 바뀐다: **CMFGEN은 osc의 A열을 읽지 않는다.**
원본에서 재확인했고, **λ열도 읽지 않음**을 새로 확인했다:

```
genosc_v6.f:278       READ(STRING,*)T1        ! f 만 읽는다
genosc_v6.f:279-285   DO L2=1,3 ... 토큰 3개(f·A·Lam) 건너뜀 → i-j 로 감
genosc_v6.f:205       FEDGE = (E_ion - E_lev)*c*1e-15     ! 준위표 전정밀도 = 진공
genosc_v6.f:313-317   EINA = OPLIN/EMLIN*TWOHCSQ * f * g_i/g_j * (FEDGE_i-FEDGE_j)^2
```

`T1 = OPLIN/EMLIN*TWOHCSQ`은 h가 상쇄되어 `8π²e²/(m_e c³)·1e30`으로 환원된다.
⟹ **CMFGEN이 소비하는 것은 f와 준위 에너지뿐이다.**

## 3. ★기전 — 공기파장을 A→f 변환에 썼다

덱 f의 생성 레시피가 기계정밀도로 재구성됐다:

```
f_deck = A_file · (g_up/g_lo) · λ_file² · m_e c/(8π² e_deck²)      재구성 오차 6.7e-16
```

그런데 `λ_file`은 원본 헤더가 명시하듯 **λ>2000Å에서 공기파장**이다
(*"Wavelengths in air for lambda > 2000 Ang, else vacuum"*). A↔f 변환은 **진공** ν를
요구한다. 실측된 굴절률 서명:

| 구간 (Ni III) | 선 수 | 원본\|λ\| vs 준위에너지 λ | 덱 f 편향 |
|---|---|---|---|
| λ>2000Å | 42,446 (64%) | **−2.79e-4** (std 3e-5) | **−5.65e-4 계통·한쪽 부호** |
| λ≤2000Å | 24,040 (36%) | −3.2e-9 | −1.8e-6 (반올림뿐) |

`f ∝ λ²`이므로 `2 × 2.79e-4 = 5.58e-4` — 정확히 들어맞는다.

**⟹ v1 스크립트가 낸 `NOT_A_DEFECT_A_VS_F_PRIORITY_CHOICE`는 A축만 보고 내린 오판이다.**
A축은 exact지만 **CMFGEN이 실제로 쓰는 f축에 Lumina 임포트가 만든 계통 결함이 있다.**

## 4. ★★더 큰 파급 — 덱의 선 파장 자체가 공기파장이다

덱 λ가 원본 λ열과 비트 동일하므로, 오염은 f에 그치지 않고 **선 위치**에 있다.
`src/lumina_plasma.c:2804,14765` · `src/lumina_cuda.cu:1905`가
`atom->line_wavelength_cm[line]`을 Sobolev τ에 그대로 쓰며,
**Lumina 어디에도 공기↔진공 변환이 없다**(`air.?to.?vac|n_air|refract|edlen` 전수 grep = 0행).

덱 전량 census (2,220,953선, 58이온):

| | |
|---|---|
| 오염 이온 | **45 / 58** |
| 오염 선 (λ>2000Å ∧ 오염 이온) | **635,169 = 덱의 28.6%** |
| 함의 속도 편이 | **82–85 km/s** (전 이온 일관) |

### 통제 (이것이 판정을 결정한다)

**같은 이온 안에서** λ≤2000Å 대역은 깨끗하고 λ>2000Å 대역만 어긋난다:

| 이온 | air 대역 r | vac 대역 r |
|---|---|---|
| Fe VII | 2.767e-4 | 9.2e-9 |
| Ni III | 2.763e-4 | 3.7e-9 |
| Co III | 2.760e-4 | 7.0e-9 |

준위 에너지가 틀렸다면 **두 대역이 함께** 어긋나야 한다. 어긋나지 않으므로
원인은 **λ열의 공기 규약 하나**로 특정된다.

비오염 13이온(Fe II·Fe III·Cr III·Ti II·S I·S II·Ti III·Fe I·Ca I·Co I·Si II·Ca II·Si III)은
양쪽 대역 모두 ~1e-9다 — 그 파일들(주로 `19apr23` 계열)은 전 구간 진공으로 적는다.
**규약이 vintage별로 다르므로 이온 단위 판별이 필수다.**

## 6. 판정

| 축 | 판정 |
|---|---|
| A_ul 임포트 | **무죄** — 원본 A열과 exact (5이온 201,377선, 임계 1e-12) |
| g·λ 임포트 | **무죄** — exact / 비트 동일 |
| **f_lu** | **결함** — A→f 역산에 공기파장 사용, λ>2000Å에서 −5.6e-4 계통 |
| **선 위치 λ** | **결함** — 45/58 이온, 635,169선(덱 28.6%)이 공기파장, **82–85 km/s** |
| e 상수 | **기재** — 참값 대비 −9.6e-8 (I9) |

**구 I2 75,075는 이 판정으로 대체되지 않는다** — 그것은 교차-vintage A열 비교였고
(Fable 검수 확정) 여기서 잰 것은 다른 양이다. `_ftos`의 정본 I2 수치는 위 표다.

**처분 = 대장 기재.** 수리는 별도 결정이다(`feedback_wrong_values_register_quietly`).
크기 판단: τ·rate에 대한 영향은 5.6e-4로 무시 가능하나, **선 위치 82–85 km/s는
narrow-band 스펙트럼 잣대와 P-Cygni 최소 위치에 직접 들어간다** — SN Ia 선폭
~10,000 km/s의 0.8%지만 한쪽 부호이고 덱의 28.6%에 걸린다.
