# 과제 D — **coevolution(ARTIS 채택)** 대 **two-arm(Lumina)** 의 물리적 평가

너는 읽기 전용 분석자다. **수리 코드·구현 제안을 쓰지 마라.** 물리적 평가만 낸다.

대상:
- `./artis/` — ARTIS 원본 발췌 (coevolution 실물)
- `./lumina/` — Lumina src 발췌 (two-arm 실물)
- `./paper_main.tex` — Lumina 논문 본문 (아키텍처 서술은 `\label{fig:arch}` 부근)

## 무엇을 평가하는가

두 방법은 **같은 문제**(비국소열평형 복사수송 + 통계평형의 동시해)를 다르게 푼다.

- **coevolution (ARTIS)**: MC 수송과 플라즈마 상태를 **함께 진화**시킨다.
  패킷이 나르는 표본 estimator 가 곧 rate 의 입력이고, 상태는 시간축(또는 반복축)을 따라
  전진한다. LTE 시대(`num_lte_timesteps`)로 출발한다.
- **two-arm (Lumina)**: **하나의 plasma state** 를 MC 팔과 결정론 팔이 공유한다.
  MC 는 표본 estimator·event-resolved history 를, 결정론은 **잡음 없는 장**과
  (선형화용) 미분가능 수송 연산자를 같은 통계평형에 공급한다.

## 산출 (전부 **물리** 논거로)

1. **수렴의 성격** — 두 방법이 각각 무엇에 수렴하는가, 그리고 **무엇을 향해** 수렴하는가.
   고정점이 같은가 다른가. 다르다면 어디서 갈리는가.

2. **오차의 종류** — 각 방법이 안는 오차를 **잡음(variance)** 과 **치우침(bias)** 으로 분해하라.
   · MC estimator 의 표본 잡음이 rate 를 통해 population 으로 어떻게 전파되는가
   · 결정론 팔의 이산화(주파수·각도·공간) 치우침은 어디에 남는가
   · coevolution 에서 잡음이 상태에 **누적**되는가, 아니면 씻기는가

3. **각 방법이 도달할 수 있는 물리 / 없는 물리**
   · 형광 재분배(macro-atom 내부 캐스케이드), 선중첩, 비열적 여기
   · 3차원·시간의존으로의 확장
   · 미분가능성(전역 선형화)이 필요한 물리

4. **비용의 스케일링** — 준위수·주파수·기하 차원·패킷수에 대해. 어디서 실용 한계가 오는가.

5. **★two-arm 이 coevolution 을 대체하는가, 포함하는가, 다른 것인가**
   특히: two-arm 의 "두 장의 일치" 진단이 coevolution 에서는 원리적으로 불가능한가?
   반대로 coevolution 이 주는 것 중 two-arm 이 잃는 것이 있는가?

6. **부트스트랩(반복 0)** — 각 방법이 첫 상태를 어떻게 얻는가. `파일:행`.
   ARTIS 의 LTE 시대가 하는 일이 two-arm 에서는 무엇에 해당하는가.

## 규율

- 한국어. 표 중심. `[실측]`(코드·논문 근거 행 있음) / `[추정]`(물리 논증) 을 문장마다 구분.
- **어느 쪽이 우월하다는 결론을 미리 두지 마라.** 조건별로 갈리면 조건을 적어라.
- ARTIS 를 정답으로 삼지 마라 — Lumina 의 최종 심판은 **CMFGEN** 이고 ARTIS 는 참고다.
- 근거 없는 성능 주장 금지. 스케일링은 코드 구조에서 읽어낸 것만.
- 마지막에 **"물리적으로 결판나는 시험 3개"** — 두 방법의 차이가 관측 가능한 양으로
  드러나는 구체적 시험을 제안하라(구현이 아니라 시험 설계).
