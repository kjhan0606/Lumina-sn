# 과제 F — **생존 함수 목록 + 구현할 함수 목록 + 그 배선도**

너는 읽기 전용 분석자다. **구현하지 마라.** 목록과 배선도만 낸다.

## 입력 (전부 이 디렉토리)

- `OUT_A_lumina_wiring.md` — Lumina 실제 배선도 (반복 0 표: `ABSENT` 7 · 끊긴 간선 6)
- `OUT_B_artis_diff.md` — ARTIS 대조 (필수 6항목 중 5 DIVERGENT + 1 MISSING)
- `OUT_C_fable_verdict.md` — 비물리 판정 + 2-arm 적합성
- `OUT_D_coevolve_vs_twoarm.md` — coevolution vs two-arm 물리 평가
- `OUT_E_fable_certification.md` — ★위 D 의 인증/반박. **E 가 D 를 반박한 부분은 E 를 따른다.**
- `./lumina/` `./artis/` — 원 소스 발췌 · `paper_main.tex` — 논문

## 기준선

- **최종 심판은 CMFGEN.** ARTIS 는 참고다.
- **0층 계약 10건은 자산**이다(C2-EXEC · H-TRANSFORM · GEN-GUARD · K-SHAPE · K-FRESH ·
  Z-INERT · D-BUILD · TE-DEAD · A2-00 · CONFIG-PREC). **계약을 깎지 마라.**
  `OUT_C` 판정: 틀린 것은 계약이 아니라 **위상(순서)과 절단**이다.
- 목표 순서는 **물리가 한 조각씩 서는 방향**이다(감사 편의 아님).

## 산출 (셋)

### 1. 생존 함수 목록

현 소스에서 **그대로 살아남는** 함수. 각 행:
`함수 / 파일:행 / 무엇을 계산하는가 / 어느 계약이 보증하는가 / 왜 생존인가`

생존 기준: 물리적 근거가 있고(식·보존·극한), 계약이 보증하며, 배선도의 사슬에 자리가 있다.

### 2. 구현할 함수 목록

**없거나 · 잘려 있거나 · 위상이 틀린** 것. 각 행:
`함수(신설/수리) / 무엇을 공급하는가 / 그것이 없어서 끊긴 간선 / 의존하는 것 / 순서`

반드시 포함(앞선 판정에서 확정된 것):
- 반복 0 물질 공급자 — seed-T_e LTE(Saha). 현재 `(void)phi_neb` 로 **절단**돼 있다
  (`lumina_plasma.c:2643-2650`; 주석 `2347` 은 그 fallback 을 선언해 놓고 코드는 반대)
- 세대 장부 위상 — a208/a209 발행을 field commit 직후·T_e 호출 전으로;
  비적격 시 `T_e_generation=0` 화(`lumina_main.c:645-649`) 제거
- 결정론 line-J̄ (같은 q-set hash·profile identity) — 없으면 SE 가 `POP_BB_STALE`
- pure lane 의 a209 emissivity 발행
- 최상단 이온 바닥준위 — `inject_topstage_continuum_levels` 는 **존재하나 O IV 하나뿐**이고
  기본 off (`lumina_atomic.c`). ARTIS 는 `SINGLE_LEVEL_TOP_ION` 으로 전 원소에 준다

### 3. 배선도 (텍스트)

생존 함수와 구현할 함수를 **하나의 그림**으로. 다음을 반드시 표시하라:

- 반복 1회 안의 **순서**(수송 · 추정자 · T_e · Z · n_e · 이온 · 준위 · tau · 전이확률)
- **반복 0(부트스트랩)** 경로 — 무엇이 무엇을 공급해 첫 수송에 닿는가
- **두 팔**(MC / 결정론)이 각각 어디서 갈라지고 **어디서 같은 것을 읽고 같은 곳에 쓰는가**
- 각 간선을 지키는 **계약**(이름 + 위반 시 상태코드)
- **세대(generation)** 가 어디서 증가하고 무엇이 그것을 요구하는가

형식은 ASCII 다이어그램 + 간선표. 그림과 표가 서로 모순되면 안 된다.

## 규율

- 한국어. `[실측]`(`파일:행` 있음) / `[추정]` 구분. 근거 없는 문장 금지.
- **노브를 늘리는 설계를 하지 마라.** 부트스트랩은 선언적 1회 공급자이지 스위치가 아니다.
- 클램프·floor 로 답을 만들어 내는 설계 금지.
- 구현 코드 금지 — 목록과 배선도까지.
- 마지막에 **"이 배선도가 서면 무엇이 처음으로 가능해지는가"** 를 3줄로.
