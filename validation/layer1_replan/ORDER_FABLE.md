# Fable 발주 — Lumina 배선도의 **비물리 지점 판정** + **2-arm 구조 적합성**

## 입력

1. `OUT_A_lumina_wiring.md` — Lumina 의 실제 물리 배선도(코드가 하는 것). 반복 0 표 포함.
2. `OUT_B_artis_diff.md` — ARTIS 배선도 + Lumina 대조표(MISSING/EXTRA/DIVERGENT/EQUIVALENT).

## 심판 관계 (혼동 금지)

- **최종 심판은 CMFGEN 이다.** ARTIS 는 **참고**다 — "ARTIS 가 이렇게 하니까 옳다" 는 논거가 아니다.
- 단 Lumina 는 2 개월 전 전면 재구축 때 **ARTIS 배선도를 기준으로 삼았다.**
  따라서 `MISSING` 은 대개 "의도적 변경" 아니면 "이식 중 누락" 이다. **그 둘을 가르는 것**이 유용하다.

## 과제 1 — 어디가 비물리적인가

배선도의 각 지점에 대해 판정하라. 세 값만 쓴다:

- `PHYSICAL` — 물리적 근거가 있다 (식/보존/극한이 근거. 어떤 것인지 적어라)
- `NON-PHYSICAL` — 근거가 없다. 편의·임시방편·화석이다
- `UNDECIDED` — 판정에 필요한 정보가 없다 (무엇이 있으면 판정되는지 적어라)

각 판정에 `파일:행` 과 한 줄 근거를 붙여라. **분량보다 정확도.**
특히 다음을 반드시 판정하라(오늘 실측으로 드러난 것들):

- 계약이 **준위 없는 최상단 이온**을 자료 결손으로 거부한 것
- `(void)phi_neb` 로 Saha 값을 계산해 놓고 버리고 `POP_BF_STALE` 를 내는 것
- n_e 반복의 "TARDIS-style damped update" + "5% 수렴" (계보 혼재)
- 반복 루프 **앞**에서 전 플라즈마 풀이를 요구하는 K-FRESH 배치
- ★**초기 T_e 프로파일**: `OUT_A` 는 seed T_e 가 `T_inner` 를 **전 셸에 복제**한 것이라고
  적었다(`lumina_atomic.c`). 사실이면 균질 등온 시작이다 — 균질 팽창 외피에서
  외곽이 내부 경계온도와 같다는 것은 물리적으로 성립하지 않는다.
  덱에는 `plasma_state.csv` 의 `t_electrons` 가 따로 있고 CONFIG-PREC 계약이 그것을
  override 가 아닌 **consistency witness** 로 규정했다. 이 배치가 옳은지 판정하라
  (덱의 T_e 프로파일이 쓰이지 않는다면 그 근거가 무엇인가).

## 과제 2 — ★2-arm 구조에 맞는 배선인가 (user 지시)

**Lumina 는 ARTIS 와 다르다.** 논문 Fig.1(`main.tex:267`, 설명 `main.tex:230-266`):

> 두 솔버가 **하나의 plasma state** 를 공유하며 서로 반대 방향으로 순환한다.
> **MC arm** = 표본 rate estimator · packet spectra · event-resolved history ·
>   재분배 물리를 기하 차원에 무관한 비용으로.
> **결정론 arm** = **잡음 없는 복사장** + (선형화에 필요한) 미분가능 수송 연산자.
> 둘은 **같은 opacity·source function 을 읽고 같은 통계평형에 쓴다.**
> **두 장의 일치 자체가 진단**이며 어느 한 팔도 단독으로는 주지 못한다.

판정하라:

1. 현 배선이 이 2-arm 구조를 **실제로 구현하는가**, 아니면 MC 단일 팔 구조에
   결정론 팔이 덧대어져 있는가. 근거를 `파일:행` 으로.
2. `OUT_A` 의 반복 0 표에서 `ABSENT` 인 입력들을, **결정론 arm 이 공급할 수 있는가**.
   ★핵심 가설(내가 세운 것이니 **검증하거나 기각하라**):
   > ARTIS 가 LTE start 를 필요로 하는 것은 **MC 전용**이기 때문이다.
   > Lumina 에는 패킷 없이 J_nu 를 내는 결정론 팔이 있으므로,
   > 부트스트랩은 "ARTIS 식 LTE start" 가 아니라
   > **"seed 상태에서 결정론 formal solve → 잡음 없는 J_nu → 통계평형"** 일 수 있다.
   맞으면 그 사슬이 성립하는 최소 조건을 적고, 틀리면 왜 틀린지 적어라.
3. 2-arm 을 제대로 구현하면 **계측 배선도**가 어떻게 달라지는가.
   논문은 검증층이 "표시된 인터페이스" 에 붙는다고 하고, **두 장의 일치가 진단**이라고 한다.
   현 계측이 그 진단을 실제로 쓰고 있는가? 아니면 단일 팔 기준의 게이트만 있는가?

## 형식

- 한국어. 표 중심. `[실측]`(근거 행 있음) / `[추정]` 을 문장마다 구분.
- **수리 코드를 쓰지 마라.** 판정과 방향만.
- 확신이 없으면 `UNDECIDED` 를 써라 — 억지 판정보다 낫다.
- 마지막에 **"가장 먼저 손대야 할 지점 3 개"** 를 순서와 이유와 함께.
  순서 기준: *물리가 한 조각씩 실제로 서는 방향* (감사 편의 아님).
